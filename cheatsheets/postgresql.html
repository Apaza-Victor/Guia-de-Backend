🐘 PostgreSQL

El motor relacional de código abierto más avanzado: JSON, transacciones sólidas, extensiones y EXplain de verdad. La base de datos preferida para sistemas modernos.

⚡ Cheatsheet Bases de datos Cheatsheets

Entrar con psql

psql es la terminal interactiva de PostgreSQL. No confundas los comandos meta (empiezan con \) con SQL.

Crear bases y tablas

BIGSERIAL crea una secuencia que genera el siguiente entero automáticamente. TIMESTAMPTZ guarda hora UTC con zona: la opción correcta para multiusuarios.

Buenas prácticas

  • Usa TIMESTAMPTZ y deja que el cliente decida la zona de presentación.
  • Prefiere IDENTITY (SQL estándar) sobre SERIAL para tablas nuevas.
  • JSONB es potente, pero no sustituye a las columnas para datos con esquema.
  • Crea índices solo donde EXPLAIN lo justifique.
  • Usa transacciones y FOR UPDATE con cuidado de no dejar transacciones abiertas.
  • Habilita backups automáticos SOLO después de probar una restauración.
