🎨 CSS

El lenguaje de presentación que convierte el HTML en una interfaz atractiva y adaptable. Esta hoja cubre desde selectores y especificidad hasta Grid, variables y modo oscuro.

Especificidad y cascada

Cuando dos reglas apuntan al mismo elemento, gana la que tiene mayor especificidad. Se calcula por componentes: estilos en línea (1000), IDs (100), clases/pseudo-clases/atributos (10) y elementos/pseudo-elementos (1).

ReglaPeso
style="color:red"1000 (gana casi siempre)
#main .card { }110
.card.card--active { }20
.card { }10
div p { }2
p { }1
  • A misma especificidad, gana la última regla declarada.
  • !important rompe la cascada; úsalo solo como último recurso.
  • Prefiere clases sobre IDs para mantener la especificidad baja y el CSS reutilizable.

Flexbox

Layout unidimensional: distribuye elementos en una fila (row) o columna (column). El contenedor padre se declara display: flex.

PropiedadValoresDescripción
flex-directionrow | column | row-reverseEje principal.
justify-contentflex-start, center, space-between, space-aroundAlineación en el eje principal.
align-itemsstretch, flex-start, center, flex-endAlineación en el eje cruzado (equivalente a fila/columna).
flex-wrapnowrap | wrapDeja que los hijos saltan a otra línea.
gap8px, var(--space-3)Espacio entre hijos (también en Grid).
flex-grow0 | 1 | nCuánto crece el hijo si sobra espacio.
flex-shrink1 | 0Cuánto se encoge si falta espacio.
flex-basisauto | px | %Tamaño base antes de crecer/encoger.
align-selfauto | stretch | centerSobrescribe align-items para un hijo.

grid-auto-flowdenseRellena huecos al colocar elementos.

Media queries y responsive

Las media queries aplican estilos según el ancho de la pantalla, el tipo de medio o las preferencias del sistema.

Hoy se recomienda el enfoque mobile-first: escribe los estilos base para el móvil y usa min-width para subir de tamaño.

Unidades

UnidadDescripciónUso típico
pxPíxel absoluto.Bordes finos, sombras, gaps pequeños.
remRelativa al tamaño de raíz (normalmente 16px).Tamaños de texto y espaciado.
emRelativa al tamaño de fuente del elemento padre.Padding proporcional al texto.
%Porcentaje del contenedor.Anchuras, alturas, fondos.
vh / vwRelativa a la ventana (100vh = alto total).Secciones a pantalla completa.
chAncho del carácter 0.Limitar longitud de párrafos (max-width: 72ch).
clamp()clamp(min, deseado, max)Tamaños fluidos responsivos.

Variables y animaciones

Las custom properties se declaran en una regla (normalmente :root) y se usan con var(). Permiten temas, dark mode centralizado y consistencia.

Buenas prácticas

  • Usa clases BEM (.bloque__elemento--modificador) para mantener la especificidad baja y el CSS predecible.
  • Centraliza el diseño en variables: colores, spacing, radios y duraciones.
  • Mobile-first con min-width en lugar de driblar max-width.
  • Anima solo transform y opacity: son las propiedades que la GPU acelera.
  • Evita !important y los IDs como ganchos de estilo.
  • Comprueba contraste de color (WCAG AA exige 4.5:1 para texto normal).
