🌐 HTML

El lenguaje que estructura toda página web y el punto de partida de cualquier aplicación: cada elemento, formulario o tablero que ves en pantalla es HTML en última instancia.

⚡ Cheatsheet Web Cheatsheets

Estructura básica

Todo documento HTML válido comienza con la declaración de tipo de documento y envuelve el contenido en las etiquetas raíz <html>, con los metadatos en <head> y el contenido visible en <body>.

EtiquetaFunción
<DOCTYPE html>Declara HTML5; va siempre en la primera línea.
<html lang="es">Raíz del documento; lang indica el idioma para accesibilidad y SEO.
<head>Metadatos: charset, viewport, title, links, scripts.
<body>Todo lo que se renderiza en pantalla.

Etiquetas semánticas

Las etiquetas semánticas describen qué es el contenido, no solo cómo se ve. Mejoran el SEO y la accesibilidad y son la base de cualquier página bien estructurada.

EtiquetaUso
<header>Cabecera de la página o de una sección (logos, nav, título).
<nav>Navegación principal con enlaces.
<main>Contenido principal único del documento.
<section>Agrupación temática de contenido.
<article>Contenido independiente y reutilizable (post, noticia, tarjeta).
<aside>Contenido complementario (sidebar, enlaces relacionados).
<footer>Pie de página: copyright, enlaces legales, contacto.
<figure> / <figcaption>Ilustración o bloque de código con su leyenda.
<hr>Separador temático horizontal.
<details> / <summary>Contenido plegable sin JavaScript.

Atributos comunes

Los atributos son pares clave="valor" que modifican el comportamiento de un elemento. Estos son los más usados:

AtributoDescripciónEjemplo
idIdentificador único del elemento (anclas, JS, CSS).id="nombre"
classClases CSS reutilizables (puede llevar varias).class="btn btn--primary"
hrefDestino de un enlace (en <a> y <link>).href="../index.html"
srcOrigen de un recurso (imagen, script, iframe).src="logo.png"
altTexto alternativo en imágenes (accesibilidad y SEO).alt="Logo de Backend Academy"
titleTooltip informativo al pasar el cursor.title="Ver más"
data-*Atributos de datos personalizados para JavaScript.data-user-id="42"
aria-* y roleDescriptores de accesibilidad (lectores de pantalla).aria-label="Buscar"
hiddenOculta el elemento sin borrarlo del DOM.hidden
typeTipo del elemento (botón, input, script, link).type="button"

Formularios y input types

El formulario es el puente entre el usuario y el backend: los datos se envían mediante GET (en la URL) o POST (en el cuerpo de la petición).

typeUsoValidación nativa
textTexto de una línea (nombre, usuario).—
passwordContraseña oculta con puntos.—
emailCorreo electrónico.Formato de email
numberValores numéricos con flechas.min, max, step
telNúmero de teléfono.—
urlEnlace web.Formato de URL
dateSelector de fecha.Formato AAAA-MM-DD
datetime-localFecha y hora local.—
fileAdjuntar archivos (sube con enctype="multipart/form-data").accept
checkboxCasilla de verificación (0 o varios).checked
radioOpción única dentro del mismo name.checked
select (no type)Lista desplegable con <option>.—
textarea (no type)Texto multilínea.rows, maxlength
rangeControl deslizante.min, max, step
hiddenValor enviado sin mostrarse.—

Usa <label for="id"> para vincular la etiqueta con su campo: hace clicable toda la etiqueta y ayuda a los lectores de pantalla.

Tablas

Las tablas se construyen con <table>, filas con <tr>, celdas de datos con <td> y cabeceras con <th>. Agrupa la cabecera con <thead> y el cuerpo con <tbody>.

Con colspan y rowspan una celda puede ocupar varias columnas o filas; úsalos para encabezados agrupados, no para maquetar.

Multimedia

Imágenes, audio y video con atributos de respaldo y accesibilidad:

  • <picture> sirve formatos modernos (WebP, AVIF) si el navegador los soporta.
  • loading="lazy" difiere la carga de imágenes fuera de la vista inicial.
  • <track> añade subtítulos a los videos.

Meta tags esenciales

Los meta viven en <head> y controlan el SEO, el comportamiento y las redes sociales:

MetaFunción
<meta charset="utf-8">Codificación de caracteres (obligatorio).
<meta name="viewport" ...>Responsive en móviles.
<meta name="description" content="...">Resumen que muestra Google en los resultados.
<meta name="keywords" ...>Palabras clave (poco peso real en SEO actual).
<meta name="author" ...>Autor del documento.
<link rel="canonical" href="...">URL canónica para evitar contenido duplicado.
<meta property="og:title" ...>Título al compartir en redes sociales.
<meta name="robots" content="noindex">Impide que Google indexe la página.

Buenas prácticas

  • Una sola etiqueta <h1> por página; usa los niveles h2-h6 en orden jerárquico.
  • Anida correctamente: cada etiqueta de apertura debe cerrarse (o ser autocontenida como <img>).
  • Si una etiqueta se puede cerrar sola, ciérrala cuando lleve atributos pero no marques bloque en línea.
  • Usa etiquetas semánticas antes que <div> y <span>: div es el último recurso para estructurar.
  • Siempre acompaña cada <input> con su <label>.
  • Valida del lado del servidor: el HTML nunca es una frontera de seguridad real.
  • Usa minúsculas en etiquetas y atributos, y comillas dobles para los valores.
