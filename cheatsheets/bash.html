Buenas prácticas

  • Empieza todo script con #!/usr/bin/env bash y set -euo pipefail.
  • Usa local dentro de funciones y llaves en toda variable.
  • Comillas dobles en expansiones: "$var" para manejar espacios.
  • Rutas absolutas en cron y servicios; verifica el PATH.
  • Valida argumentos y devuelve códigos de salida 0/1 explícitos.
  • Logs con fecha y redirección de 2>&1 para no perder errores.
