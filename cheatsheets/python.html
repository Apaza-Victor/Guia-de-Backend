ComandoQué hace

source .venv/bin/activateActivar (Linux/macOS).
.venv\Scripts\activateActivar (Windows).
pip install fastapiInstalar un paquete.

deactivateSalir del entorno.

Buenas prácticas

  • Escribe siempre con type hints: mejoran la legibilidad y permiten autocompletado y validación.
  • Usa venvs por proyecto y congela requirements.txt.
  • Prefiere comprehensions para transformaciones cortas y bucles claros para lógica larga.
  • Maneja errores capturando excepciones específicas, nunca except: a secas.
  • Nombres en snake_case, clases en CamelCase.
  • Configura siempre if __name__ == "__main__": para scripts ejecutables.
