Tipos de datos

FamiliaEjemplos típicos
Numéricos enterosTINYINT, SMALLINT, INT, BIGINT (con UNSIGNED para no negativos)
DecimalesDECIMAL(10,2) para dinero; FLOAT solo aproximaciones
CadenasCHAR(n) fijo, VARCHAR(n) variable, TEXT, JSON
FechasDATE, DATETIME, TIMESTAMP, TIME, YEAR
OpcionesENUM('a','b'), SET
  • Dinero: DECIMAL, nunca FLOAT.
  • IDs: BIGINT UNSIGNED AUTO_INCREMENT o CHAR(36) para UUID.
  • Hashes: CHAR(64) para SHA-256, VARCHAR(255) para bcrypt.

Buenas prácticas

  • Define siempre una PRIMARY KEY y claves foráneas con el mismo tipo exacto de dato.
  • Motor InnoDB siempre (transacciones y FK).
  • Nunca formes consultas concatenando texto; usa prepared statements en el backend.
  • Usa utf8mb4_unicode_ci en bases nuevas.
  • Backups automáticos programados (cron) y restauración probada, no solo programada.
  • No hagas SELECT * desde la aplicación; pide columnas.
