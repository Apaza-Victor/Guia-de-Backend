Introducción a AWS

🔥 Avanzado 10 min Cloud para Backend Módulo 2 · AWS

El gigante del cloud

Amazon Web Services es el proveedor de cloud más usado del mundo. Su alcance asusta (más de 200 servicios), pero un backendista necesita conocer bien unos diez. Esta lección te da el mapa mental antes de tocar cada pieza.

La cuenta y sus cuidados

La cuenta AWS se crea con email + tarjeta (hay tier gratuito por 12 meses, no se cobra de inicio). Reglas de oro desde el minuto uno:

  • Jamás uses los accesos de la cuenta raíz para trabajar; se crean usuarios IAM para eso (lección de seguridad).
  • Activa MFA (segundo factor) en la cuenta raíz sí o sí.
  • Configura una alerta de gasto a $1 antes de tocar nada (módulo de costos).
  • Por defecto la consola es tu casa: https://console.aws.amazon.com.

Mapa de servicios para Backend

La arquitectura típica de una API

El patrón más usado: front en CloudFront → API en EC2 o contenedores → datos en RDS, archivos en S3. Con Lambda + API Gateway, la misma API corre sin tocar una máquina. Ambas variantes son legítimas; las lecciones siguientes te dan las piezas para armarlas.

Ejercicio

  1. Crea tu cuenta AWS (puedes esperar si prefieres el tier gratuito) y entra a la consola.
  2. Activa MFA en la cuenta raíz y configura una alerta de presupuesto a $1.
  3. Redacta los pasos de tu posible arquitectura usando los servicios del mapa.

Resumen

  • AWS tiene +200 servicios, pero para Backend bastan ~10 bien usados.
  • Cuenta raíz se protege con MFA; la operación pasa por usuarios IAM.
  • El patrón base: API (EC2/Lambda) + RDS para datos + S3 para archivos.
  • Las alertas de gasto se configuran antes que cualquier recurso.
