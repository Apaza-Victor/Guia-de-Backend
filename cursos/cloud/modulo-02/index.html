Módulo 2 · Amazon Web Services (AWS)

Los servicios que sostienen al Backend de AWS: cómputo, almacenamiento, bases de datos, funciones y seguridad.

🔥 Avanzado Cloud para Backend Nivel: Avanzado

Objetivos del módulo

AWS es el proveedor más usado: conocerás las piezas que cualquier API usa en producción y las operarás desde la CLI.

  • Lanzar y conectar EC2 con seguridad por security groups.
  • Guardar y servir archivos con S3.
  • Usar RDS como base gestionada con réplicas.
  • Ejecutar lógica con Lambda sin servidores.
  • Manejar permisos mínimos con IAM.

Lecciones del módulo

6 lecciones · ~65 min · soporte real de AWS para tu Backend.

1 · Introducción a AWS

La cuenta, la consola, las regiones y el mapa de servicios esenciales.

10 minconceptos

2 · EC2: máquinas virtuales

Lanza una instancia, llaves SSH y security groups para tu API.

13 mincómputo

3 · S3: almacenamiento de archivos

Buckets para subir y servir archivos de tu Backend públicamente o no.

10 minalmacenamiento

4 · RDS: bases de datos gestionadas

Postgres/MySQL en la nube con backups, réplicas y alta disponibilidad.

11 mindatos

5 · Lambda: funciones serverless

Executa código bajo demanda, eventos S3/SQS y API Gateway.

12 minserverless

6 · IAM y seguridad

Usuarios, roles y políticas de menor privilegio para no regalar tu cuenta.

9 minseguridad
