EC2: máquinas virtuales

🔥 Avanzado 13 min Cloud para Backend Módulo 2 · AWS

La VM de AWS

EC2 (Elastic Compute Cloud) es el servicio de máquinas virtuales de AWS: eliges sistema operativo (AMI), tamaño (tipo de instancia) y red, y en minutos tienes un servidor con root propio. Es la pieza IaaS por excelencia.

Tipos de instancia

Las instancias se agrupan por familia: t3.small, m5.large, etc. Letra = familia (t: burst / general, m: general, c: cómputo, r: memoria), número = generación, sufijo = tamaño (small, large, xlarge...).

Pares de llaves y AMIs

Para entrar por SSH, EC2 usa pares de llaves: generas un par, AWS guarda la pública y tú la privada (el .pem lo descargas una sola vez, no se puede recuperar). La AMI es la imagen del sistema: Ubuntu, Amazon Linux, o la que quieras, construidas para esa región.

Ejercicio

  1. Lanza una instancia t3.micro (tier gratuito) con tu par de llaves y un security group con SSH limitado a tu IP.
  2. Conéctate por SSH y verifica que eres root.
  3. Documenta qué puertos abrirías para una API detrás de Nginx y cuáles no.

Resumen

  • EC2 es IaaS: eliges AMI, tipo de instancia, llaves y red.
  • Los pares de llaves se generan una vez; la privada no se recupera.
  • Los security groups abren sólo lo necesario (principio de mínimo acceso).
  • Nunca expongas el puerto 22 a todo internet.
