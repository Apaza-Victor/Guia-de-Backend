S3: almacenamiento de archivos

🔥 Avanzado 10 min Cloud para Backend Módulo 2 · AWS

El cajón infinito de AWS

S3 (Simple Storage Service) guarda objetos (archivos con metadatos) en buckets (contenedores con nombre único global). Es el almacenamiento más usado del mundo: fotos, backups, logs, assets de una API. Casi ilimitado, duradero y barato.

Conceptos clave

  • Bucket: contenedor con nombre único global (mi-api-media).
  • Objeto: clave (ruta lógica) + datos + metadatos. "Carpetas" son prefijos: usuarios/42/avatar.png.
  • Región: se elige al crear el bucket y define latencia y precio.
  • Versionado: guarda cambios de un objeto (protección contra borrados).

Público o privado: con cuidado

S3 en el Backend

  • Rama privada: fotos de perfil, documentos, facturas: la API firma URLs temporales.
  • Rama pública: estáticos del frontend, assets, imágenes de catálogo.
  • Backups: versionado + regla de vida útil (Glasier para archivos de años).
  • Eventos: al cargar un objeto se dispara una Lambda (thumbnail, validación).

Ejercicio

  1. Crea un bucket, sube un archivo y listalo desde la línea de comandos.
  2. Genera una presigned URL con boto3 o la CLI y descarga el archivo con ella.
  3. Evalúa qué de tu app debería ser público, qué privado y qué a proteger con versionado.

Resumen

  • S3 guarda archivos como objetos en buckets con nombres únicos globales.
  • Los objetos son privados por defecto; el acceso público se concede con cuidado.
  • Las presigned URLs sirven archivos privados por tiempo limitado.
  • El versionado y los eventos S3→Lambda completan su uso Backend.
