☁️ Cloud para Backend

Domina los servicios en la nube que sostienen el Backend moderno. Aprende a desplegar, escalar y gestionar aplicaciones en AWS, Google Cloud y Azure, y entiende cuándo usar Serverless, contenedores o máquinas virtuales.

6 semanas 6 módulos · 54 lecciones AWS · GCP · Azure · Serverless

¿Qué vas a aprender?

El Backend moderno vive en la nube. En este curso aprenderás a utilizar los principales proveedores de cloud (AWS, Google Cloud y Azure) para desplegar APIs, almacenar archivos, gestionar bases de datos y escalar automáticamente. Compararás los servicios de cada proveedor, aprenderás a elegir el más adecuado para tu caso de uso y dominarás el paradigm serverless con Lambda, Cloud Functions y más.

Objetivos del curso

✔Entender los conceptos fundamentales de cloud computing y modelos de servicio (IaaS, PaaS, SaaS).
✔Desplegar y gestionar instancias EC2, Lambda y S3 en Amazon Web Services.
✔Usar Google Cloud Run, Cloud Functions y Cloud Storage para Backend.
✔Explorar los servicios clave de Azure: App Service, Functions y Blob Storage.
✔Diseñar arquitecturas serverless para APIs Backend eficientes y escalables.
✔Gestionar variables de entorno, secrets, dominios y certificados SSL en la nube.
✔Comprender el modelo de costos y optimizar el gasto en cada proveedor.

Requisitos previos

  • Experiencia básica con Backend (APIs REST, servidores, bases de datos).
  • Conocimientos de Docker son recomendados pero no obligatorios.
  • Una cuenta gratuita en AWS, Google Cloud o Azure (todas ofrecen tier gratuito).
  • Familiaridad con la línea de comandos y terminal.

Tecnologías y herramientas

AWS Google Cloud Azure Lambda S3 Serverless EC2 Cloud Run
