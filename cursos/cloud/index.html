Módulos del curso

Módulo 1 · Fundamentos del Cloud

5 lecciones≈ 53 min

Comprende qué es la nube, los modelos de servicio IaaS, PaaS y SaaS, las regiones y zonas de disponibilidad, y las herramientas de cada proveedor para empezar con bases sólidas.

  1. ¿Qué es la nube? Por qué domina el Backend
  2. Modelos de servicio: IaaS, PaaS, SaaS
  3. Regiones y zonas de disponibilidad
  4. VPS vs Serverless
  5. CLIs y consolas de cada proveedor

Módulo 2 · Amazon Web Services (AWS)

6 lecciones≈ 65 min

Domina los servicios fundamentales de AWS para backend: máquinas virtuales EC2, almacenamiento S3, bases de datos gestionadas RDS, funciones serverless Lambda y seguridad IAM.

  1. Introducción a AWS
  2. EC2: máquinas virtuales
  3. S3: almacenamiento de archivos
  4. RDS: bases de datos gestionadas
  5. Lambda: funciones serverless
  6. IAM y seguridad
Empezar módulo

Módulo 3 · Microsoft Azure

5 lecciones≈ 54 min

Aprende Azure desde la perspectiva del backend: suscripciones y resource groups, App Service como PaaS, Functions serverless, bases de datos gestionadas y Blob Storage.

  1. Introducción a Azure
  2. App Service: PaaS para APIs
  3. Functions: serverless en Azure
  4. Azure SQL Database y Cosmos DB
  5. Blob Storage y almacenamiento
Empezar módulo

Módulo 4 · Google Cloud Platform

5 lecciones≈ 55 min

Aprende Google Cloud desde la perspectiva del backend: proyectos y contexto gcloud, Compute Engine, Cloud Functions, Cloud Run y el almacenamiento con Storage y Firestore.

  1. Introducción a Google Cloud
  2. Compute Engine y VM
  3. Cloud Functions: serverless
  4. Cloud Run: contenedores serverless
  5. Storage y Firestore

Módulo 5 · Redes, seguridad y alta disponibilidad

6 lecciones≈ 71 min

Domina las redes en la nube, la seguridad y compliance, el IAM con menor privilegio, los backups, las estrategias de migración y la tolerancia a fallos que sostienen un backend profesional.

  1. VPC y redes en la nube
  2. Seguridad y compliance
  3. IAM y menor privilegio
  4. Backups y alta disponibilidad
  5. Estrategias de migración
  6. Tolerancia a fallos y redundancia

Módulo 6 · Costos y Estrategia

5 lecciones≈ 58 min

Gestiona el costo de tu backend en la nube: capas gratuitas, alertas de gasto, modelos de precios, optimización, equivalencias entre proveedores y el despliegue de una API con estrategia.

  1. Capa gratuita y alertas de gasto
  2. Entender el modelo de precios
  3. Optimización de costos
  4. Equivalencias entre AWS, GCP y Azure
  5. Despliegue de una API con estrategia

5 lecciones≈ 63 min

Cierra el curso con los patrones de producción serverless, API Gateway y CDN, arquitecturas event-driven, infraestructura como código en la nube y el diseño cloud-native completo.

  1. Serverless en producción
  2. API Gateway y CDN
  3. Arquitecturas event-driven
  4. Infraestructura como código en la nube
  5. Diseño cloud-native
