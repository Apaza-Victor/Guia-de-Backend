Despliegue de una API con estrategia

🔥 Avanzado 14 min Cloud para Backend Módulo 6 · Costos y Estrategia

Todo el curso en un despliegue

Este proyecto final junta cada pieza: una API Flask con Postgres, archivos en S3 y un frontend de estáticos; con presupuesto, seguridad y costos bajo control. El objetivo: producción real por menos de $5/mes en AWS (o su equivalente gratis en GCP/Azure).

Diseño y arquitectura

Paso 1: red y seguridad

  • VPC propia con dos subredes (una pública para el ELB, una privada para la API y la DB).
  • Security groups draconianos: API: solo 80/443 del load balancer y SSH desde tu IP; DB: solo 5432 del SG de la API.
  • Usuarios IAM con roles mínimos (EC2 con rol que solo lee su bucket).

Paso 2: los recursos

Paso 3: desplegar la API

La API usa el rol de la instancia para firmar las presigned URLs de S3: cero Access Keys en el servidor.

Paso 4: presupuesto y monitoreo

Checklist final

  • ✔ API sin acceso público directo: la entrada es el load balancer y Nginx.
  • ✔ DB privada en la VPC, con backups de 7 días.
  • ✔ Archivos privados por presigned URL; front estático en S3 público.
  • ✔ Roles IAM y cero secretos en el código.
  • ✔ Presupuesto a $5 con alerta al 80%.
  • ✔ Rotar credenciales y detener instancias de prueba fuera de horario.

Ejercicio

  1. Despliega esta arquitectura en tu proveedor con los recursos mínimos que pague $0.
  2. Verifica que no puedes llegar a la DB ni a la API por buro de internet.
  3. Borra o detén los recursos no esenciales y registra tu factura al cierre del mes.

Resumen

  • Una API de producción es cloud: VPC + EC2/API + RDS + S3, bien segmentada.
  • La seguridad se declara: subredes privadas y security groups mínimos.
  • El presupuesto se configura antes del primer recurso.
  • Con free tier y buenas prácticas, producción real cabe en $5/mes o $0.
