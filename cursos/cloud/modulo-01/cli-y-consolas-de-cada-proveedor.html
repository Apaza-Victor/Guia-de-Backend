CLIs y consolas de cada proveedor

🔥 Avanzado 10 min Cloud para Backend Módulo 1 · Fundamentos

Consola o terminal

Todo proveedor tiene una consola web (apunta y clic) y una CLI (comandos). La CLI es lo que usarás en pipelines y scripts: reproducible, versionable y rápida. En producción te conviene vivir en la terminal.

AWS CLI

gcloud (Google Cloud)

az (Microsoft Azure)

La parte divertida: todo se parece

Los tres siguen el mismo ritmo: login → setear región/proyecto → crear recurso → listar → borrar. Aprender uno prepara los otros dos. Si tu presupuesto es bajo, una muy razonable ruta: empezar por AWS por su cobertura y comunidad, o GCP por su tier generoso en Cloud Run.

Ejercicio

  1. Instala la CLI de un proveedor (usa la capa gratuita) y autentícate.
  2. Verifica tu identidad con el equivalente de sts get-caller-identity en tu proveedor.
  3. Lista todos los recursos que tengas en la región por defecto con un solo comando.

Resumen

  • La CLI es reproducible y versionable: la base de todo pipeline.
  • AWS: aws configure + aws s3/ec2/... ; GCP: gcloud auth login; Azure: az login.
  • Todos comparten el mismo flujo: autenticar, fijar región/proyecto, operar.
  • Elige un proveedor, domina su CLI y los otros llegan solos.
