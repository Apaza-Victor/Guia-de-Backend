Subconsultas escalares

⚙️ Intermedio 10 min SQL Módulo 4 · Subconsultas y CTEs

Introducción

Una subconsulta escalar es una consulta dentro de otra que devuelve un único valor (una fila, una columna). Se lee de dentro hacia fuera: primero se calcula el valor interno y luego se usa como si fuera un dato normal.

Con WHERE

Con SELECT

La subconsulta del SELECT depende de la fila exterior (pr.categoria): por eso es tan flexible. No dejes que el nombre te intimide: «escalar» solo significa «un valor solo».

Reglas y límites

  • Debe devolver una sola fila y una sola columna (1 valor).
  • Si devuelve más de una fila, el motor lanza error (1242 en MySQL).
  • Con NO valor devuelto (0 filas), el resultado es NULL (no error).
  • En un WHERE, colócala a la derecha del operador de comparación.

Alternativa con JOIN

Compara y elegirás: si solo quieres el dato global, la subconsulta es simple. Si quieres el detalle fila a fila, sigue con la subconsulta del SELECT o pasa a CTEs (próximas lecciones).

Ejercicio

  1. Lista productos más caros que la media global de tu tienda.
  2. Trae cada pedido y junto a él el importe medio de todos los pedidos.
  3. Predice el resultado si la subconsulta devuelve dos filas… y compruébalo.

Resumen

  • Subconsulta escalar = un único valor calculado al vuelo.
  • Aparece en WHERE (comparaciones) y en SELECT (columnas extra).
  • 0 filas → NULL; varias filas → error.
  • Se lee desde dentro hacia fuera.
