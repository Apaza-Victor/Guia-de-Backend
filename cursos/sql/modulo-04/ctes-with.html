CTEs con WITH

⚙️ Intermedio 10 min SQL Módulo 4 · Subconsultas y CTEs

Introducción

Una CTE (Common Table Expression) es un «SELECT con nombre» declarado con WITH y usado después en la consulta principal. Es como crear una tabla temporal en memoria, sin ensuciar la base, para leer el problema por etapas.

CTE vs subconsulta en FROM

La subconsulta en el FROM hace lo mismo, pero anida paréntesis. Con tres niveles de profundidad se vuelve ilegible. El CTE «aplana» el código y además permite reutilizar el mismo SELECT varias veces dentro de la consulta:

Trampas habituales

  • Olvidar que una CTE no crea un índice propio: si es enorme, úsala con red o considera una vista materializada.
  • No recuadrar el SELECT principal tras el bloque WHERE final: todo debe quedar dentro del statement.
  • Usar un nombre repetido (nombre de tabla real): el CTE lo oculta; califica o renombra.

Ejercicio

  1. Escribe un reporte de 3 pasos con WITH: pagados → por cliente → ranking.
  2. Refactoriza una consulta con subconsultas anidadas a CTEs.
  3. Reutiliza la misma CTE dos veces y valida el resultado.

Resumen

  • WITH crea SELECT con nombre, reutilizable dentro de la consulta.
  • Encadena CTEs para convertir monstruos en pasos legibles.
  • Es «aplanamiento» de subconsultas, no una tabla física.
  • Perfectas para reportes de varias etapas.
