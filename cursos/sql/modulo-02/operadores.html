Operadores de comparación y lógicos

⚙️ Intermedio 10 min SQL Módulo 2 · Consultas avanzadas

Introducción

Los operadores son los ladrillos de todo filtro SQL. Parecen sencillos, pero el NULL y los errores de la lógica de tres valores cogen a más de un junior (y a más de un senior). Aquí lo asentamos de una vez.

Ejercicio

  1. Escribe 3 consultas que demuestren la lógica de tres valores con tus datos.
  2. Prueba NOT IN con NULL y explica qué pasó.
  3. Usa COALESCE para presentar un campo nullable con un valor por defecto.

Resumen

  • Comparadores >, <, =, <>, >=, <=.
  • La lógica de tres valores: TRUE, FALSE, UNKNOWN.
  • NULL nunca se compara con =, se usa IS NULL / COALESCE.
  • AND, OR, NOT con paréntesis explícitos.
  • NOT IN con NULL es trampa: usa NOT EXISTS.
