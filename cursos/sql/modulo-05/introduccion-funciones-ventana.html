Introducción a funciones de ventana

⚔️ Avanzado 12 min SQL Módulo 5 · Funciones de ventana

El problema

Quieres, en una misma fila, un valor y «su posición» o «la media del grupo». Con GROUP BY logras el agregado, pero pierdes el detalle: se colapsan las filas. La función de ventana calcula sobre un conjunto de filas relacionadas sin fusionarlas.

Qué es una ventana

Ventana = subconjunto de filas, definido en el OVER(), sobre el que se aplica el cálculo. La sintaxis base es función + OVER:

A diferencia de GROUP BY (1 fila por grupo), aquí el resultado tiene todas las filas de entrada, cada una con columnas calculadas.

GROUP BY vs ventana

PARTITION BY divide el conjunto en «subgrupos» (la ventana); ORDER BY dentro del OVER marca el orden del cálculo. Sin PARTITION, la ventana es todo el conjunto.

Tres familias de funciones

  • Ranking: ROW_NUMBER, RANK, DENSE_RANK, NTILE.
  • Agregadas: SUM, AVG, COUNT, MIN, MAX aplicadas sobre la ventana (muy usadas con acumulados).
  • Offset: LAG, LEAD (miran filas anteriores/posteriores).

Casos de uso típicos

  • Top N por categoría (ranking + PARTITION + filtro de posición).
  • Acumulado de ventas por mes (SUM + ORDER BY fecha).
  • Comparar un importe con el del mes anterior (LAG).
  • Porcentajes dentro de un grupo (SUM/SUM OVER).

Ejercicio

  1. Reproduce el ejemplo de RANK con tus datos de salarios.
  2. Compara visualmente la salida de GROUP BY y de la ventana COUNT.
  3. Enumera tres reportes de tu trabajo donde una ventana sería útil.

Resumen

  • Ventana = cálculo sobre subconjuntos sin colapsar filas.
  • OVER() define la ventana: PARTITION BY divide; ORDER BY ordena.
  • GROUP BY devuelve 1 fila por grupo; la ventana conserva todas.
  • Ranking, agregadas sobre ventana y LAG/LEAD.
