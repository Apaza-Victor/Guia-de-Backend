SQL desde cero hasta experto

SELECT, JOINs, subconsultas, CTEs, funciones de ventana, transacciones y optimización: SQL completo hasta nivel profesional.

8 semanas 7 módulos · 33 lecciones SQL · Consultas · Optimización

¿Qué vas a aprender?

SQL es el idioma común de todas las bases de datos relacionales y una habilidad imprescindible para cualquier desarrollador backend. Este curso te lleva de las consultas más simples a las técnicas de nivel experto: JOINs complejos, subconsultas, CTEs, funciones de ventana y optimización de índices. Al finalizar analizarás y escribirás consultas rápidas incluso sobre grandes volúmenes de datos.

Categoría🗄️ Base de Datos

Objetivos de aprendizaje

✔Construir consultas SELECT completas con filtros, orden y límites.
✔Combinar y analizar datos con todo tipo de JOINs.
✔Dominar subconsultas, CTEs y consultas recursivas.
✔Aplicar funciones de ventana para cálculos avanzados.
✔Optimizar consultas leyendo planes de ejecución y usando índices.

Requisitos previos

  • Bases de Datos: saber qué es una tabla, un registro y una clave.
  • Una instalación de MySQL o PostgreSQL (te guiamos en el proceso).
  • Lógica para pensar en términos de conjuntos de datos.

Tecnologías y herramientas

SQL MySQL PostgreSQL CTEs Índices EXPLAIN

Siete módulos que avanzan de las primeras consultas al dominio del lenguaje: desde SELECT hasta optimización real.
