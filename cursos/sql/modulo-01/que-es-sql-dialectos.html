Qué es SQL y sus dialectos

⚙️ Intermedio 8 min SQL Módulo 1 · Fundamentos de SQL

Introducción

SQL (Structured Query Language) es el lenguaje declarativo con el que hablas con una base de datos relacional: le dices qué quieres, no cómo conseguirlo. Es la habilidad más demandada en backend porque casi todo producto descansa sobre una base relacional.

Pensar en conjuntos

Fíjate: no le indicas cómo buscar. La base decide la estrategia (índice, orden de lectura…). Tu trabajo es plantear bien qué conjunto de datos quieres.

El estándar y los dialectos

Existe un estándar ANSI/ISO, pero cada motor implementa su propia versión con extensiones y particularidades. Lo que escribes en uno casi siempre funciona en otro, con matices:

  • MySQL: popular, incluyó JSON y funciones de ventana en versiones recientes (8.0).
  • PostgreSQL: fiel al estándar y con funciones propias potentes (JSONB, RETURNING).
  • SQL Server / Oracle: estándar corporativo, con TOP o ROWNUM en vez de LIMIT.
  • SQLite: embebida y perfecta para pruebas.

Las cinco familias de instrucciones

  • DQL: SELECT (leer).
  • DML: INSERT, UPDATE, DELETE (manipular datos).
  • DDL: CREATE, ALTER, DROP (estructura).
  • DCL: GRANT, REVOKE (permisos).
  • TCL: BEGIN, COMMIT, ROLLBACK (transacciones).

Claves para portar consultas

  • Conoce la documentación oficial del motor (convención de comillas, sintaxis de fecha).
  • Busca la documentación oficial del dialecto antes de copiar.
  • Prueba siempre en un ambiente de desarrollo.
  • El estándar es tu punto común: aprende lo portátil primero.

Ejercicio

  1. Escribe con tus palabras qué significa que SQL sea declarativo.
  2. Elige el motor que usarás en el curso y anota 3 diferencias de sintaxis frente a otro.
  3. Identifica a qué familia pertenecen: ALTER TABLE, DELETE, GRANT, COMMIT.

Resumen

  • SQL describe qué datos quieres, no cómo obtenerlos.
  • Hay un estándar ANSI y variaciones por motor.
  • DQL, DML, DDL, DCL y TCL agrupan las instrucciones.
  • La antigüedad del dialecto te prepara para cualquier base.
