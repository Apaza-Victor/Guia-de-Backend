Filtrando con WHERE

⚙️ Intermedio 9 min SQL Módulo 1 · Fundamentos de SQL

Introducción

Con WHERE le dices a la base «de todas las filas, dame solo estas». Es la cláusula más usada en consultas de producción: cada búsqueda, cada filtro de reporte, cada endpoint de tu API pasa por aquí.

Operadores de comparación

Operadores lógicos

Prioridad clásica: NOT > AND > OR. Usa paréntesis para que la lógica sea explícita.

IN, BETWEEN y LIKE

NULL: el tercer estado

NULL no es cero ni texto vacío: es «sin valor». Por eso se consulta con IS NULL / IS NOT NULL, nunca con = NULL (que no devuelve nada):

Ejercicio

  1. Productos con precio > 30 y stock <= 5.
  2. Productos de 2 categorías con LIKE para nombres que empiecen por «Te».
  3. Una consulta donde pruebes IS NULL con tus datos.

Resumen

  • WHERE filtra filas con comparadores.
  • AND, OR y NOT componen condiciones (con paréntesis).
  • IN, BETWEEN y LIKE agilizan rangos y texto.
  • NULL se consulta con IS NULL, nunca con =.
