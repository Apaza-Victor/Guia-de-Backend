Tu primera consulta: SELECT básico

⚙️ Intermedio 9 min SQL Módulo 1 · Fundamentos de SQL

Introducción

El SELECT es la instrucción que más escribirás. Su forma más simple tiene dos partes: qué columnas quieres y de qué tabla. Pensar siempre en términos de tabla resultado te da una ventaja enorme.

Estructura básica

SELECT * está bien para explorar; en producción se lista explícitamente (consume menos y no depende del orden de columnas).

Alias con AS

Los alias dan nombre a las columnas calculadas y ahorran teclas: los necesitarás en todas las consultas complejas.

Valores únicos con DISTINCT

Orden lógico de ejecución

Aunque escribas SELECT ... FROM ... WHERE ... ORDER BY, el motor ejecuta así: FROM → WHERE → SELECT → ORDER BY. Esto explica por qué no puedes usar un alias del SELECT en el WHERE pero sí en el ORDER BY. Lo retomamos en la optimización.

Ejercicio

  1. Inserta 3 productos de prueba en tu tabla (nombre, precio, stock).
  2. Consulta solo nombre y precio, y agrega una columna calculada con IVA (21%).
  3. Usa DISTINCT sobre la columna que quieras e interpreta su salida.

Resumen

  • SELECT columna(s) FROM tabla devuelve una tabla-resultado.
  • Los alias con AS renombran columnas.
  • DISTINCT elimina duplicados.
  • El orden lógico de ejecución empieza por FROM.
