Instalando MySQL o PostgreSQL

⚙️ Intermedio 8 min SQL Módulo 1 · Fundamentos de SQL

Introducción

Toda la teoría de SQL se aprende escribiendo. Elige MySQL o PostgreSQL, instálalo y verifica que tu terminal te responde. Si ya lo hiciste en el curso de Bases de Datos, salta a la prueba rápida final.

Instalar MySQL (recap)

  1. Descarga MySQL Community Server y ejecuta el instalador.
  2. Deja el puerto 3306 y define contraseña para root.
  3. Comprueba que el servicio está levantado.

Instalar PostgreSQL (recap)

El instalador de PostgreSQL trae pgAdmin 4, pero la práctica de este curso se hace en consola: los hábitos de terminal te servirán en servidores de producción donde no hay GUI.

Base de práctica sugerida

Esta tabla «productos» será tu banco de pruebas en todo el curso.

Prueba rápida final

  • Conectarse sin errores desde la terminal.
  • Ejecutar SELECT 1; y recibir una fila.
  • Crear la base y la tabla de práctica.
  • Saber detener y arrancar el servicio.

Ejercicio

  1. Si no tienes motor instalado, instala MySQL o PostgreSQL.
  2. Conéctate por consola y ejecuta SELECT 1 y SELECT VERSION().
  3. Crea la base «academia_tienda» con la tabla productos.

Resumen

  • Instala MySQL o PostgreSQL; ambos sirven para el curso.
  • Conócelos por consola, la forma de trabajo profesional.
  • Crea tu banco de pruebas: base «academia_tienda».
  • La práctica constante es el corazón del aprendizaje de SQL.
