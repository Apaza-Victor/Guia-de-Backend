Módulo 3 · Escalar y asegurar WebSockets

Lleva el tiempo real a producción: múltiples nodos con Redis pub/sub, adaptadores y sticky sessions, seguridad, heartbeat y despliegue tras un proxy.

5 lecciones ≈ 50 min Redis · nginx

Objetivos del módulo

✔Escalar WebSockets a múltiples instancias con Redis pub/sub.
✔Configurar sticky sessions y adaptadores como socket.io-redis.
✔Endurecer el sistema: wss://, origen, rate limiting y sanitización.
✔Mantener conexiones vivas con heartbeat y desplegar tras nginx o HAProxy.
