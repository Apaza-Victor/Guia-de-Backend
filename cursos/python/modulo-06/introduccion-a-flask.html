Introducción a Flask

🔥 Avanzado 12 min Python para Backend Módulo 6 · Web con Flask

Introducción

Flask es un micro framework que en pocas líneas convierte tu lógica Python en un servidor web capaz de responder peticiones.

Es ideal para aprender web en Python: sin magia, rutas explícitas y control total.

Definición

Flask es un framework web mínimo: la app se crea con Flask(__name__), @app.route asocia URLs a funciones y app.run() levanta el servidor.

Por qué importa. Con un servidor web tus funciones dejan de ser scripts: clientes, navegadores y otras APIs pueden consumirlas.

Cuándo usarlo. Usa Flask para prototipos, microservicios pequeños, dashboards internos o como puente a APIs externas.

Conceptos clave

  • pip install flask instala la librería.
  • Flask(__name__) crea la aplicación.
  • @app.route("/") asocia la URL raíz a una vista.
  • app.run(debug=True) arranca con recarga automática.
  • Las vistas devuelven texto, HTML o JSON con jsonify.

Ejemplo real

Consumir tu API Flask con curl y con requests desde otro script: el flujo cliente-servidor.

  • El navegador y curl hacen GET en la URL raíz.
  • La segunda vista devuelve JSON nativo que Flask serializa.
  • debug=True recarga y muestra errores útiles en desarrollo.

Para desarrollo usa app.run; en producción el servidor WSGI (gunicorn) ejecutará tu app. Mismo código, distinto ejecutor.

Explicación

  • @app.route registra una URL; varias rutas pueden compartir una vista.
  • Devolver un dict en Flask produce automáticamente un JSON con 200.
  • debug=True incluye recarga y tracebacks en el navegador.
  • Flask(__name__) usa el nombre del módulo para localizar templates y estáticos.
  • app.run solo debe ejecutarse desde el guard __main__.

Errores comunes

  • Address already in use si el puerto 5000 está ocupado; cambia el port.
  • RuntimeError working outside of request context al usar request fuera de una vista.
  • ModuleNotFoundError: No module named 'flask' por instalar fuera del venv correcto.

Buenas prácticas

  • Trabaja siempre con un venv para no ensuciar tu Python global.
  • Activa debug solo en desarrollo; desactívala en producción.
  • Devuelve dicts para JSON; no construyas la serialización manualmente.
  • Usa puertos no convencionales para evitar conflictos del sistema.

Ejercicio

  1. Crea una ruta /saludo que responda Hola Mundo.
  2. Agrega una ruta /version que devuelva un JSON con version y fecha.
  3. Consume ambas con curl y con requests desde un script.

Resumen

  • Flask crea un servidor con @app.route y app.run().
  • Devolver dicts genera JSON automáticamente.
  • curl y requests permiten probar tu backend sin navegador.
