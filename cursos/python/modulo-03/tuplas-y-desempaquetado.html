Tuplas y desempaquetado

⚙️ Intermedio 9 min Python para Backend Módulo 3 · Estructuras de datos

Introducción

Cuando una función devuelve varios valores o quieres un grupo inmutable, las tuplas son la elección natural.

Junto con el desempaquetado, escriben código muy expresivo en backend: coordenadas, pares clave-valor, intervalos.

Definición

Una tupla es una secuencia inmutable que agrupa valores; el desempaquetado asigna sus elementos a variables en una sola línea.

Por qué importa. Los datos estructurales (un rango, un endpoint con verbo, una coordenada) no deberían mutar; las tuplas protegen y documentan eso.

Cuándo usarlo. Usa tuplas para retornos múltiples, claves de dict, configs inmutables y conjuntos de constantes.

Conceptos clave

  • Una tupla se crea con (a, b) o con la coma: a, b = 1, 2.
  • Es inmutable: no admite append ni asignación de índices.
  • El desempaquetado a, b = tupla funciona con cualquier iterable.
  • El asterisco captura el resto: primero, *resto = datos.
  • Para ignorar valores usa el guion bajo.

El swap b, a = a, b funciona porque Python evalúa el lado derecho completo antes de asignar.

Explicación

  • Las tuplas son inmutables: imposible modificar datos por accidente.
  • El desempaquetado obliga a que la cantidad de variables coincida con la de elementos.
  • El asterisco captura el resto y facilita trabajar con listas de tamaño variable.
  • Los pares clave-valor de .items() se desempaquetan naturalmente en bucles.

Errores comunes

  • ValueError: too many values to unpack al usar más variables que elementos.
  • Tuple index assignment lanza TypeError por inmutabilidad.
  • Olvidar la coma en tuplas de un solo elemento: (5) no es tupla, (5,) sí.

Buenas prácticas

  • Usa tuplas para datos que nunca deban cambiar: rutas, puertos, constantes.
  • Desempaqueta con nombres claros que expliquen cada elemento.
  • Usa _ para marcar los valores que descartas.
  • Prefiere tuplas a listas para los retornos múltiples de funciones.

Ejercicio

  1. Crea una tupla llamada constantes con (10, 20, 30) y desempaquétala en 3 variables.
  2. Escribe una función devolver_estado() que retorne (codigo, mensaje) y captura ambos.
  3. Intercambia dos variables sin variable auxiliar.

Resumen

  • Las tuplas agrupan datos inmutables.
  • El desempaquetado asigna muchos valores en una línea.
  • *resto y _ hacen flexible el unpacking con listas variables.
