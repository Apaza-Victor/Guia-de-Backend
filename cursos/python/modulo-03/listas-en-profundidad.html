Listas en profundidad

⚙️ Intermedio 10 min Python para Backend Módulo 3 · Estructuras de datos

Introducción

Las listas son la colección que más usas en backend: listas de resultados de una consulta, de pedidos, de ids para una API.

En esta lección vas más allá de append y for: slicing, ordenación con claves, copias seguras y comprensiones potentes.

Definición

Una lista es una secuencia ordenada y mutable de elementos que se indexa desde 0 y se manipula con métodos y operadores.

Por qué importa. Casi todos los datasets que se procesan llegan como listas; dominarlas es procesar datos a velocidad real.

Cuándo usarlo. Usa listas para resultados de consultas, colas de trabajo, historiales y agrupaciones en memoria.

Conceptos clave

  • Los índices empiezan en 0; los negativos cuentan desde el final.
  • El slicing lista[inicio:fin:paso] devuelve una copia parcial.
  • sorted() ordena sin mutar; .sort() ordena en el lugar.
  • append, extend, insert, remove y pop editan la lista.
  • Las comprensiones [exp for x in it if cond] construyen listas nuevas.

Ejemplo básico

Slicing y operaciones básicas sobre una lista de nombres.

ana
pedro
['luis', 'carla']
['ana', 'carla']
['ana', 'carla', 'luis', 'pedro', 'sofia']

Ordenar un listado de usuarios por un campo y filtrar con comprensión.

Ejemplo real

Paginación en memoria de una lista grande de resultados antes de devolverla en una API.

  • Un slice para paginar de (pagina-1)*limite a pagina*limite.
  • Una comprensión para mapear o filtrar los items.
  • El dict de respuesta incluye total, pagina y limite.

En producción la paginación suele caer en la base de datos (LIMIT/OFFSET), pero este patrón vale para listas en memoria y cachés.

Explicación

  • El slicing no modifica la lista original: crea una copia.
  • .sort() altera el estado original; sorted() lo respeta.
  • Las comprensiones son más rápidas y legibles que un for + append.
  • key recibe una función; lambda permite claves rápidas sin definir función aparte.

Errores comunes

  • IndexError al acceder a un índice fuera de rango.
  • Modificar una lista mientras se itera provoca saltos; itera sobre una copia.
  • Ordenar una lista mixta de tipos lanza TypeError en la comparación.

Buenas prácticas

  • Usa sorted() cuando quieras mantener la lista original intacta.
  • Define claves con nombres en lugar de lambdas si se repiten.
  • Usa .copy() o [:] para evitar aliasing involuntario.
  • Para colas FIFO usa collections.deque, no list.pop(0).

Ejercicio

  1. Toma una lista de temperaturas y quédate con las mayores a 20 con una comprensión.
  2. Ordena una lista de dicts de productos por precio descendente.
  3. Implementa paginar() y prueba bordes como pagina=0.

Resumen

  • Slicing y métodos construyen y transforman listas en una línea.
  • sorted() con key y reverse ordena estructuras complejas.
  • Las comprensiones condensan filtro y transformación.
