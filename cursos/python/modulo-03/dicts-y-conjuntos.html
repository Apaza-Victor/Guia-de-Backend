Dicts y conjuntos

💻 Básico 10 min Python para Backend Módulo 3 · Estructuras de datos y módulos

Qué es un dict

Un diccionario (dict) guarda pares clave → valor. Se escribe entre llaves {} y mantiene el orden de inserción desde Python 3.7. En backend es la representación natural de un documento JSON: campos con nombre, sin posición fija.

clave["x"] lanza KeyError si no existe; .get() devuelve un valor por defecto. Elegir uno u otro es una decisión consciente: el primero dice "esto debe estar"; el segundo "esto es opcional".

Operaciones habituales

  • Agregar/actualizar: usuario["ciudad"] = "Lima".
  • Eliminar: usuario.pop("roles") o del usuario["roles"].
  • Comprobar clave: "id" in usuario.
  • Recorrer: for clave, valor in usuario.items().
  • Obtener llaves, valores o pares: usuario.keys(), usuario.values(), usuario.items().

Qué es un conjunto (set)

Un conjunto es una colección de elementos únicos y sin orden. Se escribe con {valores} (ojo: {} vacío crea un dict, no un set; para un set vacío usa set()).

  • | unión, & intersección, - diferencia, ^ diferencia simétrica.
  • <= subconjunto, < subconjunto propio.
  • Elementos cadena, número o tupla: todo lo inmutable; nunca una lista.

  3. Define un set de IPs en lista negra y comprueba tres IPs de ejemplo con un solo in.
  4. Calcula qué métodos HTTP faltan para completar todos los de la lista.

Resumen

  • Los dicts mapean claves a valores y se parecen a los objetos JSON.
  • dict.get con default evita KeyError para claves opcionales.
  • Los sets guardan únicos e implementan álgebra de conjuntos.
  • Conjuntos: O(1) para pertenencia, ideal para validar verbos o listas negras.
  • Elementos de set o clave de dict deben ser inmutables.
