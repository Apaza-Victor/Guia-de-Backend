Python para Backend

Python aplicado al backend: sintaxis, POO, virtualenv, Flask y FastAPI para construir APIs modernas y rápidas.

8 semanas 7 módulos · 33 lecciones Python · Flask · FastAPI

¿Qué vas a aprender?

Python es uno de los lenguajes más usados en el backend por su claridad y su enorme ecosistema de bibliotecas. En este curso lo llevarás desde cero hasta la creación de APIs modernas: primero la sintaxis, las colecciones y la programación orientada a objetos, luego los entornos virtuales y las dependencias con pip. Al final construirás aplicaciones web con Flask y APIs rápidas, tipadas y autodocumentadas con FastAPI.

Objetivos de aprendizaje

✔Leer y escribir Python con soltura: tipos, colecciones y funciones.
✔Aplicar POO y manejo de excepciones en código real.
✔Gestionar entornos y dependencias con venv y pip.
✔Construir aplicaciones web con Flask: rutas, formularios y sesiones.
✔Crear APIs rápidas y documentadas con FastAPI y Pydantic.

Requisitos previos

  • Fundamentos de Backend: conocer HTTP, cliente-servidor y request/response.
  • Programación para Backend: lógica, funciones y estructuras de datos.
  • Ganas de practicar: Python es fácil de leer, pero se domina escribiendo.

Tecnologías y herramientas

Python Flask FastAPI Pydantic venv pip

Módulos del curso

Siete módulos que van del intérprete a la API en producción: el lenguaje, los objetos, los entornos y dos frameworks modernos.

1. Introducción a Python

Instala Python, usa el intérprete y la consola interactiva, y domina variables y tipos.

5 lecciones≈ 42 min
  • Instalando Python y el intérprete
  • Tu primer script y la consola interactiva
  • Variables, constantes y tipos de datos
  • Entrada y salida de datos
  • Comentarios y documentos con docstrings

2. Control de flujo y funciones

Condicionales, bucles y funciones, con énfasis en las colecciones y la legibilidad de Python.

5 lecciones≈ 48 min
  • Condicionales: if, elif y else
  • Bucles: for y while
  • Funciones: argumentos y retorno
  • Listas y tuplas en acción
  • Comprensión de listas

3. Estructuras de datos y módulos

Diccionarios, conjuntos, paquetes y la forma Python de organizar grandes programas.

5 lecciones≈ 50 min
  • Diccionarios y operaciones clave-valor
  • Conjuntos y operaciones de teoría
  • Módulos y paquetes
  • Importando código externo
  • map, filter y funciones lambda

4. Programación Orientada a Objetos

Clases, atributos, métodos mágicos, herencia y excepciones para código sólido.

5 lecciones≈ 55 min
  • Clases y objetos
  • Atributos, métodos y self
  • Métodos mágicos: str, repr y comparaciones
  • Herencia y polimorfismo
  • Excepciones y manejo de errores

5. Entorno y dependencias

Aísla tus proyectos con entornos virtuales y gestiona dependencias como un profesional.

4 lecciones≈ 40 min
  • Por qué usar entornos virtuales
  • venv y virtualenv en la práctica
  • pip y archivos requirements
  • Instalando y actualizando paquetes

6. Flask

Tu primera aplicación web en Python: rutas, plantillas, formularios, sesiones y bases de datos.

5 lecciones≈ 55 min
  • Introducción a Flask
  • Rutas y métodos HTTP
  • Templates con Jinja2
  • Formularios y validación
  • Sesiones y conexión a base de datos

7. FastAPI

APIs modernas con tipado: endpoints, validación con Pydantic, asincronía y documentación automática.

4 lecciones≈ 50 min
  • Introducción a FastAPI y el tipado
  • Endpoints y status codes
  • Validación de datos con Pydantic
  • Async/await y documentación automática
