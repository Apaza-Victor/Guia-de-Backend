Introducción a FastAPI

🔥 Avanzado 12 min Python para Backend Módulo 7 · APIs con FastAPI

Introducción

FastAPI es el framework moderno de Python para APIs: construido sobre la base ASGI, con validación con Pydantic y documentación OpenAPI automática.

Su marca distintiva: anotaciones de tipos y endpoints en minutos, con docs interactivas en /docs.

Definición

FastAPI construye la API declarando funciones con parámetros tipados; uvicorn es el servidor ASGI que la ejecuta; Pydantic valida los modelos.

Por qué importa. Al tipar parámetros obtienes validación, documentación y autocompletado sin escribir código extra: la productividad que un backend moderno exige.

Cuándo usarlo. Elige FastAPI para APIs nuevas, microservicios y proyectos donde el tipado y la documentación automática ahorren mantenimiento.

Conceptos clave

  • pip install fastapi uvicorn[standard].
  • from fastapi import FastAPI; app = FastAPI().
  • @app.get("/") convierte la función en endpoint.
  • Los parámetros tipados en la firma se convierten en query params.
  • uvicorn app:app --reload levanta el servidor con recarga.

Ejemplo básico

Instalar el stack y arrancar uvicorn desde la terminal.

Ejemplo intermedio

El endpoint más simple y uno que usa query params tipados.

Ejemplo real

Probar los endpoints y descubrir la documentación interactiva generada al instante.

  • /docs ofrece Swagger UI para probar sin curl.
  • /redoc ofrece la versión alternativa de documentación.
  • Los query params tipados aparecen en la documentación automática.

FastAPI detecta los tipos en la firma y genera el schema OpenAPI completo de tu API sin configurar nada.

Explicación

  • El servidor ASGI (uvicorn) ejecuta la aplicación app que vive en el archivo main.py.
  • Los query params tipados se declaran como argumentos de la función.
  • Un tipado int obliga a FastAPI a rechazar textos no numéricos con 422.
  • @app.get() crea el mapeo de verbo y ruta.
  • --reload reinicia el servidor ante cada guardado, solo en desarrollo.

Errores comunes

  • ModuleNotFoundError: No module named 'fastapi' por instalar en el venv equivocado.
  • uvicorn main:app no encuentra app si tu archivo no la llama así o la ruta está mal.
  • 422 Unprocessable Entity cuando el tipo de un parámetro no coincide.

Buenas prácticas

  • Usa venv e instala con fastapi[standard] para incluir herramientas útiles.
  • Desactiva --reload en producción.
  • Nombra tu aplicación app para el patrón uvicorn main:app sin pelear.
  • Empieza probando en /docs antes de escribir tests.

Ejercicio

  1. Crea un endpoint /version que devuelva version y autor.
  2. Agrega /suma?x=2&y=3 con enteros tipados y devuelve el resultado.
  3. Abre /docs y prueba tus dos endpoints ahí.

Resumen

  • FastAPI + uvicorn levantan una API tipada en segundos.
  • Los parámetros de función tipados son query params validados.
  • /docs documenta y permite probar la API al instante.
