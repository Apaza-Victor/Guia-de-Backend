Bucles: for y while

💻 Básico 10 min Python para Backend Módulo 2 · Control de flujo y funciones

Introducción

Los bucles te permiten repetir una operación sobre muchos datos: recorrer una lista de pedidos, leer líneas de un log o construir una respuesta agregada.

Python ofrece dos: for, perfecto para recorrer colecciones, y while, para repetir mientras se cumpla una condición.

Definición

for itera sobre cada elemento de una secuencia (lista, tupla, string, dict). while repite el bloque mientras su condición siga siendo verdadera.

Por qué importa. El backend procesa colecciones constantemente: usuarios en memoria, filas de una tabla, eventos de un log. Un bucle bien escrito sustituye cientos de líneas repetidas.

Cuándo usarlo. Usa for para recorrer algo conocido; usa while cuando no sabes cuántas iteraciones harán falta: colas, reintentos, encuestas.

Conceptos clave

  • range(n) genera números de 0 a n-1 para iterar.
  • enumerate(coleccion) entrega índice y elemento a la vez.
  • break corta el bucle; continue salta a la siguiente iteración.
  • Una comprensión de lista es un for condensado que devuelve una lista nueva.
  • Los diccionarios se recorren con .items() para obtener clave y valor.

Ejemplo básico

Recorrer una lista de usuarios y construir una lista filtrada con comprensión.

1. ana
2. luis
3. carla
[0, 2, 4, 6, 8]

Ejemplo intermedio

Filtrar registros mientras recorremos un dataset con for y acumular totales.

Ejemplo real

Un caso típico en backend: leer un log línea a línea y quedarte solo con los errores críticos.

  • Procesa con streams en lugar de cargar todo a memoria.
  • Usa break para detenerte al encontrar lo buscado.
  • Combina con análisis de cadenas para extraer campos.

El operador := (walrus) asigna y evalúa en la misma línea; es una joya moderna de Python 3.8+.

Explicación

  • for recorre elementos; range solo produce números para controlar recorridos numéricos.
  • Los bucles se detienen con break y se saltan elementos con continue.
  • Un else tras un for se ejecuta si el bucle terminó sin break; útil en búsquedas.
  • Las comprensiones de lista son más rápidas y legibles para filtrar y transformar.

Errores comunes

  • Olvidar la indentación del cuerpo del bucle.
  • Incrementar manualmente una variable en un for en vez de recorrer la colección.
  • Crear un while infinito al no cambiar la condición dentro del bloque.

Buenas prácticas

  • Prefiere for sobre while cuando recorres colecciones conocidas.
  • Usa enumerate en lugar de indexar con range(len(...)).
  • Procesa archivos con with y línea a línea para no agotar memoria.
  • Nombra el iterador de forma significativa: for pedido in pedidos.

Ejercicio

  1. Suma los totales de una lista de dicts con un for.
  2. Genera la lista de ids impares con una comprensión.
  3. Lee un archivo y cuenta las líneas vacías con un while.

Resumen

  • for recorre colecciones y while repite hasta cumplir una condición.
  • break y continue controlan el flujo de la iteración.
  • Las comprensiones condensan la transformación y el filtrado.
