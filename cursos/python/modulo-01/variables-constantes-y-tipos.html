Variables, constantes y tipos de datos

💻 Básico 10 min Python para Backend Módulo 1 · Introducción a Python

Qué es una variable

Una variable es un nombre que apunta a un valor que vive en memoria. En Python no declaras el tipo: el intérprete lo determina solo cuando asignas. Por eso se dice que Python tiene tipado dinámico.

La asignación con = lee el valor de la derecha, lo guarda en memoria de trabajo y enlaza el nombre de la izquierda a ese objeto.

Los tipos básicos

  • int: enteros sin límite práctico (255, -10, 10**100).
  • float: números decimales de coma flotante (3.14, 1e9).
  • complex: números complejos (2+3j).
  • str: cadenas de texto con comillas simples o dobles.
  • bool: solo True o False.
  • NoneType: el valor None, usado para "sin valor".

type() es tu herramienta de diagnóstico: si algo no se comporta como esperas, lo primero es preguntar qué tipo tiene.

¿Y las constantes?

Python no tiene constantes verdaderas. La convención es nombrarlas todo en mayúsculas: cualquiera que lea el código entenderá "esto no debe cambiarse", aunque técnicamente el lenguaje no lo prohíbe.

Poner los valores de configuración como constantes al inicio del módulo facilita encontrarlas y cambiarlas sin tocar la lógica.

Buenas prácticas al nombrar

  • Usa snake_case: palabras en minúscula separadas por guion bajo: max_intentos.
  • Elige nombres descriptivos: tiempo_maximo_ms mejor que t.
  • No uses palabras reservadas (class, for, print mejor evítala como nombre).
  • En español es válido y común en equipos hispanos, pero sé consistente.

Ejercicio

  1. Declara variables para: nombre de usuario, id de usuario, saldo y si la cuenta está activa.
  2. Imprime el tipo de cada una con type().
  3. Crea tres constantes de configuración simulando tiempos de espera.
  4. Responde: ¿qué pasa si asignas un texto a una variable que antes tenía un número?

Resumen

  • Las variables unen un nombre con un valor; no tienen tipo fijo.
  • Los tipos base: int, float, str, bool y NoneType.
  • type() revela el tipo de cualquier valor.
  • Las "constantes" son convención: nombres en MAYÚSCULAS.
  • Nombres descriptivos en snake_case hacen tu código legible.
