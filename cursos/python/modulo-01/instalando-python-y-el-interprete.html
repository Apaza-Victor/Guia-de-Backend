Instalando Python y el intérprete

💻 Básico 8 min Python para Backend Módulo 1 · Introducción a Python

Qué es Python y por qué para Backend

Python es un lenguaje interpretado, multiplataforma y con una sintaxis pensada para leerse como inglés. En Backend destaca porque los frameworks web más populares —django y FastAPI— se escriben en Python, igual que buena parte de la industria de datos y de la inteligencia artificial.

Aquí hubo un cambio de mentalidad importante: ya no compilas. Escribes código, lo guardas en un archivo .py y se lo entregas a un intérprete que lee, valida y ejecuta instrucción por instrucción.

Descargar el intérprete

La fuente oficial es python.org. Baja la última versión estable de la rama 3.x (evita las versiones antiguas 2.x, retiradas desde 2020).

Windows

  1. Descarga el instalador .exe desde python.org.
  2. Marca la casilla "Add Python to PATH" antes de instalar: te evitará dolores de cabeza después.
  3. Pulsa Install Now y termina el asistente.

Si olvidas marcar "Add Python to PATH", el comando python no se reconocerá en la terminal. Puedes repararlo reinstalando y marcando la casilla.

Eso es la consola interactiva (REPL, Read-Eval-Print-Loop): lee una línea, la evalúa y te devuelve el resultado al momento. Es perfecta para experimentar.

Qué hace el intérprete al ejecutar

Cuando ejecutas un script, Python recorre este camino:

  1. Lee el archivo fuente y comprueba la sintaxis línea por línea.
  2. Compila internamente a "bytecode" (no lo ves, está en memoria o en la carpeta __pycache__).
  3. Ejecuta las instrucciones con la máquina virtual de Python.
  4. Detecta errores y los reporta con la famosa traceback: dónde falló y por qué.

Esta separación entre "compilar a bytecode" y "ejecutar" es lo que hace que Python funcione igual en Windows, macOS y Linux: la portabilidad vive en ese paso intermedio.

Errores típicos al instalar

  • "python no se reconoce": problema de PATH, sobre todo en Windows tras olvidar la casilla.
  • "Command 'python' not found": en Linux el binario se llama python3.
  • Dos versiones instaladas: usa py -0p en Windows para distinguirlas y elegir con py -3.12.
  • pip no instalado: casi siempre viene incluido; si no, ejecuta python -m ensurepip.

Ejercicio

  1. Instala Python en tu sistema por el método de tu plataforma.
  2. Comprueba la versión con py --version (Windows) o python3 --version (Linux/macOS).
  3. Entra a la consola interactiva y calcula 15 * 3 - 4 sin escribirlo en ningún archivo.
  4. Identifica los dos binarios de Python que envía tu sistema (si aplica) con py -0p.

Resumen

  • Python es interpretado y su intérprete se obtiene desde python.org o el gestor de tu SO.
  • En Windows, py es el acceso recomendado desde PowerShell.
  • El intérprete lee, compila a bytecode y ejecuta; los errores llegan como tracebacks.
  • Marca "Add Python to PATH" para evitar problemas de arranque.
  • La consola interactiva (REPL) es ideal para probar expresiones al instante.
