Entrada y salida de datos

💻 Básico 8 min Python para Backend Módulo 1 · Introducción a Python

Leer datos del usuario con input()

La función input() pausa el programa, muestra un mensaje opcional y devuelve todo lo que escribiste como texto (str). Recuerda lo importante: siempre devuelve un str, aunque escribas números.

Cuando ejecutas python saludo.py, el programa se detiene en la línea del input() hasta que escribas y pulses Enter.

Formatos de salida con print()

Más allá de encadenar con comas, Python moderno prefiere las f-strings: pon una f antes de la cadena e inserta variables dentro de llaves.

Dos parámetros útiles más: sep elige el separador entre valores (por defecto espacio) y end qué escribir al final (por defecto salto de línea).

Ejercicio

  1. Pide nombre y edad; saluda con una f-string.
  2. Pide dos números, conviértelos y muestra su suma.
  3. Muestra un precio con dos decimales y signo de moneda.
  4. Responde: ¿qué error esperas si escribes "veinte" como edad?

Resumen

  • input() siempre devuelve texto.
  • Convierte con int() y float() antes de operar.
  • Las f-strings interpulan variables con {}.
  • sep y end afinan el formato de print().
  • Entrada de texto + conversión = la base de formularios y APIs.
