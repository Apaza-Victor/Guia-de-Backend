Tu primer script y la consola interactiva

💻 Básico 8 min Python para Backend Módulo 1 · Introducción a Python

Crea tu primer archivo

En una carpeta de trabajo, crea un archivo llamado hola.py. El editor de texto plano que uses da igual (VS Code, Notepad++, Vim…); la clave es que guardes con codificación UTF-8, porque por defecto Python 3 la usa para leer el código fuente.

print() es de las primeras funciones que usarás siempre: manda texto a la salida estándar (la terminal). Los paréntesis son obligatorios en Python 3, a diferencia de Python 2, donde podían (erróneamente) omitirse.

Ejecútalo desde la terminal

Navega hasta la carpeta del archivo y ejecuta:

El intérprete lee el archivo completo, lo compila a bytecode en memoria y lo ejecuta. Si hay un error de sintaxis, te lo dirá con un traceback sin ejecutar nada de lo que viene después de la línea conflictiva.

La consola interactiva (REPL)

Escribe python (o py) sin argumentos y entrarás al REPL: Read, Eval, Print, Loop. Cada línea que escribes se evalúa al instante y te muestra el resultado, perfecto para hacer experimentos rápidos.

  • El prompt >>> espera una instrucción nueva.
  • El prompt ... aparece cuando una instrucción quedó a medias (p. ej. un paréntesis abierto o un bloque con dos puntos).
  • Para salir escribe exit() o pulsa Ctrl+Z + Enter en Windows.

¿REPL o script?

Usa el REPL cuando quieras probar una expresión suelta, explorar una librería o hacer cuentas rápidas. Usa un archivo .py cuando el código vaya a repetirse, a crecer o a ejecutarse muchas veces: los scripts se guardan, se revisan y se comparten.

En backend casi todo vive en archivos: handlers, modelos, tests. El REPL queda para inspección rápida y debugging puntual.

Ejercicio

  1. Crea saludo.py que imprima tu nombre y la fecha actual (pista: import datetime).
  2. Ejecútalo por terminal y anota el traceback si cometes un error a propósito.
  3. Entra al REPL, multiplica 7 * 6 y calcula 2 ** 10; sal con exit().
  4. Explica con tus palabras la diferencia entre REPL y script.

Resumen

  • Un script es un archivo .py que Python ejecuta de punta a punta.
  • print() escribe en la salida estándar.
  • El REPL evalúa línea a línea al instante.
  • >>> pide instrucciones; ... indica que estás a mitad de una.
  • Script para proyecto, REPL para experimentar.
