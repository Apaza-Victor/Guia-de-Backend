💻 Básico

Módulo 1 · Introducción a Python

Instala el intérprete, ejecuta tus primeros programas y domina variables, tipos, entrada/salida y comentarios.

5 lecciones ≈ 42 min Nivel básico

Objetivos del módulo

✔Instalar Python y comprobar que el comando python funciona en tu terminal.
✔Crear y ejecutar tu primer script: del archivo al resultado en consola.
✔Declarar variables y entender los tipos de datos con type().
✔Leer datos del usuario con input() y mostrarlos formateados con print().
✔Documentar tu código con comentarios y docstrings según PEP 8.

Lecciones

1 · Instalando Python y el intérprete

Descarga el instalador, verifica python --version y entiende qué es el intérprete.

8 mininstalación

2 · Tu primer script y la consola interactiva

Crea archivos .py, ejecútalos y distingue el REPL de un programa.

8 minprimeros pasos

3 · Variables, constantes y tipos

Nombres válidos, asignación dinámica, números, cadenas y type().

10 minvariables

4 · Entrada y salida de datos

Lee datos con input(), conviértelos y dale formato a print().

8 minI/O

5 · Comentarios y docstrings

Documenta tu código con #, comillas triples y docstrings según PEP 8.

8 minbuenas prácticas
