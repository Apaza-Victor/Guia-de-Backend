Tablas, registros y columnas

🌱 Principiante 9 min Bases de Datos Módulo 1 · Fundamentos

Introducción

En el modelo relacional toda la información vive dentro de tablas. Una tabla es una estructura de dos dimensiones: columnas que definen qué tipo de dato se guarda, y filas (registros) que guardan cada dato concreto. Es exactamente el mismo concepto visual de Excel, pero con reglas más estrictas.

Estas tres palabras —tabla, columna, registro— son el vocabulario del 90% de las conversaciones sobre bases de datos.

Las tres piezas

  • Tabla: el contenedor que agrupa una misma clase de información (clientes, productos, pedidos). Su nombre suele ir en plural.
  • Columna (campo): un atributo común a todos los registros. Cada columna tiene un nombre y un tipo de dato: texto, número, fecha, booleano.
  • Registro (fila): un dato concreto, una instancia. Por ejemplo, «el cliente número 7» es un registro con valores para cada columna.

La regla de oro: todas las filas de una tabla comparten las mismas columnas, y todas las columnas de una fila describen la misma entidad.

Tipos de datos comunes

Elegir el tipo correcto es parte del diseño profesional. Los más habituales en SQL son:

  • INT / BIGINT: números enteros (edades, cantidades, identificadores).
  • DECIMAL: números con decimales (precios, totales).
  • VARCHAR(n): texto de longitud variable (nombres, emails).
  • TEXT: texto largo (descripciones, contenido).
  • DATE / DATETIME / TIMESTAMP: fechas y horas.
  • BOOLEAN: verdadero o falso (MySQL usa TINYINT(1) internamente).

Definir los tipos evita errores clásicos como guardar un precio como texto y no poder hacer sumas.

Ejercicio

  1. Diseña la tabla pedidos de una tienda: piensa en 5 columnas y su tipo de dato correcto.
  2. Agrega 3 registros de ejemplo; escribe qué es cada fila.
  3. Escribe un CREATE TABLE para tu tabla de pedidos (puedes copiar la base del ejemplo).

Resumen

  • Una tabla agrupa una misma clase de información.
  • Las columnas definen los atributos y sus tipos de dato.
  • Los registros son cada fila: un dato concreto.
  • Los tipos de dato correctos protegen la calidad de la información.
  • CREATE TABLE define estructura y reglas desde el principio.
