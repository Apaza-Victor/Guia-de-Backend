Consultas SELECT y filtros WHERE

🌱 Principiante 10 min Bases de Datos Módulo 3 · SQL básico

Introducción

SELECT es la instrucción que más escribirás en tu vida como desarrollador: sirve para leer datos. Su forma general es SELECT columnas FROM tabla WHERE condición, y con ella respondes «¿qué datos… de dónde… en qué condiciones?».

SELECT: elegir columnas

Consejo profesional: en código de aplicación evita SELECT *. Si la tabla cambia, tu programa recibe columnas que no esperaba y se rompen los índices de los arrays. Selecciona lo que necesitas.

WHERE: el filtro

Los operadores comparativos: =, <> (distinto), >, <, >=, <=. Para comparar con NULL no se usa =, sino IS NULL / IS NOT NULL.

Operadores lógicos y de conjuntos

Preparando el terreno

El filtrado define qué filas se usan. El orden de las cláusulas importa: WHERE va después de FROM y antes de ORDER BY. En la siguiente lección completarás el conjunto con ORDER BY y LIMIT.

Ejercicio

  1. Escribe un SELECT que devuelva los productos de la categoría «libros» con precio entre 10 y 50.
  2. Devuelve los clientes cuyo nombre empiece por «A» y estén activos.
  3. Escribe una consulta con NOT IN para excluir tres ciudades de un listado.

Resumen

  • SELECT define qué columnas leer; evita SELECT * en producción.
  • WHERE filtra filas con comparadores y lógicos.
  • IN, BETWEEN, LIKE y IS NULL amplían las condiciones.
  • El orden de las cláusulas importa (FROM, WHERE, ORDER BY).
  • Practicar SELECT es la base de toda consulta avanzada.
