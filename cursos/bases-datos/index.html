Bases de Datos

Modelado, normalización, índices, transacciones y las bases de datos relacionales y NoSQL que usa el backend real.

8 semanas 7 módulos · 33 lecciones SQL · MySQL · PostgreSQL · MongoDB

¿Qué vas a aprender?

Toda aplicación respalda su información en una base de datos, y saber modelarla bien marca la diferencia en cualquier backend. Aquí aprenderás de forma práctica cómo diseñar esquemas, normalizar datos, usar transacciones y decidir entre bases relacionales y NoSQL. Trabajarás con MySQL, PostgreSQL y MongoDB, los motores más usados en producción, con ejercicios reales en cada lección.

Objetivos de aprendizaje

✔Entender qué es una base de datos, sus tipos y cuándo usar cada uno.
✔Modelar datos con el modelo entidad-relación y la normalización.
✔Crear y consultar tablas con SQL básico y relaciones.
✔Aplicar transacciones, índices y buenas prácticas de concurrencia.
✔Conocer MySQL, PostgreSQL y MongoDB en escenarios reales.

Requisitos previos

  • Programación para Backend: lógica de programación y manejo de variables.
  • Un editor de código y ganas de practicar con ejemplos reales.
  • No se necesita experiencia previa con bases de datos.

Tecnologías y herramientas

SQL MySQL PostgreSQL MongoDB Índices ACID

Módulos del curso

Siete módulos para entender las bases de datos desde los cimientos: modelado, SQL, transacciones y los motores del mundo real.

1. Fundamentos

Qué es una base de datos, qué papel cumple en el backend y cómo se organiza la información en tablas.

5 lecciones≈ 42 min
  • ¿Qué es una base de datos?
  • SGBD: sistemas de gestión de bases de datos
  • Tablas, registros y columnas
  • Claves primarias y foráneas
  • El papel de la base de datos en una aplicación

2. Modelado y diseño

Diseña esquemas que resistan el paso del tiempo: entidades, relaciones y normalización.

5 lecciones≈ 52 min
  • Modelo entidad-relación
  • Dibujando diagramas entidad-relación
  • Cardinalidad de las relaciones
  • Primera y segunda forma normal
  • Tercera forma normal y desnormalización

3. SQL básico

El lenguaje de todas las bases relacionales: crear, leer, actualizar y borrar datos.

5 lecciones≈ 48 min
  • Creando tablas con CREATE TABLE
  • Insertando y modificando datos
  • Consultas SELECT y filtros WHERE
  • Ordenando y limitando resultados
  • Borrado seguro con DELETE

4. Relaciones y consultas

Une tablas con JOINs, agrupa resultados y acelera las búsquedas con índices.

5 lecciones≈ 55 min
  • Relaciones uno a muchos y muchos a muchos
  • JOINs: inner, left y right
  • Subconsultas básicas
  • Agrupación con GROUP BY
  • Índices y rendimiento

5. Transacciones y concurrencia

La propiedad ACID: transacciones, bloqueos y niveles de aislamiento para datos consistentes.

4 lecciones≈ 45 min
  • Propiedades ACID
  • Transacciones: BEGIN, COMMIT y ROLLBACK
  • Bloqueos y concurrencia
  • Niveles de aislamiento

6. MySQL y PostgreSQL

Instala, configura y administra los dos motores relacionales más usados del ecosistema.

5 lecciones≈ 52 min
  • Instalando MySQL
  • Usuarios, permisos y respaldos
  • Instalando PostgreSQL
  • Diferencias prácticas entre MySQL y PostgreSQL
  • Backups y restauración

7. NoSQL

MongoDB: documentos, colecciones y cuándo el modelo relacional no es la mejor opción.

4 lecciones≈ 42 min
  • ¿Qué es NoSQL y por qué existe?
  • MongoDB: documentos y colecciones
  • CRUD básico en MongoDB
  • ¿Relacional o NoSQL? Cómo decidir
