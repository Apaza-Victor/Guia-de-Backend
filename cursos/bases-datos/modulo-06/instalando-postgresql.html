Instalando PostgreSQL

🌱 Principiante 10 min Bases de Datos Módulo 6 · MySQL y PostgreSQL

Introducción

PostgreSQL es el motor relacional de referencia por sus funciones: JSONB, funciones de ventana, tipos avanzados y un optimizador excelente. En esta lección lo instalas y aprendes su modelo de seguridad, basado en roles en lugar de usuarios.

Instalación en Windows

  1. Descarga el instalador desde postgresql.org/download.
  2. Elige la versión actualizada y sigue el asistente.
  3. Define el puerto estándar 5432 y una contraseña para postgres.
  4. Acepta instalar también pgAdmin 4: la GUI oficial para administrar.
  5. Al final tendrás el servicio postgresql-x64-17 corriendo.

Primer acceso con psql

Roles, lo equivalente a usuarios

En PostgreSQL un rol puede ser «usuario», «grupo» o ambas cosas. CREATE ROLE define uno nuevo y CREATE DATABASE reserva su espacio:

Verificar la instalación

Los comandos psql empiezan con contrabarra (\du, \l) y los SQL terminan en punto y coma. Cuando ambos te respondan, tu PostgreSQL está listo para el siguiente módulo.

Ejercicio

  1. Instala PostgreSQL y conéctate con psql.
  2. Crea un rol de aplicación y una base de datos con el comando CREATE DATABASE.
  3. Consulta \du para ver tus roles y \l para tus bases.

Resumen

  • PostgreSQL usa roles en lugar de usuarios.
  • El superusuario por defecto es postgres.
  • psql es la línea de comandos; pgAdmin 4, la GUI.
  • PGPASSWORD permite conexiones no interactivas.
  • CREATE DATABASE OWNER vincula la base a tu rol.
