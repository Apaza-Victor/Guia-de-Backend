Instalando MySQL

🌱 Principiante 10 min Bases de Datos Módulo 6 · MySQL y PostgreSQL

Introducción

Empieza por el motor más usado del ecosistema: MySQL. En esta lección lo instalas en local, lo levantas como servicio y te conectas por línea de comandos por primera vez. Al final tendrás un servidor real donde practicar todo lo aprendido.

Instalación en Windows

  1. Descarga el MySQL Community Server desde la web oficial de MySQL (dev.mysql.com/downloads).
  2. Ejecuta el instalador y elige Developer Default (incluye MySQL Workbench y el shell).
  3. En Type and Networking deja el puerto estándar 3306.
  4. Configura una contraseña fuerte para el usuario root.
  5. En Windows Service marca «Start at System Startup» y termina la instalación.

Con el servicio instalado, MySQL arranca solo con Windows. Puedes controlarlo desde Services o desde PowerShell (también sirve para Linux/macOS):

Opciones de cliente

  • mysql CLI: para scripts y trabajo rápido en terminal.
  • MySQL Workbench: GUI con editor visual, diagramas ER y herramientas de administración.
  • Herramientas de tu lenguaje: desde Node, Python o Java te conectarás con «drivers» (pronto lo harás en el curso de APIs).

Ejercicio

  1. Instala MySQL en tu equipo y registra las opciones con las que lo configuraste.
  2. Conéctate por consola, ejecuta SHOW DATABASES y SELECT VERSION().
  3. Anota el puerto, el nombre del servicio y cómo lo reiniciarías.

Resumen

  • MySQL Server se instala como servicio y escucha en el puerto 3306.
  • El primer acceso usa el usuario root y tu contraseña.
  • El shell mysql -u root -p es tu puerta de entrada.
  • Workbench ofrece un entorno gráfico cómodo.
  • Tenerlo local te permite practicar cada lección del curso.
