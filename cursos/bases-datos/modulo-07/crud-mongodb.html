CRUD en MongoDB

🌱 Principiante 11 min Bases de Datos Módulo 7 · NoSQL

Introducción

Es hora de tocar datos de verdad. El shell de MongoDB (mongosh) usa una API basada en «métodos» que recuerda mucho a JavaScript: insertOne, find, updateOne y deleteOne.

Create: insertOne e insertMany

Read: find y filtros

Operadores frecuentes: $lt, $gt, $lte, $gte, $ne, $in, $nin… El paralelo con SQL es directo: WHERE stock < 10 → { stock: { $lt: 10 } }.

Update: updateOne, updateMany

Delete: deleteOne, deleteMany

Consejos de uso

  • Filtra siempre por índice en producción (igual que en SQL).
  • Usa sort({ campo: -1 }).limit(n) para «ordenar y limitar».
  • Transacciones multi-documento existen: no reimplementes ACID a mano.
  • Prueba todo en una base de desarrollo antes de tocar la real.

Ejercicio

  1. Inserta 5 productos en la base tienda.
  2. Consulta los que cuestan menos de 50 y los que tienen stock menor a 5.
  3. Incrementa el precio un 10% a todos con updateMany y verifica el resultado.

Resumen

  • insertOne/insertMany crean documentos.
  • find con filtros y operadores $ lee datos.
  • update con $set/$inc modifica sin reemplazar.
  • deleteOne/deleteMany eliminan con cuidado.
  • El CRUD en MongoDB se parece mucho a SQL con otra sintaxis.
