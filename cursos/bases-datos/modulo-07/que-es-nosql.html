¿Qué es NoSQL?

🌱 Principiante 11 min Bases de Datos Módulo 7 · NoSQL

Introducción

NoSQL no significa «sin SQL» ni «sin bases de datos»: significa «No Solo SQL» (Not Only SQL). Es una familia de bases que sacrifican parte del modelo relacional para ganar escalabilidad horizontal, flexibilidad de esquema y velocidad en casos concretos.

Las cuatro grandes familias

  • Clave-valor: la más simple y veloz. Redis, Memcached. Ideal para cachés y sesiones.
  • Documentos: guarda JSON; el formato favorito del backend moderno. MongoDB, CouchDB.
  • Columnas: optimizada para datos masivos y analítica. Cassandra, Bigtable.
  • Grafos: relaciones explícitas entre nodos. Neo4j. Ideal en social, recomendaciones.

Qué aportan en el backend

  • Escalabilidad horizontal: añadir más servidores para crecer (sharding).
  • Esquema flexible: evitas migraciones de esquema al cambiar la app.
  • Modelo cercano al código: el documento se parece al objeto de tu API.
  • Despliegue rápido: sin diseño previo de tablas ni JOINs.

A cambio de...

  • Menos garantías ACID (aunque MongoDB ya ofrece transacciones multi-documento).
  • Consistencia eventual en ciertos motores.
  • JOINs manuales: el modelado de datos es tu responsabilidad.
  • Un estándar de consulta menos universal que SQL.

Cuándo aparece en un proyecto real

Patrón habitual: una aplicación usa PostgreSQL para lo transaccional (pedidos, pagos) y Redis para caché y MongoDB para catálogos o JSON variables. NoSQL no reemplaza a SQL: convive con él.

Ejercicio

  1. Clasifica estas necesidades en la familia adecuada: (a) contador de visitas, (b) catálogo de productos con atributos variables, (c) frijoles de amigos de usuarios.
  2. Busca un caso real de cada base mencionada en esta lección.
  3. Explica por qué «NoSQL» no significa «sin SQL».

Resumen

  • NoSQL = Not Only SQL; una familia, no una ausencia.
  • Cuatro familias: clave-valor, documentos, columnas y grafos.
  • Gana flexibilidad y escala; paga consistentia y estándares.
  • El backend real combina motores: transaccional + caché + docs.
