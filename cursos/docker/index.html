🐳 Docker para Backend

Aprende a crear contenedores, imágenes y orquestar servicios con Docker Compose. Containeriza tus aplicaciones Backend para que funcionen igual en desarrollo y en producción.

5 semanas 6 módulos · 50 lecciones Docker · Contenedores · DevOps

¿Qué vas a aprender?

Docker revolucionó la forma en que se despliegan las aplicaciones. En este curso aprenderás a crear contenedores ligeros, definir imágenes reproducibles con Dockerfiles, gestionar datos con volúmenes, conectar servicios con redes y orquestar todo con Docker Compose. Al final, sabrás containerizar cualquier aplicación Backend para que funcione igual en tu máquina y en el servidor.

Objetivos del curso

✔Entender qué son los contenedores y por qué son fundamentales en Backend.
✔Crear imágenes personalizadas con Dockerfiles eficientes y seguros.
✔Gestionar persistencia de datos con volúmenes y bind mounts.
✔Configurar redes Docker para conectar múltiples servicios.
✔Orquestar entornos completos con Docker Compose.
✔Aplicar multi-stage builds para optimizar imágenes de producción.
✔Containerizar aplicaciones Backend reales (Node.js, Python, PHP).

Requisitos previos

  • Conocimientos básicos de Backend y línea de comandos (terminal).
  • Experiencia con al menos un lenguaje de servidor (Node.js, Python, PHP, Go).
  • Un sistema operativo con Docker instalado (macOS, Linux o Windows con WSL2).
  • Comprensión básica de qué es una API REST.

Tecnologías y herramientas

Docker Dockerfile Docker Compose Volúmenes Redes Multi-stage CLI Contenedores

¿Qué es un contenedor y cómo se diferencia de una máquina virtual? Conceptos de aislamiento, namespaces, cgroups y el motor de Docker. Instalación y primeros comandos.
