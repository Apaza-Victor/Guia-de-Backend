Variables de entorno

🔧 Intermedio 10 min Docker para Backend Módulo 4 · Docker Compose

La config no vive en la imagen

La misma imagen debe servir para dev, staging y producción. La diferencia se inyecta con variables de entorno: no van a Git (algunas), no van a la imagen, y se pueden rotar sin reconstruir.

environment: directo en el servicio

env_file: la lista con vida propia

Interpolación: el YAML lee tu shell

El "nunca" que evita incendios

Ejercicio

  1. Extrae el password de Postgres a un .env.
  2. Usa env_file para la config de tu API.
  3. Verifica docker compose config que resuelva la interpolación.

Resumen

  • Environment = config por entorno, sin reconstruir.
  • env_file organiza por archivo; ${VAR:-default} parametriza.
  • La misma imagen cambia de personalidad con variables.
  • Secretos fuera de Git y fuera del compose versionado.
