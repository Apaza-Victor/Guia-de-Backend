¿Qué es Docker Compose?

🔧 Intermedio 10 min Docker para Backend Módulo 4 · Docker Compose

Un comando para todo el stack

En vez de 5 docker run, un archivo compose.yml describe los servicios y docker compose up los levanta juntos: API, BD, caché y colas, con sus redes y sus volúmenes.

Los nombres que genera

Lo que decide Compose por ti

  • Red propia para el proyecto (se hablan por nombre).
  • Sin restart automático: Compose no reinicia servicios caídos salvo que lo declares con restart:.
  • Solo publicas los ports: que declaraste: el resto interno.

Ejercicio

  1. Copia el compose mínimo y levanta el stack.
  2. Entra a la API y confirma que ve a postgres.
  3. Apaga con down y vuelve a levantar con up -d.

Resumen

  • compose.yml describe el stack: servicios, puertos, volúmenes.
  • up -d / ps / logs / down es el ciclo diario.
  • Nombres de proyecto: carpeta como prefijo.
  • El DNS interno usa el nombre del servicio.
