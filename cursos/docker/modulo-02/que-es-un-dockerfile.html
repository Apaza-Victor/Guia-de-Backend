¿Qué es un Dockerfile?

🔧 Intermedio 10 min Docker para Backend Módulo 2 · Imágenes y Dockerfile

Un archivo que es una receta

El Dockerfile describe paso a paso cómo construir tu imagen: qué base, qué paquetes, qué código, qué comando al arrancar. Es texto plano, versionable y reproducible de principio a fin.

Ejercicio

  1. Escribe un Dockerfile mínimo que corra node -e.
  2. Construye con -t mi-primer-api:1.0 y cápalo con --rm -d.
  3. Mira docker history y relaciona cada capa con una instrucción.

Resumen

  • Dockerfile = receta versionable de la imagen.
  • FROM / RUN / COPY / EXPOSE / CMD son lo esencial.
  • docker build -t nombre . construye desde el contexto.
  • ARG build-time, ENV runtime: no confundir.
