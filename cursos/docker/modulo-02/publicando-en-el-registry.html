Publicando en el registry

🔧 Intermedio 9 min Docker para Backend Módulo 2 · Imágenes y Dockerfile

Por qué distribuir

Tu imagen debe poder correr en cualquier servidor, en el CI y en la máquina del compañero. El registry es el repositorio donde publicas versiones exactas y reproducibles de tu app.

Los nombres: tag semver + migas fijas

login y push

Docker Hub, GHCR y registries privados

El error del "latest perezoso"

  • latest siempre cambia de significado: deja de ser reproducible.
  • Deploys que dependen de latest = sorpresas cuando otro push llegó.
  • Regla: despliega por versión exacta, usa latest solo para desarrollo.

Ejercicio

  1. Crea un repo público (Docker Hub o GHCR) para tu API.
  2. Etiqueta 1.0.0 y latest y haz push.
  3. Borra la imagen local y prueba docker pull + run.

Resumen

  • Registry = distribución reproducible de tu app.
  • Tags semver inmutables + latest solo para dev.
  • login con token; push por versión; pull para desplegar.
  • GHCR/registries privados: mismo flujo, otro host.
