Backup y restauración

Las 3 reglas de la BD dockerizada

  1. El volumen es tu BD: ni bind-mounts de carpetas locales, ni datos en el contenedor.
  2. Nunca pegues el dump dentro de la imagen: los datos no van a Git ni a docker build.
  3. Backups con copia real del volumen: borrar el contenedor no te detiene, pero borrar el volumen sí: respáldalo aparte.

Ejercicio

  1. Levanta Postgres con un volumen nombrado.
  2. Crea una tabla con datos y borra el contenedor rm -f.
  3. Recréalo con el Mismo volumen y confirma que los datos siguen.

Resumen

  • Monte /var/lib/postgresql/data en un volumen nombrado.
  • pg_dump dentro para backups; la imagen jamás lleva datos.
  • Borrar el contenedor es seguro; borrar el volumen NO.
  • Backup de verdad = copia del volumen en otro sitio.
