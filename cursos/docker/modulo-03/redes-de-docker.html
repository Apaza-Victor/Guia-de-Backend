Redes de Docker

🔧 Intermedio 10 min Docker para Backend Módulo 3 · Volúmenes y Redes

Red privada por defecto

Los contenedores salen con su propia interfaz de red virtual. Docker crea una red bridge por defecto: los contenedores se ven entre sí por IP, pero NO están expuestos al exterior hasta que lo quieras (publicando puertos con -p).

Publicar puertos: abrir solo lo necesario

Redes que puedes crear

La regla de oro

  • Nada publicas si nadie de fuera debe entrar: la BD queda internal.
  • Solo la API expone puertos al host.
  • Los servicios entre sí se hablan por la red interna, no por el host.
  • Las redes por nombre de servicio se ven mejor en la lección de Compose.

Ejercicio

  1. Corre Nginx en una red bridge y abre el puerto 8080.
  2. Crea una segunda red y verifica con docker network inspect.
  3. Confirma qué contacto hay entre dos contenedores: ¿se ven?

Resumen

  • Aislamiento por defecto; -p es la puerta al mundo.
  • Bridge: pila de red virtual por contenedor.
  • Redes con nombre = segmentos controlados.
  • Host: sin aislamiento; solo para casos puntuales.
