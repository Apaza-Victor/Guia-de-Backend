Módulo 3 · Volúmenes y Redes

Lo que un contenedor NO guarda y cómo persistirlo: volúmenes nombrados, bind mounts, bases de datos reales y redes para que tus servicios se hablen.

6 lecciones ~60 min
Progreso del curso

Objetivos de aprendizaje

  • Explicar por qué los datos no sobreviven un rm.
  • Persistir datos con volúmenes nombrados.
  • Usar bind mounts para desarrollo y configuración.
  • Mantener la base de datos de un servicio en volúmenes.
  • Comprender las redes bridge y host de Docker.
  • Conectar contenedores por nombre en vez de IPs.
