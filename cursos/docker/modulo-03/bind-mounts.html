Bind mounts

🔧 Intermedio 10 min Docker para Backend Módulo 3 · Volúmenes y Redes

Montar "tu" carpeta, no un espacio de Docker

Un bind mount conecta una ruta del host con una ruta del contenedor. Lo que escribas en una lo ves en la otra. No lo administra Docker como un volumen: es tu carpeta, tu disco.

El caso rey: desarrollo con hot-reload

Con un runner que recarga (nodemon, tsx watch, --watch), cada cambio se refleja al instante en el contenedor.

Configuración sin reconstruir

Los percances típicos

Ejercicio

  1. Crea ./app con un server.js que devuelva un texto.
  2. Móntalo con bind y cambia el texto SIN reconstruir.
  3. Prueba el montaje: docker cp ya no te necesita.

Resumen

  • Bind mount = carpeta del host dentro del contenedor.
  • Hot-reload y configuración editable al vuelo.
  • Cuidado con permisos y con pisar node_modules.
  • Para datos de la app usa volúmenes; para dev, bind.
