Módulo 5 · Docker en el Backend

El momento de la verdad: containerizar tu API de Node con su Postgres y su Redis, cuidar el arranque, manejar secretos e integrarlo todo en el pipeline.

6 lecciones ~65 min
Progreso del curso

Objetivos de aprendizaje

  • Dockerizar una API Node de punta a punta.
  • Conectarla a Postgres y a Redis por red interna.
  • Usar Redis como caché del backend.
  • Garantizar arranques sanos con healthchecks.
  • Manejar secretos y variables por entorno.
  • Integrar el build y los tests en el pipeline.
