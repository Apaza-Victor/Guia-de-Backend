Limpieza y buenas prácticas

🔧 Intermedio 9 min Docker para Backend Módulo 1 · Fundamentos

Primero: mira cuánto ocupas

La limpieza segura

Cuidado: --volumes borra datos. Si un volumen es tu base de datos, lo pensamos dos veces (M3).

¿Por qué se llena el disco?

  • Imágenes viejas de builds: docker image prune -a libera mucho.
  • Contenedores que mueren solos y nadie borra.
  • Build cache en proyectos con volumen de imágenes.
  • Volúmenes huérfanos de contenedores ya eliminados.

Reglas de oro del flujo

Ejercicio

  1. Ejecuta docker system df y escribe qué hay que limpiar.
  2. Prueba docker container prune para los parados.
  3. Repite el comando y compara cuánto volviste a ganar.

Resumen

  • system df diagnostica; prune limpia con filtros.
  • El disco se llena: imágenes, contenedores muertos, cache.
  • Nombres + restart + límites = contenedores predecibles.
  • No edites en marcha: vuelve a crear desde la imagen.
