Instalando Docker

🔧 Intermedio 10 min Docker para Backend Módulo 1 · Fundamentos

Dos piezas: CLI y engine

docker (la CLI que escribes) le habla a un daemon (el engine, dockerd) que crea y administra contenedores. En la práctica solo instalas el paquete y todo viene junto.

Windows: Docker Desktop + WSL2

Linux: el engine directo

Cómo verificar que todo funciona

El clásico "permission denied"

Ejercicio

  1. Instala Docker por tu plataforma y ejecuta docker run hello-world.
  2. Corre la prueba con Nginx: exponer 8080 y abrir en el navegador.
  3. Verifica docker info y el puerto del docker ps.

Resumen

  • CLI + daemon (engine): la instalación trae ambos.
  • Windows: Docker Desktop sobre WSL2.
  • Linux: engine con tu usuario en el grupo docker.
  • Si algo falla: revisa el servicio y los permisos.
