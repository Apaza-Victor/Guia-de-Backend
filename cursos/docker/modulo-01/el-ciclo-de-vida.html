El ciclo de vida

🔧 Intermedio 11 min Docker para Backend Módulo 1 · Fundamentos

Los estados del contenedor

Las imágenes son inmutables

Una imagen jamás se modifica. Cuando "editas" un archivo dentro de un contenedor, Docker utiliza una capa de escritura privada para ese contenedor (mecanismo copy-on-write). Dos contenedores de la misma imagen comparten capas de lectura y divergen solo en su capa privada.

namespaces: el "ilusión" de máquina

cgroups: los límites de recursos

Ver las capas reales de una imagen

Ejercicio

  1. Corre docker run -d --cpus="0.5" --memory="128m" nginx:alpine y mira docker stats.
  2. Ejecuta docker history en tu imagen y anota sus capas.
  3. Inspecciona con docker inspect los límites aplicados.

Resumen

  • Imágenes inmutables; el contenedor tiene capa de escritura propia.
  • namespaces: vista aislada de procesos, red y archivos.
  • cgroups: límites reales de CPU y memoria por contenedor.
  • Parar no borra: hay que rm para liberar disco.
