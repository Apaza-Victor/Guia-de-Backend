Errores comunes del arranque

  • Puerto ocupado: -p 8080:80 falla si algo ya usa 8080 en el host → cambia el puerto host.
  • "Unable to find image": se baja sola, no es error.
  • Contenedor que "muere" solo: apps con proceso principal que termina (p. ej., algo sin daemon).

Ejercicio

  1. Levanta nginx:alpine con -d -p 8080:80 --name web.
  2. Entra con exec, crea un archivo en /tmp y sal.
  3. Apaga, borra el contenedor y verifica con docker ps -a.

Resumen

  • run = pull + create + start; los flags hacen el trabajo.
  • ps / stop / start / rm administran el ciclo de vida.
  • logs y exec son tus ojos y tus manos dentro.
  • borrar un contenedor borra sus datos: eso es del M3.
