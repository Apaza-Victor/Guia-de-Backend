Módulo 1 · Fundamentos de GraphQL

Antes de escribir una línea de servidor hay que dominar el modelo mental de GraphQL: cómo se escriben las consultas, cómo se define el schema en SDL, qué rol juegan los resolvers y cómo la API se documenta sola con la introspección.

5 lecciones ≈ 42 min Node.js y JavaScript

Objetivos del módulo

✔Comparar REST y GraphQL y reconocer cuándo conviene cada modelo.
✔Definir tipos, escalares, listas y el schema completo en SDL.
✔Escribir queries con argumentos, aliases y mutations.
✔Implementar resolvers usando parent, args y context.
✔Explorar el schema mediante introspección y herramientas como GraphiQL.
