Módulo 2 · Implementación con Node.js

Lleva los conceptos al código: monta un servidor Apollo, intégralo a una app Express con contexto y base de datos, maneja argumentos, variables, errores y mutations con validación real y transacciones.

5 lecciones ≈ 46 min Node.js y JavaScript

Objetivos del módulo

✔Levantar un servidor Apollo Server con typeDefs y resolvers.
✔Integrar GraphQL en una app Express y construir el context de cada request.
✔Pasar argumentos y variables con validación de tipos del schema.
✔Entender el formato de errores y personalizarlo con extensiones.
✔Escribir mutations con input types, validación y transacciones.
