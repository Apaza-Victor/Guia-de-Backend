Explotando una consulta vulnerable

🔥 Avanzado 11 min Seguridad en el Backend Módulo 2 · Inyecciones

Entorno legal para aprender

Esto se juega solo en tu máquina contra una app propia o un laboratorio de pago (hackthebox, portswigger). Atacar sistemas ajenos sin permiso es delito. El objetivo es ver la mecánica para que el gusto por romper se vuelva instinto de defensa.

Romper el login

El payload ' UNION SELECT 1, 'admin', 'x' -- convierte el resultado vacío en una fila falsa: la consulta espera (id, email, password) y el atacante fabrica las tres.

Extraer datos con UNION

sqlmap, el martillo

sqlmap automatiza todo lo anterior. Úsalo para comprobar tu defensa, recordando: si tu app usa prepared statements, sqlmap no encontrará nada.

Ejercicio

  1. Crea una ruta vulnerable local y logra el login falso a mano.
  2. Descubre las columnas y lista una tabla con UNION.
  3. Corre sqlmap y luego corrige la consulta; repite sqlmap.

Resumen

  • Practica solo en entornos propios o de pago.
  • Login falso: ' OR 1=1 -- y UNION controlado.
  • ORDER BY para adivinar columnas; information_schema para mapear.
  • sqlmap automatiza la explotación: perfecto para validar defensa.
