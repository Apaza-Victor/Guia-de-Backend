Módulo 3 · Comunicación y entrega

El backend se entrega en equipo o no se entrega. Aquí verás cómo comunicar decisiones con ADRs, hacer code review que de verdad mejora el código, blindar la calidad con CI, manejar entornos y despliegues con rollback, y cerrar con lanzamientos, retrospectivas y postmortems constructivos.

5 lecciones ≈ 42 min Gestión para Backend

Objetivos del módulo

✔Diseñar comunicación síncrona y asíncrona y documentar decisiones con ADRs.
✔Hacer code review y pair programming efectivos con estándares claros.
✔Blindar la calidad con CI, tests de backend y cobertura de los flujos críticos.
✔Planear entornos, despliegues con rollback y lanzamientos con postmortem constructivo.

Lecciones

1 · Comunicación en el equipo

Sync y async, el registro escrito y ADRs para que ninguna decisión muera con quien la tomó.

CI, pruebas en backend y cobertura: qué verifica el pipeline antes de desplegar.

9 mincalidad

4 · Entornos y despliegue

Dev, staging y producción; estrategias de deploy y el plan de rollback que da calma.

8 minentrega

5 · Lanzamientos y postmortem

Release con feature flags, retrospectiva y postmortem sin culpables para aprender de verdad.

8 minentrega
