Proyectos Backend

Ruta de 16 proyectos para tu portafolio: desde una API de tareas hasta arquitecturas de microservicios y sistemas de alto tráfico.

12 semanas 4 módulos · 16 proyectos CRUD · E-commerce · Microservicios

¿Qué vas a aprender?

La teoría se demuestra construyendo. Este curso es la ruta de práctica definitiva: 16 proyectos que van creciendo en complejidad, de una API de tareas con CRUD a un sistema de alto tráfico con microservicios. Cada proyecto sigue un estándar profesional — entornos, logging, tests y git — y termina listo para tu portafolio, con su README, deploy y documentación. Si los completas todos, tendrás la evidencia real que cualquier reclutador quiere ver.

Objetivos de aprendizaje

✔Configurar un backend profesional: entornos, variables, logging y git.
✔Construir APIs REST completas con CRUD, autenticación y caché.
✔Desarrollar productos reales: e-commerce, chat, reservas y uploads.
✔Diseñar microservicios, pagos y sistemas de alto tráfico.
✔Publicar 16 proyectos listos para el portafolio.

Requisitos previos

  • Todo lo anterior: este curso integra los conocimientos de toda la ruta.
  • Dominio de al menos un lenguaje backend y una base de datos.
  • Git, Docker y conceptos de arquitectura y testing.

Tecnologías y herramientas

REST CRUD Autenticación WebSockets Microservicios Redis

Módulos del curso

Cuatro módulos, dieciséis proyectos que van del primer endpoint al sistema distribuido.

1. Fundamentos de práctica

Prepara el cinturón de herramientas que usarás en los dieciséis proyectos.

4 proyectos≈ 50 min
  • Configuración de entornos de desarrollo
  • Variables de entorno y secretos
  • Logging profesional
  • Git profesional y git flow

2. Proyectos fundamentales

Los clásicos que todo backend ha construido: CRUD, auth y caché.

4 proyectos≈ 60 min
  • API de tareas con CRUD
  • Blog con autenticación
  • URL shortener con caché
  • API de producción con tests

3. Proyectos intermedios

Productos con más partes móviles: pagos, tiempo real y archivos.

4 proyectos≈ 68 min
  • E-commerce MVP
  • Chat con WebSockets
  • API de reservas
  • File upload y download

4. Proyectos avanzados

Arquitectura a escala: microservicios, pagos y alto tráfico.

4 proyectos≈ 72 min
  • Microservicios de inventario
  • Sistema de pagos
  • Dashboard en tiempo real
  • Sistema de alto tráfico
