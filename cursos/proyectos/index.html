Módulos del curso

7 módulos con 31 lecciones en total.

Módulo 1 · Fundamentos de gestión

5 lecciones≈ 44 min

Aprende el ciclo de vida del software, las metodologías ágiles, la gestión de requisitos y la entrega incremental que sostienen a un equipo backend de verdad.

  1. Ciclo de vida del software
  2. Estimación y priorización
  3. Metodologías ágiles
  4. Requerimientos y aclaraciones
  5. Scrum aplicado a backend
Empezar módulo

Módulo 2 · Planificación y seguimiento

5 lecciones≈ 42 min

Planifica sprints reales, controla la deuda técnica, gestiona riesgos y mide el progreso con datos, no con impresiones.

  1. Deuda técnica
  2. Gestión de riesgos
  3. Gestión de tareas
  4. Planificación de sprints
  5. Seguimiento y medición
Empezar módulo

Módulo 3 · Comunicación y entrega

5 lecciones≈ 42 min

La entrega es un arte de equipo: calidad verificable, code reviews que enseñan, comunicación eficaz, despliegue sin drama y el postmortem que mejora lo siguiente.

  1. Calidad y verificación
  2. Code review y colaboración
  3. Comunicación en el equipo
  4. Entornos y despliegue
  5. Lanzamientos y postmortem
Empezar módulo

Módulo 4 · Del portafolio al proyecto real

5 lecciones≈ 55 min

Convierte una idea de proyecto en un producto real: define qué construyes, escribe una arquitectura, monta el CRUD y despliega tu portafolio para que se vea, no para que se quede en local.

  1. Qué hace grande a un portafolio backend
  2. De la idea a los requisitos del proyecto
  3. Escribir la arquitectura del proyecto
  4. El CRUD bien hecho como base
  5. Contenerizar y desplegar el portafolio
Empezar módulo

Módulo 5 · Casos de uso reales

4 lecciones≈ 48 min

Construye cuatro proyectos clásicos con vencida técnica: una API de tareas con autenticación, un e-commerce con carrito, un chat en tiempo real y una API que conversa con un modelo de IA.

  1. API de tareas con autenticación
  2. Mini e-commerce con carrito
  3. Chat en tiempo real con WebSockets
  4. API con integración de IA
Empezar módulo

Módulo 6 · De monolitos a microservicios

3 lecciones≈ 35 min

Viaja del monolito bien hecho a los microservicios con criterio: cuándo dividir, cómo resolver la comunicación y qué precio pagas por la complejidad.

  1. El monolito bien hecho
  2. Cuándo dividir el monolito
  3. Dos microservicios con cola
Empezar módulo

Módulo 7 · Hacia el perfil senior

4 lecciones≈ 43 min

Eleva tu proyecto a nivel senior: mide el rendimiento, blindalo con pruebas integrales y hazlo observable; después, conviértelo en la mejor entrevista de tu carrera.

  1. Rendimiento en el proyecto
  2. Testing integral del proyecto
  3. Observabilidad del proyecto
  4. Del proyecto a la entrevista
