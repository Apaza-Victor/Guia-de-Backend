System Design / Arquitectura de Sistemas

Requisitos, escalabilidad horizontal, load balancing, caching, CDN, replicación, sharding y diseño de sistemas de alto tráfico.

9 semanas 4 módulos · 20 lecciones Load Balancing · Sharding · Alta Disponibilidad

¿Qué vas a aprender?

Un sistema se cae por diseño, no por casualidad. Este curso te entrena para pensar como el senior que diseña arquitecturas que soportan millones de usuarios: recopilar requisitos, estimar capacidades, elegir bases de datos y escalar con load balancers, cachés, colas y sharding. Practicarás seis casos reales — URL shortener, feed, chat global, motores de búsqueda, pagos y recomendaciones — y cerrarás con un framework completo para entrevistas.

Objetivos de aprendizaje

✔Recopilar requisitos y estimar capacidades de un sistema.
✔Escalar con load balancers, caching, CDN, colas y sharding.
✔Diseñar seis sistemas de alto tráfico desde cero.
✔Equilibrar disponibilidad y consistencia bajo el teorema CAP.
✔Resolver entrevistas de system design con un framework.

Requisitos previos

  • Sistemas Distribuidos: nodos, latencia, CAP y replicación.
  • Arquitectura de Software: capas, microservicios y patrones.
  • Bases de datos: modelado relacional y NoSQL.

Módulos del curso

Cuatro módulos para diseñar sistemas a gran escala: fundamentos, bloques, casos reales y entrevistas.

1. Fundamentos

Aprende a definir el problema antes de dibujar la primera caja del diagrama.

5 lecciones≈ 60 min
  • Reunir requisitos del sistema
  • Capacidades y estimaciones
  • Requisitos no funcionales (NFR)
  • Escalabilidad vertical y horizontal
  • Disponibilidad vs consistencia

2. Bloques de construcción

Las piezas que se repiten en todo sistema grande y cómo combinarlas.

5 lecciones≈ 62 min
  • Load balancers
  • Caching y CDN
  • Bases de datos a escala
  • Colas y workers
  • Almacenamiento de archivos

3. Diseño de sistemas

Seis casos reales de alto tráfico, diseñados paso a paso de principio a fin.

6 lecciones≈ 92 min
  • URL shortener
  • Feed de noticias
  • Chat global
  • Motores de búsqueda
  • Sistema de pagos
  • Sistema de recomendaciones

4. Entrevistas

Convierte todo lo aprendido en un proceso claro y pulido para la entrevista.

4 lecciones≈ 48 min
  • Framework de resolución
  • Cómo presentar las estimaciones
  • Ejemplo guiado de entrevista
  • Errores comunes a evitar
