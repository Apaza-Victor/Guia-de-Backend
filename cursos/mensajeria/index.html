📨 Mensajería Backend

Conecta tus servicios con sistemas de mensajería asíncrona. Aprende MQTT, RabbitMQ y Apache Kafka para manejar colas, eventos y tareas en segundo plano, y diseña Backends desacoplados y resilientes.

5 semanas 6 módulos · 48 lecciones Colas · Eventos · Kafka

¿Qué vas a aprender?

Cuando una API necesita enviar correos, procesar archivos o coordinar varios servicios, el trabajo asíncrono es la respuesta. En este curso aprenderás los conceptos de mensajería, colas de trabajo, productores y consumidores, y dominarás las dos grandes tecnologías: RabbitMQ y Apache Kafka. También explorarás MQTT para dispositivos IoT y aprenderás los patrones que hacen que los sistemas se comuniquen sin acoplarse.

Objetivos del curso

✔Entender el modelo productor-consumidor y los beneficios de la mensajería asíncrona.
✔Construir colas de trabajo con RabbitMQ: exchanges, queues, bindings y routing.
✔Dominar Apache Kafka: topics, particiones, offset, grupos de consumidores y replicación.
✔Configurar MQTT para comunicación ligera entre dispositivos y servicios.
✔Implementar entrega de mensajes con acknowledgment, retries y dead-letter queues.
✔Integrar mensajería en arquitecturas de microservicios y eventos de dominio.
✔Monitorizar rendimiento y escalamiento horizontal de consumidores.

Requisitos previos

  • Experiencia construyendo APIs Backend (Node.js, Python o PHP).
  • Conocimientos de microservicios y arquitectura de aplicaciones.
  • Docker instalado para levantar RabbitMQ y Kafka localmente.
  • Comprensión de JSON y formatos de intercambio de datos.

Tecnologías y herramientas

RabbitMQ Apache Kafka MQTT Colas Pub/Sub Eventos Docker DLQ
