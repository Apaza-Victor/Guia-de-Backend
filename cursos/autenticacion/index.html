Módulos del curso

7 módulos con 34 lecciones en total.

Módulo 1 · Fundamentos de la Autenticación

5 lecciones≈ 48 min

Comprende la diferencia entre autenticación y autorización, el papel de las cookies, las diferencias entre hashing y encriptación y el modelo de amenazas que todo sistema de login debe contemplar.

  1. Autenticación vs Autorización
  2. Cookies y su rol en la web
  3. Hashing vs encriptación
  4. Identidad y estados de sesión
  5. El modelo de amenazas del login

Módulo 2 · Registro y Login

5 lecciones≈ 49 min

Implementa el ciclo completo de cuentas: hashing de contraseñas con bcrypt, registro validado, login con verificación de credenciales, modelo de usuario con rol y recuperación de contraseña.

  1. Hashing con bcrypt y password_hash
  2. Login y verificación de credenciales
  3. Modelo de usuario y rol básico
  4. Registro y validación de datos
  5. Restablecimiento de contraseña

Módulo 3 · Sesiones del lado servidor

5 lecciones≈ 44 min

Gestiona sesiones persistentes en el servidor: expiración, renovación, revocación, protección de la cookie de sesión y almacenamiento en bases de datos o Redis.

  1. Cierre de sesión y revocación
  2. Expiración y renovación
  3. Protección de la cookie de sesión
  4. Sesiones en Bases de Datos y Redis
  5. Sesiones y almacenamiento

Módulo 4 · JWT

5 lecciones≈ 50 min

Domina los JSON Web Tokens: sus partes, el acceso sin estado, tipos de firma HS256 y RS256, expiración, almacenamiento seguro en el cliente y estrategias con refresh tokens y rotación.

  1. Access tokens y expiración
  2. Almacenamiento seguro en el cliente
  3. Firmando tokens: HS256 y RS256
  4. ¿Qué es un JWT y sus partes?
  5. Refresh tokens y rotación

Módulo 5 · Autorización y RBAC

4 lecciones≈ 41 min

Separa identidad de permisos: construye roles, claims y middlewares de autorización, y protege rutas y funciones para que cada usuario solo acceda a lo suyo.

  1. Middleware de autorización
  2. Permisos y claims
  3. Protegiendo rutas y funciones
  4. Roles de usuario

Módulo 6 · OAuth 2.0 y OIDC

5 lecciones≈ 50 min

Integra autenticación delegada: actores y flujos de OAuth 2.0, authorization code flow, integración con proveedores externos, scopes, consentimiento y OpenID Connect con id tokens.

  1. Authorization code flow
  2. Integrando un proveedor externo
  3. OAuth: actores y flujos
  4. OpenID Connect e id tokens
  5. Scopes y consentimiento

Módulo 7 · Seguridad, OWASP y cumplimiento

5 lecciones≈ 60 min

Aplica la seguridad de sesiones y autenticación de nivel producción: OWASP en auth, gestión de secretos, CSRF y secuestro de sesión, rate limiting contra fuerza bruta y cabeceras de seguridad HTTP.

  1. OWASP y la autenticación
  2. Gestión segura de secretos
  3. CSRF y secuestro de sesión
  4. Rate limiting y fuerza bruta
  5. Cabeceras de seguridad HTTP
