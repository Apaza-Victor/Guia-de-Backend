⚡ Redis para Backend

Redis es el almacén en memoria que acelera cualquier Backend. Aprende sus estructuras de datos, patrones de caché, manejo de sesiones, colas de trabajo y pub/sub, todo con ejemplos prácticos usando redis-cli y clientes reales.

4 semanas 6 módulos · 44 lecciones Redis · Caché · Datos

¿Qué vas a aprender?

Redis es mucho más que una base de datos en memoria: es una máquina de estructuras de datos al servicio del Backend. En este curso aprenderás a usarlo como caché de alto rendimiento, almacén de sesiones, cola de trabajos y sistema de mensajería pub/sub. Dominarás los comandos de redis-cli, los clientes oficiales en Node.js, Python y PHP, y los patrones que resuelven los problemas reales de rendimiento de una API.

Objetivos del curso

✔Instalar y configurar Redis, y domina redis-cli para administrarlo.
✔Dominar las estructuras de datos: strings, hashes, lists, sets y sorted sets.
✔Implementar patrones de caché como cache-aside, TTL y eviction.
✔Gestionar sesiones de usuario distribuidas con Redis.
✔Construir colas de trabajo y sistemas de mensajería con pub/sub.
✔Usar clientes de Redis desde Node.js, Python y PHP.
✔Aplicar mejores prácticas de rendimiento: pipelines, transacciones y cluster.

Requisitos previos

  • Conocimientos básicos de Backend y de al menos un lenguaje de programación.
  • Familiaridad con APIs REST y bases de datos tradicionales.
  • Redis instalado localmente o acceso vía Docker (docker run redis).
  • Ganas de optimizar el rendimiento de tus aplicaciones.

Tecnologías y herramientas
