Sorted sets y rankings

🔥 Avanzado 12 min Redis para Backend Módulo 2 · Estructuras

Un set con score, ordenado todo el tiempo

Un sorted set asocia a cada miembro un score (número en coma flotante) y mantiene el orden por ese score. Responde "¿cuál es el top 10?" sin ordenar nada en tu app.

Comandos esenciales

Leaderboard en tiempo real

Colas priorizadas con fecha de entrega

Ventanas de tiempo para analytics

Ejercicio

  1. Implementa un leaderboard con zincrby y zrevrange.
  2. Crea la cola con retraso por timestamp: programa 3 tareas y consume las vencidas.
  3. Explica la diferencia entre ZRANK y ZREVRANK.

Resumen

  • Los sorted sets mantienen el orden por score de forma permanente.
  • El leaderboard vive en un solo comando: ZREVRANGE.
  • Timestamp como score = colas con retraso y ventanas de tiempo.
  • Buscar por score es O(log N): escala a millones de miembros.
