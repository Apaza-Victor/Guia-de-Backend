Casos reales

🔥 Avanzado 10 min Redis para Backend Módulo 2 · Estructuras

Reto 1: feed de actividad

Piezas: LPUSH como head, LTRIM para cap, LRANGE para paginar.

Reto 2: carrito que sobrevive a la sesión

Piezas: un hash negocia campo por campo y el TTL limpia carritos abandonados.

Reto 3: dedupe de webhooks y filtros combinados

Elegir la estructura: resumen mental

Ejercicio

  1. Implementa los tres retos de la lección en un solo script Python.
  2. Añade filtros con SINTER: "tag python + backend" y devuelve el resultado.
  3. Elige la estructura idónea para un sistema de "megusta" que use ranking por fecha.

Resumen

  • El feed se resuelve con LIST + LTRIM + LRANGE.
  • El carrito es un HASH con TTL: campos atómicos y limpieza gratis.
  • El dedupe de eventos es SADD + SISMEMBER, idempotente.
  • Los filtros combinados son operaciones nativas de conjuntos.
