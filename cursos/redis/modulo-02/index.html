Módulo 2 · Estructuras de Datos

Cada tipo de dato de Redis resuelve un problema concreto: modela perfiles, colas, pertenencia y rankings.

🔥 Avanzado Redis para Backend Nivel: Avanzado

Objetivos del módulo

Dominar las estructuras de Redis es elegir el modelo de datos correcto antes de escribir una línea. Aquí verás cada tipo con su caso de uso real y su costo.

  • Hashes para modelar objetos con campos independientes.
  • Lists para feeds y colas FIFO.
  • Sets para pertenencia, dedupe y operaciones entre grupos.
  • Sorted sets para rankings y colas por prioridad.
  • El enfoque de "un tipo de datos, un problema".
Progreso del curso Redis para Backend 0%

Lecciones del módulo

5 lecciones · ~50 min · profundiza cada estructura con código real.

1 · Hashes en profundidad

Objetos de verdad: campos atómicos y sin re-serializar el JSON.

10 minestructuras

2 · Lists y colas

Feeds, colas FIFO y consumo bloqueante con BRPOP.

11 mincolas

3 · Sets y pertenencia

Dedupe O(1), grupos y operaciones entre conjuntos.

10 minconjuntos

4 · Sorted sets y rankings

Top 10, colas priorizadas y ventanas de tiempo.

12 minrankings

5 · Casos reales

Feed de actividad, carrito y dedupe de eventos: retos resueltos.

10 minintegración
