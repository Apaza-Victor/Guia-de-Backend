Módulo 1 · Introducción a Redis

El almacén clave-valor en memoria que todo Backend usa: instala, explora la CLI y conoce sus tipos de datos.

🔥 Avanzado Redis para Backend Nivel: Avanzado

Objetivos del módulo

Redis no es "una base como las demás": todo vive en memoria y con latencias de microsegundos. Al terminar sabrás:

  • Qué es Redis y cuándo usarlo en tu Backend.
  • Instalarlo y manejarlo con la CLI.
  • Diferenciar y aplicar las estructuras de datos básicas.
  • Controlar la vida de los datos con TTL.
  • Conectarte desde Python con redis-py.
