Ejercicio

  1. Escribe un perfil como hash desde Python y lee un campo.
  2. Implementa el contador de visitas con incr.
  3. Guarda un dict como JSON con TTL y recupéralo.

Resumen

  • redis.Redis() con pool y decode_responses=True es el punto de partida.
  • Los métodos python reflejan los comandos: set/get/incr/ttl.
  • JSON se serializa manualmente; los hashes evitan esa travesía.
  • Las pipelines agrupan comandos; WATCH da concurrencia atómica.
