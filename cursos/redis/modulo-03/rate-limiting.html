Rate limiting

🔥 Avanzado 12 min Redis para Backend Módulo 3 · Caché

Frenar bots y abusos

El rate limiting limita cuántas peticiones admite tu API por unidad de tiempo y por cliente (IP, usuario, API key). Redis es el lugar natural: contadores atómicos, TTL y latencia de microsegundos.

Ventana fija y deslizante

Protege también los endpoints internos: el rate limit vive delante (API Gateway) y a nivel de código para los servicios clave (login, OTP, búsqueda).

Ejercicio

  1. Implementa el límite de 20 peticiones/min por IP.
  2. Repite con ventana deslizante y compara el pico en el borde.
  3. Devuelve 429 con las cabeceras RateLimit-*.

Resumen

  • Ventana fija = INCR + EXPIRE; sencilla, con borde traicionero.
  • Ventana deslizante = sorted set de timestamps; precisa.
  • Es el antídoto para bots y abusos sobre login y endpoints costosos.
  • Responde 429 y anuncia el límite en cabeceras.
