Arquitectura de Software

Diseña sistemas mantenibles: monolito, capas, MVC, Service Layer, Repository, DI, SOLID, Clean Architecture y Hexagonal Architecture.

7 semanas 7 módulos · 31 lecciones MVC · Clean · Hexagonal · DDD

¿Qué vas a aprender?

Escribir código que funcione es relativamente fácil; escribir código que sobreviva años de cambios es arquitectura. Este curso te enseña a diseñar software mantenible: estilos como capas y monolito modular, patrones como MVC, Service Layer y Repository, y enfoques modernos como Clean Architecture, Hexagonal y Domain-Driven Design. Aprenderás a tomar decisiones de diseño con argumentos y a razonar sobre la estructura de tu código antes de escribir cada línea.

Objetivos de aprendizaje

✔Diferenciar arquitectura, diseño y patrones, y aplicar cada uno en su momento.
✔Diseñar con capas, MVC, Service Layer y Repository desde la primera lección.
✔Aplicar SOLID de forma práctica y medir acoplamiento y cohesión.
✔Estructurar proyectos con Clean Architecture y dependencias invertidas.
✔Modelar dominios con Hexagonal Architecture y domain-driven design.

Requisitos previos

  • Programación para Backend: POO y MVC de forma aplicada.
  • Algún curso de framework (PHP, Node o Python) para los ejemplos.
  • Experiencia escribiendo o manteniendo código real, aunque sea poca.

Tecnologías y herramientas

MVC Clean Architecture Hexagonal DDD SOLID Repository

Módulos del curso

Siete módulos que van del concepto al mundo real: estilos, patrones, principios y las arquitecturas modernas.

Qué es arquitectura de software, los atributos de calidad y cómo razonar las decisiones.

  • El rol del arquitecto en el equipo

Los grandes patrones de organización: monolito, capas, cliente-servidor y módulos.
