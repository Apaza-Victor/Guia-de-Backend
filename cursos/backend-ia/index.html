Backend para IA

Integra modelos de IA en tu backend: API keys, streaming, embeddings, vector databases, RAG y arquitecturas con IA en producción.

7 semanas 3 módulos · 14 lecciones APIs de IA · RAG · Embeddings

¿Qué vas a aprender?

La IA se consume desde un servidor: llamar a modelos, transmitir respuestas en streaming y proteger las API keys son trabajo de backend. En este curso conectarás un modelo LLM a tu aplicación, convertirás datos en embeddings y montarás una vector database para darle memoria a la IA con RAG. Terminarás construyendo chatbots con historial, agentes con herramientas y un asistente real listo para el mundo.

Objetivos de aprendizaje

✔Consumir APIs de modelos LLM con streaming y control de tokens.
✔Generar embeddings y buscar de forma semántica en vector databases.
✔Montar un pipeline RAG que responde con tus propios documentos.
✔Construir chatbots con historial y agentes con herramientas.
✔Evaluar costos, latencia y arquitectura de un backend con IA.

Requisitos previos

  • Python: escribir servicios y consumir bibliotecas de IA.
  • APIs REST: exponer endpoints y trabajar con JSON.
  • Redis: para cache, sesiones e historial de conversaciones.

Tecnologías y herramientas
