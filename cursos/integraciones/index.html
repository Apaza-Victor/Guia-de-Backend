Módulo 1 · Fundamentos de integración

5 lecciones≈ 48 min

Comprende qué es una integración, gestiona APIs externas como producto, aplica patrones de integración, elige entre SDKs, clientes HTTP y webhooks y entra en contacto con el mundo real de los servicios de terceros.

  1. Gestión de APIs externas
  2. Patrones de integración
  3. ¿Qué son las integraciones?
  4. SDKs y clientes HTTP
  5. Webhooks

  1. Email y notificaciones
  2. Mapas y geolocalización
  3. Pasarelas de pago
  4. Social login y OAuth

Módulo 3 · Robustez

5 lecciones≈ 54 min

Encola tareas lentas, guarda secretos fuera del código, reintenta con estrategia, monitoriza cada integración y automatiza las pruebas contra terceros.

  1. Colas para tareas lentas
  2. Configuración y secretos
  3. Errores y reintentos
  4. Monitoreo de integraciones
  5. Pruebas de integración

Módulo 4 · Integraciones con SaaS

5 lecciones≈ 53 min

Integra SaaS de referencia con rigor: entender el contrato, sincronizar con un CRM, enviar notificaciones multicanal, gestionar pagos recurrentes y emitir eventos de analítica.

  1. El contrato de un SaaS
  2. Sincronizar datos con un CRM
  3. Notificaciones multicanal
  4. Suscripciones y pagos recurrentes
  5. Eventos de analítica desde el backend

Módulo 5 · Webhooks y eventos

5 lecciones≈ 54 min

Exponer y proteger endpoints de webhook, verificar firmas criptográficas, reintentar de forma idempotente, estudiar un caso real de proveedor y derivar webhooks hacia eventos asíncronos.

  1. Recibir un webhook con control
  2. Verificar firmas de webhook
  3. Reintentos e idempotencia en webhooks
  4. Caso real: webhooks de GitHub
  5. De webhook a evento asíncrono

Módulo 6 · Seguridad en integraciones

4 lecciones≈ 44 min

Aplica mínimos privilegios con API keys y scopes, usa flujos de máquina a máquina, evita ataques SSRF, protege los datos personales que viajan a terceros y vigila la cadena de suministro de tus dependencias.

  1. API keys y scopes
  2. OAuth de máquina a máquina
  3. SSRF: el riesgo de pedir URL al usuario
  4. Datos personales en integraciones

Módulo 7 · Operación y mantenimiento

5 lecciones≈ 59 min

La integración no acaba cuando publicas: terceros cambian sus APIs, fallan, cobran y se retiran. Planifica cómo sobrevivir, migrar y cerrar cada integración con criterio.

  1. Cuando el tercero cambia su API
  2. Failover sin el tercero
  3. Catálogo y gobierno de integraciones
  4. Costes y límites de uso
  5. Retirar y migrar una integración
