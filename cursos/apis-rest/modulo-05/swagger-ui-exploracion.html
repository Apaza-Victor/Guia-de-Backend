Swagger UI: exploración de la API

⚙️ Intermedio 11 min APIs REST Módulo 5 · Documentación

Montar Swagger UI sobre tu spec

Con tu openapi.yaml en mano, Swagger UI lo convierte en una página interactiva. Sin instalar nada, prueba con el spec de la industria:

Para tu API local en Node:

Leer la interfaz

  • Servers: la base URL que usará la página para llamar.
  • Paths: grupos por recurso; dentro, cada verbo con su acordeón.
  • Parameters: query, path, header, body — con su tipo y required.
  • Responses: cada código con su schema expandible.
  • Authorize: botón para pegarte tu token y probar protegido.

Probar en vivo (sin miedo)

Ese botón lo cambia todo: la documentación deja de ser pasiva y se convierte en un cliente de prueba descartable.

Trucos de profesional

  • Mete examples en tus schemas: llenar un POST al instante.
  • Guarda la spec en el repo y validala en CI (openapi-validator).
  • En producción, protege /docs con auth si describe detalles internos.
  • Alternativas: Redoc (estático bonito) o Stoplight (editor colaborativo).

Ejercicio

  1. Monta /docs en tu API y abre la página.
  2. Haz un POST completo desde "Try it out".
  3. Engancha tu token con Authorize y prueba un endpoint protegido.

Resumen

  • Swagger UI convierte tu spec en docs interactivas.
  • Try it out = cliente de prueba descartable.
  • Spec en repo + validation CI + auth en /docs si hace falta.
