APIs REST

Diseña APIs REST profesionales: recursos, métodos, status codes, versionado, documentación con OpenAPI y validación.

6 semanas 6 módulos · 28 lecciones REST · HTTP · JSON · OpenAPI

¿Qué vas a aprender?

Las APIs REST son la forma estándar en que los sistemas se comunican: páginas web, apps móviles e integraciones consumen los mismos servicios de datos. Aprenderás a diseñar APIs coherentes, bien documentadas y fáciles de consumir, aplicando los principios de REST, HTTP, JSON y OpenAPI. Cada concepto se practica construyendo y probando una API real de principio a fin, con tu lenguaje de backend preferido.

Nivel⚙️ Intermedio
Duración6 semanas
Módulos6

Categoría🔌 APIs

Objetivos de aprendizaje

✔Entender qué es una API y por qué el estilo REST domina la web.
✔Aplicar correctamente métodos HTTP, códigos de estado y cabeceras.
✔Diseñar recursos con buenas URL, versionado, paginación y filtros.
✔Implementar un CRUD completo con validación y manejo de errores.
✔Documentar la API con OpenAPI y consumirla desde cualquier cliente.

Requisitos previos

  • Fundamentos de Backend: conocer HTTP, request/response y status codes.
  • Un lenguaje de backend (PHP, Node o Python) para los ejemplos prácticos.
  • Bases de Datos: nociones de tablas y consultas para el CRUD final.

Tecnologías y herramientas

REST HTTP JSON OpenAPI Swagger Status Codes

Módulos del curso

Seis módulos que van del concepto al despliegue de una API documentada: HTTP, diseño, implementación y calidad.

1. Fundamentos de APIs

Qué es una API, cómo piensan sus diseñadores y por qué REST se volvió el estándar.

5 lecciones≈ 42 min
  • ¿Qué es una API y para qué sirve?
  • Clientes y consumidores de una API
  • El estilo REST y su historia
  • Recursos y representaciones con JSON
  • La anatomía de una API real

2. HTTP aplicado a REST

El protocolo que sostiene a REST: métodos, status codes, cabeceras y negociación de contenido.

5 lecciones≈ 48 min
  • Métodos HTTP: GET, POST, PUT, PATCH y DELETE
  • Códigos de estado del 1xx al 5xx
  • Cabeceras de petición y de respuesta
  • Content-Type y Content-Disposition
  • Negociación de contenido

3. Diseño REST

Nombres de recursos, versionado, paginación, filtros y errores consistentes.

5 lecciones≈ 50 min
  • Nombrando recursos en plural
  • Versionado: URL vs headers
  • Paginación y filtros por query
  • Caché con ETag y Cache-Control
  • Estructura de errores consistente

4. Implementación

Construye tu primera API completa: CRUD, validación, autenticación y serialización.

5 lecciones≈ 52 min
  • CRUD de un recurso completo
  • Validación de entrada y reglas
  • Manejo de errores centralizado
  • Autenticación básica y API keys
  • Serialización y respuestas consistentes

5. Documentación

OpenAPI y Swagger: una API sin documentar es una API difícil de consumir.

4 lecciones≈ 42 min
  • ¿Qué es OpenAPI?
  • Definiendo el contrato de tu API
  • Swagger UI y exploración interactiva
  • Ejemplos, errores y SDKs generados

6. Calidad y seguridad

El pulido final de una API profesional: testing, rate limiting, seguridad y monitoreo.

4 lecciones≈ 45 min
  • Testing de endpoints
  • Rate limiting y abuso de API
  • CORS y buenas prácticas de seguridad
  • Monitoreo y métricas básicas
