Módulos del curso

7 módulos con 33 lecciones en total.

Módulo 1 · Fundamentos de APIs

5 lecciones≈ 42 min

Comprende qué es una API real, quién la consume, la historia y el estilo REST, los recursos con sus representaciones JSON y la arquitectura que los sostiene.

  1. La anatomía de una API real
  2. Clientes y consumidores de una API
  3. El estilo REST y su historia
  4. ¿Qué es una API y para qué sirve?
  5. Recursos y representaciones con JSON
Empezar módulo

Módulo 2 · HTTP aplicado a REST

5 lecciones≈ 48 min

Domina el protocolo que transporta tu API: cabeceras de petición y respuesta, códigos de estado del 1xx al 5xx, Content-Type, métodos HTTP y negociación de contenido.

  1. Cabeceras de petición y de respuesta
  2. Códigos de estado del 1xx al 5xx
  3. Content-Type y Content-Disposition
  4. Métodos HTTP: GET, POST, PUT, PATCH y DELETE
  5. Negociación de contenido
Empezar módulo

Módulo 3 · Diseño REST

5 lecciones≈ 50 min

Diseña APIs que aguantan años en producción: caché con ETag y Cache-Control, errores consistentes, recursos en plural, paginación por query y versionado de URLs o headers.

  1. Caché con ETag y Cache-Control
  2. Estructura de errores consistente
  3. Nombrando recursos en plural
  4. Paginación y filtros por query
  5. Versionado: URL vs headers
Empezar módulo

Módulo 4 · Implementación

5 lecciones≈ 52 min

Implementa una API de verdad: autenticación básica y API keys, un CRUD completo de recurso, manejo de errores centralizado, serialización consistente y validación de entrada.

  1. Autenticación básica y API keys
  2. CRUD de un recurso completo
  3. Manejo de errores centralizado
  4. Serialización y respuestas consistentes
  5. Validación de entrada y reglas
Empezar módulo

Módulo 5 · Documentación

4 lecciones≈ 42 min

Convierte tu API en documentada y explorable: define el contrato, describe OpenAPI, documenta ejemplos y errores, genera SDKs y explora la API con Swagger UI.

  1. Definiendo el contrato de la API
  2. Ejemplos, errores y SDKs generados
  3. ¿Qué es OpenAPI?
  4. Swagger UI: exploración de la API
Empezar módulo

Módulo 6 · Calidad y seguridad

4 lecciones≈ 45 min

Endurece tu API: CORS y seguridad, monitoreo y métricas, rate limiting contra abusos y testing de endpoints para que no se rompa en producción.

  1. CORS y buenas prácticas de seguridad
  2. Monitoreo y métricas básicas
  3. Rate limiting y abuso de la API
  4. Testing de endpoints
Empezar módulo

Módulo 7 · APIs en producción

5 lecciones≈ 59 min

Gestiona la vida de tu API: versionado semántico, evolución sin romper clientes, deprecación de endpoints, compatibilidad hacia atrás y gobierno con observabilidad.

  1. Versionado semántico para APIs
  2. Evolucionar sin romper a los clientes
  3. Deprecación y ciclo de vida de endpoints
  4. Compatibilidad hacia atrás y migraciones
  5. Gobierno y observabilidad de la API
