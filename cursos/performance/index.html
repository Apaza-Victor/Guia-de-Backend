🚀 Performance Backend

Mide, diagnostica y optimiza el rendimiento de tus APIs. Aprende a reducir latencia, manejar concurrencia, configurar caché HTTP, eliminar consultas N+1, indexar bases de datos y profilear tu código como un profesional.

5 semanas 6 módulos · 47 lecciones Rendimiento · Optimización · Latencia

¿Qué vas a aprender?

El rendimiento es una característica, no un extra. En este curso aprenderás a medir el rendimiento de tus sistemas Backend con métricas y herramientas de profiling, identificar cuellos de botella en latencia y concurrencia, optimizar consultas y base de datos, y aplicar estrategias de caché HTTP y Redis. Terminarás con la capacidad de hacer que una API lenta responda en milisegundos.

Objetivos del curso

✔Definir y medir métricas clave: latencia, throughput y percentiles (p50, p95, p99).
✔Identificar cuellos de botella y aplicar principios de alta concurrencia.
✔Configurar caché HTTP con headers, ETags y control de cacheo a nivel de CDN.
✔Detectar y resolver el problema N+1 en consultas a bases de datos.
✔Crear índices eficientes y entender EXPLAIN en PostgreSQL y MySQL.
✔Usar herramientas de profiling para CPU, memoria y operaciones de I/O.
✔Optimizar timeouts, pooling de conexiones y procesamiento asíncrono.

Requisitos previos

  • Conocimientos sólidos de Backend y construcción de APIs REST.
  • Experiencia con bases de datos relacionales (PostgreSQL o MySQL).
  • Familiaridad con HTTP, headers y procesos de red.
  • Un proyecto propio o de práctica para aplicar los optimizaciones.
