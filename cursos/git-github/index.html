Git y GitHub

Controla versiones de tu código: commits, branches, merge, rebase, pull requests y el flujo de trabajo profesional con Git y GitHub.

4 semanas 5 módulos · 25 lecciones Git · GitHub · Colaboración

¿Qué vas a aprender?

Git es el sistema de control de versiones que usa la inmensa mayoría de la industria, y GitHub es la plataforma donde viven los repositorios. Aprenderás a versionar tus proyectos con commits limpios, ramas, merges y rebase, y a colaborar en equipo con pull requests y code review. Terminarás dominando el flujo de trabajo profesional que se espera en cualquier equipo de desarrollo, sea frontend o backend.

Objetivos de aprendizaje

✔Gestionar el historial de tu proyecto con commits y estados.
✔Trabajar con ramas, fusiones y resolución de conflictos.
✔Colaborar en GitHub: forks, pull requests e issues.
✔Aplicar flujos profesionales: Git Flow y GitHub Flow.
✔Escribir commits claros y revisar el código de tu equipo.

Requisitos previos

  • Ninguno. Solo instalar Git en tu equipo.
  • Conocer la terminal con comandos básicos (ls, cd, pwd).
  • Un proyecto propio (aunque sea pequeño) para practicar.

Tecnologías y herramientas

Git GitHub Branches Pull Requests Rebase

Módulos del curso

Cinco módulos para pasar de tus primeros commits a la colaboración profesional en equipo.

1. Fundamentos de Git

Instala Git, inicializa tu primer repositorio y comprende el ciclo de vida de un archivo.

5 lecciones≈ 40 min
  • ¿Qué es un control de versiones?
  • Instalando y configurando Git
  • git init y el primer commit
  • El ciclo de vida: modificado, preparado y confirmado
  • Viendo el historial con git log

2. Ramas

Ramas y fusiones: trabaja en paralelo sin romper tu código.

5 lecciones≈ 45 min
  • Creando y moviéndote entre ramas
  • git merge y sus tipos
  • Conflictos: qué pasó y cómo resolverlos
  • Revert y cherry-pick
  • Ramas remotas y seguimiento

3. Rebase y workflow

Reescribe el historial con rebase y adopta los flujos de equipo estándar.

5 lecciones≈ 48 min
  • git rebase y el modo interactivo
  • Squash: unificando commits
  • Git Flow explicado
  • GitHub Flow y trunk-based
  • Etiquetas y releases con git tag

4. GitHub

Tu código en la nube: repositorios remotos, issues, proyectos y colaboración.

5 lecciones≈ 45 min
  • Creando repos e integración remota
  • Pull requests y code review
  • Issues y tableros de proyecto
  • Actions básicos y CI
  • Forks y contribuciones a open source

5. Buenas prácticas

Convenciones y hábitos de equipo: commits atómicos, .gitignore y licencias.

5 lecciones≈ 40 min
  • Conventional Commits
  • Commits atómicos y mensajes claros
  • .gitignore y archivos generados
  • Licencias de código abierto
  • Flujo diario: pull, branch, commit y push
