Módulos del curso

7 módulos con 34 lecciones en total.

Módulo 1 · Fundamentos de Git

5 lecciones≈ 49 min

Aprende qué es Git y GitHub, configura tu entorno, da tus primeros commits y entiende el staging area y la visualización de cambios con git diff.

  1. Ciclo de vida de un archivo
  2. Commits buenos y mensajes
  3. git init y configuración
  4. ¿Qué es Git y GitHub?
  5. Staging area y git diff
Empezar módulo

Módulo 2 · Ramas y merges

5 lecciones≈ 50 min

Crea y cambia de ramas, fusiona tu trabajo con git merge, resuelve conflictos y elige una estrategia de flujo como GitFlow.

  1. Conflictos y cómo resolverlos
  2. Crear y cambiar de rama
  3. git merge: fusionando trabajo
  4. GitFlow y estrategias de flujo
  5. Ramas: por qué y para qué
Empezar módulo

Módulo 3 · GitHub y remotos

5 lecciones≈ 50 min

Clona, trae y envía cambios con git pull y git push, gestiona remotos, usa .gitignore para archivos molestos y entiende el tracking de ramas remotas.

  1. git clone y git pull
  2. git push y GitHub
  3. .gitignore y archivos grandes
  4. Ramas remotas y tracking
  5. Remotos y git remote
Empezar módulo

Módulo 4 · Colaboración y PR

5 lecciones≈ 50 min

Colabora como un equipo profesional: forks, issues, pull requests, revisión de código con comentarios y el flujo diario de trabajo en equipo.

  1. Forks y colaboradores
  2. Issues y gestión de proyectos
  3. Pull requests
  4. Revisar código y comentarios
  5. Trabajo en equipo y flujo diario
Empezar módulo

Módulo 5 · Git avanzado

5 lecciones≈ 50 min

Profundiza en git log, reescribe la historia con rebase, recupera el trabajo con reflog, y gestiona stash, worktrees, tags y releases.

  1. git log en profundidad
  2. git revert y git reset
  3. Rebase y reescribir historia
  4. Stash y worktrees
  5. Tags y releases
Empezar módulo

Módulo 6 · Colaboración avanzada y code review

4 lecciones≈ 42 min

Eleva el nivel del equipo: code reviews efectivos y constructivos, branch protection, convenciones de commits y hooks de Git para automatizar la calidad.

  1. Code review efectivo y comentarios constructivos
  2. Protected branches y reglas del repositorio
  3. Semantic commits, convenciones y changelogs
  4. Git hooks y automatización local
Empezar módulo

Módulo 7 · Git en equipos grandes

5 lecciones≈ 54 min

Adopta GitHub Actions para CI/CD, gestiona monorepos y repositorios grandes, haz cirugía de historial con reflog y define estrategias de branching multiteam.

  1. GitHub Actions: CI/CD sobre tu historial
  2. Monorepos y gestión a escala
  3. Troubleshooting avanzado: reflog y cirugía segura
  4. Contribuir a proyectos open source
  5. Branching multiteam
