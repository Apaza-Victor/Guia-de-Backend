Staging area y git diff

💻 Básico 10 min Git y GitHub Módulo 1 · Fundamentos de Git

El escenario te da control

Mucha gente hace git add -A && git commit a secas y pierde la oportunidad de crear commits atómicos. La staging area existe para que tú decidas exactamente qué va en esta foto y qué espera en el siguiente commit.

git diff: ver antes de sellar

Selección quirúrgica con git add -p

Así separas dos cambios que viven en el mismo archivo (un fix y un feature) en dos commits distintos.

El combo habitual

Ejercicio

  1. Haz dos cambios en un archivo y sepáralos con git add -p.
  2. Crea dos commits atómicos con sus mensajes.
  3. Comprueba el resultado con git log --oneline.

Resumen

  • El stage es tu control quirúrgico sobre el commit.
  • git diff vs --cached distinguen zonas.
  • git add -p separa trozos dentro de un archivo.
  • Revisa siempre antes de sellar.
