¿Qué es Git y GitHub?

💻 Básico 9 min Git y GitHub Módulo 1 · Fundamentos de Git

Control de versiones sin dolor

Git es un sistema de control de versiones: guarda cada cambio de tu proyecto como un punto en el tiempo (commit) y te deja volver a cualquiera de ellos. Funciona en local, sin internet, y guarda la historia completa en tu carpeta .git.

El grafo de commits

Git vs GitHub

GitGitHub
Herramienta de línea de comandosPlataforma web que lo aprende encima
Local (y puedes empujar a remotos)Hosting remoto + issues + PR + CI
Lo tienes al instalarCuenta y repos en la nube

GitLab, Bitbucket o Gitea cumplen el mismo rol que GitHub; Git es el común.

Directorio de trabajo

Ejercicio

  1. Ejecuta git --version en tu terminal.
  2. Busca la carpeta .git de un proyecto existente.
  3. Escribe con tus palabras la diferencia Git vs GitHub.

Resumen

  • Git guarda la historia local de tu código con commits.
  • Los commits forman un grafo, nunca se pierden.
  • GitHub es una plataforma remota encima de Git.
  • Todo vive en .git dentro de tu proyecto.
