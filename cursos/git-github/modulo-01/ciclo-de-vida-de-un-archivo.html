Ciclo de vida de un archivo

💻 Básico 10 min Git y GitHub Módulo 1 · Fundamentos de Git

Tres estados, tres zonas

  • Untracked / modificado: Git lo ve pero no lo guarda.
  • Added (stage): preparado para el próximo commit.
  • Committed: sello de la foto completa en la historia.

git add, el escenario

git commit, la foto

Cada commit guarda una fotografía completa (no solo las diferencias) con autor, hora y mensaje. git commit -a -m hace add+commit de los modificados ya rastreados.

Salir del stage sin drama

Ejercicio

  1. Crea un archivo, add y commit; repite 2 veces.
  2. Modifica uno, mira git status --short.
  3. Deshaz un stage con git restore --staged.

Resumen

  • Untracked → staged → committed.
  • git add pone en el escenario; git commit sella la foto.
  • Los commits son completos e inmutables.
  • git restore deshace sin romper la historia.
