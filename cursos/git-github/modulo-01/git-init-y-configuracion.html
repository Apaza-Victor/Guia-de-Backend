git init y configuración

💻 Básico 10 min Git y GitHub Módulo 1 · Fundamentos de Git

Tu identidad en Git

Git firma cada commit con tu nombre y correo: es tu firma pública en cada colaboración. Se configura global (todos tus repos) o local (solo este).

El primer repositorio

git init marca la carpeta como repositorio. Desde aquí, Git empieza a observar tus archivos.

git status: el mapa del proyecto

  • ?? archivo sin rastrear.
  • A añadido al stage.
  • M modificado (aún sin stage).

Ejercicio

  1. Configura tu nombre y correo global.
  2. Crea mi-proyecto/, git init y un README.
  3. Ejecuta git status y git status --short.

Resumen

  • Configura nombre/email: tu firma en cada commit.
  • git init convierte la carpeta en repositorio.
  • git status muestra el estado real.
  • --short resume con una letra por archivo.
