git push y GitHub

💻 Básico 10 min Git y GitHub Módulo 3 · GitHub y remotos

Subir tu trabajo

Crear el repo en GitHub

Push rechazado

Push mientras tu equipo espera

Ejercicio

  1. Sube la rama main con git push -u origin main.
  2. Comprueba en GitHub que el código y los commits están.
  3. Haz un commit y repite el push: ahora la flecha solo tiene que avanzar.

Resumen

  • git push origin rama sube commits.
  • -u deja el seguimiento registrado.
  • Rechazo = remoto más adelantado: pull y repite.
  • Push temprano y frecuente; GitHub es tu seguro.
