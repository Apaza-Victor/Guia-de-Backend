git clone y git pull

💻 Básico 10 min Git y GitHub Módulo 3 · GitHub y remotos

Traer el proyecto entero

fetch vs pull

Un pull sano

Secuencia habitual

Ejercicio

  1. Clona un repositorio real (p. ej. el de docs de Git).
  2. Compara git fetch y git pull con git status.
  3. Practica git pull --ff-only en vez del pull simple.

Resumen

  • clone copia todo y deja el remoto listo.
  • fetch baja sin tocar tu trabajo.
  • pull = fetch + merge.
  • --ff-only evita merges accidentales.
