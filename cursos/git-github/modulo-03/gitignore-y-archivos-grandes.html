.gitignore y archivos grandes

💻 Básico 10 min Git y GitHub Módulo 3 · GitHub y remotos

Por qué ignorar cosas

Git guarda historia para siempre. Lo que entra ya no sale barato. Secretos, dependencias y bins gigantes son las tres cosas que nunca deberías comprometer.

Un buen punto de partida

Sintaxis de patrones

Si ya entró al historial

Archivos grandes

Ejercicio

  1. Crea un .gitignore para tu proyecto actual.
  2. Prueba git status --ignored para verificar.
  3. Si ya commiteaste un .env, sácalo con git rm --cached.

Resumen

  • Secretos, dependencias y bins: fuera del repo.
  • Patrones: carpetas, globs, anclas y excepciones.
  • git rm --cached deja de trackear sin borrar.
  • Bins grandes van a un storage, no al historial.
