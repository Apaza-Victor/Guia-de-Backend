Remotos y git remote

💻 Básico 10 min Git y GitHub Módulo 3 · GitHub y remotos

Qué es un remoto

Un remoto es una copia del repositorio en otro sitio (normalmente GitHub). Tu máquina tiene la tuya; el remoto es el punto de encuentro del equipo. Por convención la URL principal se guarda con el alias origin.

Ejercicio

  1. Crea un repositorio vacío en GitHub (sin README).
  2. Asócialo a tu repo local con git remote add origin URL.
  3. Verifica con git remote -v y haz un fetch.

Resumen

  • Remoto = repositorio compartido; origin es el alias típico.
  • git remote -v muestra las URLs.
  • git fetch descarga sin mezclar.
  • HTTPS para lo simple, SSH para el día a día.
