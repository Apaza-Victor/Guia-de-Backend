Ramas remotas y tracking

💻 Básico 10 min Git y GitHub Módulo 3 · GitHub y remotos

origin/rama no es tu rama

origin/main es una referencia de solo lectura: la foto del remoto. Tu main local es otra cosa, editable. La única puerta por la que se mueve origin/main son fetch/push.

Ver las ramas remotas

Establecer la rama que sigues

La vida con upstream

Ejercicio

  1. Crea una rama y súbela con -u.
  2. Revisa git branch -vv y git status.
  3. Borra la rama remota con git push origin --delete.

Resumen

  • origin/x es solo una foto del remoto.
  • push -u registra la relación de seguimiento.
  • Con upstream, push/pull no necesitan argumentos.
  • --delete para limpiar el remoto.
