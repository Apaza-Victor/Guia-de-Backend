git blame: quién y cuándo

Búsqueda en toda la historia

Ejercicio

  1. Muestra tu repo con --oneline --graph --all.
  2. Busca cuándo cambió una función con -S.
  3. Investiga una línea sospechosa con git blame.

Resumen

  • --graph --all: el mapa de tu repo.
  • Filtros por autor, fecha, texto y archivo.
  • git blame responde el porqué actual.
  • -S encuentra línea difíciles en la historia.
