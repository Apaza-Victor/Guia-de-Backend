Rebase y reescribir historia

💻 Básico 10 min Git y GitHub Módulo 5 · Git avanzado

Rebase = re-poner commits sobre otra rama

Donde el merge crea un commit de unión, el rebase reconstruye tus commits al día de hoy. La historia queda lineal y sin ruido de "merge brotes". Ojo: cambia los hashes de tus commits.

Ejercicio

  1. En una rama propia: funde 3 commits en 1 con rebase -i.
  2. Rebasea tu feature sobre main actualizado.
  3. Comprueba con git log --graph la línea limpia.

Resumen

  • Rebase = historia lineal, commits re-aplicados.
  • -i: squash, reword y reordenar.
  • Ramas compartidas NO se reescriben.
  • --force-with-lease solo con consciencia.
