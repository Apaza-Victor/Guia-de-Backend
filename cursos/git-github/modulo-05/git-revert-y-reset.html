git revert y git reset

💻 Básico 10 min Git y GitHub Módulo 5 · Git avanzado

Revert vs reset: público vs privado

Cuando el error ya está compartido (push, PR), usas git revert: crea un commit nuevo que deshace el malo. Cuando el error solo vive en tu máquina, usas git reset: mueves la historia hacia atrás.

Revert: deshacer en público

Reset: borrar historia privada

La red de seguridad

Ejercicio

  1. Rompan un commit en una rama propia y deshácelo con revert.
  2. Practica los 3 modos de reset y observa dónde van los cambios.
  3. Recupera un commit "perdido" con git reflog.

Resumen

  • Revert: deshace en público, sin borrar historia.
  • Reset: mueve hacia atrás; soft/mixed/hard.
  • --hard descarta todo: anota el hash.
  • Reflog salva incluso a los despistados.
