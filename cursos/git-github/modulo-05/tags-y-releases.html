Tags y releases

💻 Básico 10 min Git y GitHub Módulo 5 · Git avanzado

Un tag marca un momento

Un tag pone nombre a un commit exacto: v1.4.0, v2.0.0-rc1. El release de GitHub envuelve ese tag con notas visibles, changelog y los artefactos que los usuarios descargan.

Crear tags

Subir tags al remoto

Publicar el release

Ejercicio

  1. Crea el tag v0.1.0 de tu último commit.
  2. Súbelo con git push origin y publica el release.
  3. Escribe un changelog que otro dev entienda sin ti.

Resumen

  • Tag = nombre inmutable para un commit.
  • Anotados con mensaje: la opción seria.
  • Los tags suben con git push --tags.
  • Release = tag + changelog + artefactos.
