Crear y cambiar de rama

💻 Básico 10 min Git y GitHub Módulo 2 · Ramas y merges

Crear una rama

Moverse entre ramas

Borrar ramas sin miedo

Ejercicio

  1. Crea feature/blog con git switch -c.
  2. Haz un commit y regresa a main.
  3. Bórrala con git branch -D y verifica git branch.

Resumen

  • git branch lista/crea; git switch mueve.
  • -c crea y mueve en uno; - vuelve atrás.
  • Cambios sucios te detienen: commit o stash.
  • -d vs -D para borrar con juicio.
