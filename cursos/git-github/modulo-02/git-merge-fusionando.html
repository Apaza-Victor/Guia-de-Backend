git merge: fusionando trabajo

💻 Básico 10 min Git y GitHub Módulo 2 · Ramas y merges

Juntar dos caminos

git merge trae los commits de una rama a la actual. Puede terminar en un fast-forward (sin commit nuevo) o en un merge 3-way (con commit de unión). También puede toparse con un conflicto (siguiente lección).

Ejercicio

  1. Haz un cambio en main y otro en feature/x.
  2. Fusiona y observa si fue fast-forward o 3-way.
  3. Repite con --no-ff y compara el gráfico.

Resumen

  • Fast-forward: historia lineal, sin commit extra.
  • 3-way: commit de unión con dos padres.
  • --no-ff preserva el agrupamiento de la feature.
  • Estado limpio + pull antes de fusionar.
