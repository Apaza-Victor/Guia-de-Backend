Pull requests

💻 Básico 10 min Git y GitHub Módulo 4 · Colaboración y PR

Un PR es una propuesta

Un pull request dice: "quiero que estas ramas se fusionen". Vive en GitHub: ahí se compara, se revisa, se comenta y se decide. No es un comando de Git, es un componente del equipo.

Abrir el PR

Describir bien

Vivir con el PR

Fusionar con estilo

Ejercicio

  1. Sube una rama y abre un PR contra main.
  2. Escribe una descripción con la plantilla de arriba.
  3. Fusiónalo con squash y borra la rama remota.

Resumen

  • PR = propuesta de fusión revisable en GitHub.
  • La descripción dice qué, por qué y cómo probar.
  • Los cambios llegan por la misma rama, el PR se actualiza.
  • Merge, squash o rebase: decisión de equipo.
