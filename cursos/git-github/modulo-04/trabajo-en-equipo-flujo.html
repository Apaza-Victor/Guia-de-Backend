Trabajo en equipo y flujo diario

💻 Básico 10 min Git y GitHub Módulo 4 · Colaboración y PR

La rutina de trabajo

Menos magia, más hábito. Un día normal de un dev con Git y GitHub se parece mucho a esta secuencia (GitHub Flow).

De la mañana al merge

Reglas que salvan al equipo

La dinámica diaria

Ejercicio

  1. Simula el flujo completo con un compañero (o un segundo usuario).
  2. Mide de punta a punta: rama, 3 commits, PR, review, merge.
  3. Anota las reglas que tu equipo aún no tiene y adóptalas.

Resumen

  • Pull al inicio, rama corta, PR pequeño y temprano.
  • Reviews rápidos and main siempre verde.
  • Quien llega después resuelve los conflictos.
  • La cola de PR es la salud del equipo.
