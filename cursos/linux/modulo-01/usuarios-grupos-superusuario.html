Usuarios, grupos y superusuario

💻 Básico 8 min Linux y Terminal Módulo 1 · Fundamentos de Linux

Todo archivo tiene dueño

Cada archivo y proceso tiene un usuario (UID) y un grupo (GID). Los permisos hablan de yo, mi grupo y los demás. Entender las identidades evita el error clásico: correr toda la app como root.

Quién soy y quiénes hay

whoami dice quién eres, id muestra tus UID y GID, y groups la lista de tus grupos. /etc/passwd y /etc/group guardan la base local de identidades.

root y principio de mínimo privilegio

Ejercicio

Ejecuta id y groups y anota UID, GID y grupos. Crea un usuario de app de solo lectura: sudo useradd -r -s /usr/sbin/nologin appsrv.

Resumen

Para seguir aprendiendo
