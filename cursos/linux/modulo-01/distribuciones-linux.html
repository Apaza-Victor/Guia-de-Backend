Distribuciones: Ubuntu, Debian y más

💻 Básico 8 min Linux y Terminal Módulo 1 · Fundamentos de Linux

Este curso se centra en Debian/Ubuntu: lo que aprenderás transfiere al resto cambiando solo el gestor de paquetes.

Ubuntu: el estándar de facto

Alpine: el minimalista de Docker

¿Cuál elijo?

  • ¿Servidor de una app? Ubuntu LTS o Debian estable.
  • ¿Imagen Docker pequeña? Alpine.
  • ¿Empresa con soporte? RHEL/Ubuntu Pro.
  • ¿Aprender? La que toque tu proyecto y una VM para romper sin miedo.

Ejercicio

  1. Identifica tu distro con cat /etc/os-release.
  2. Averigua la versión LTS más reciente de Ubuntu.
  3. Si usas Docker, mira la imagen base de node:alpine y compara tamaños.

Resumen

  • Debian/Ubuntu: la familia de servidores por defecto.
  • Red Hat: empresas y soporte corporativo.
  • Alpine: ligera para contenedores.
  • Ubuntu LTS = estabilidad a 5 años.
