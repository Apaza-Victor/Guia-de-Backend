¿Qué es Linux y por qué en el backend?

💻 Básico 8 min Linux y Terminal Módulo 1 · Fundamentos de Linux

Linux es el núcleo, no el sistema

Linux es el kernel: el software que habla con el hardware y reparte recursos (CPU, memoria, discos) entre los programas. Lo que instalas es una distribución: el kernel + programas + gestor de arranque, empaquetados juntos.

El rey de los servidores

El paisaje: núcleo y capas

Tu primera mirada al sistema

Ejercicio

  1. Abre la terminal (WSL, macOS o Linux) y escribe uname -a.
  2. Mira cat /etc/os-release para saber tu distro.
  3. Anota qué kernel y qué arquitectura corres.

Resumen

  • Linux = kernel; distribución = todo el sistema.
  • Dominio en servidores por costo, estabilidad y ecosistema.
  • Backend vive en la capa de shell y aplicaciones.
  • uname, whoami y free para orientarte.
