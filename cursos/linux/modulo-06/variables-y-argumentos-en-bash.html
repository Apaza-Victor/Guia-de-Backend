Variables y argumentos en Bash

💻 Básico 9 min Linux y Terminal para Backend Módulo 6 · Scripting y automatización

Introducción

Un script que solo imprime texto no sirve de nada: quieres guardar rutas, aceptar parámetros y leer la salida de otros comandos.

Las variables y los argumentos dan esa flexibilidad. Y las comillas son la diferencia entre copiar una ruta con espacios y destruirla.

Definición

En Bash las variables se asignan sin espacios (nombre=valor) y se leen con $. Los argumentos se llaman $1, $2… $@, y las comillas dobles preservan espacios dentro del valor.

Por qué importa. Los scripts reutilizables dependen de parámetros y de manejar correctamente los valores: rutas con espacios y salida de subshells son la pesadilla clásica.

Cuándo usarlo. Usa variables para todo valor repetido y argumentos para hacer el script parametrizable desde la línea de comandos.

Conceptos clave

  • MI_VAR=/srv/tienda asigna; echo "$MI_VAR" lee.
  • $1, $2, … $9 son los argumentos posicionales.
  • $# cuenta argumentos; $@ lista todos.
  • Las comillas dobles preservan los espacios.
  • $(comando) captura la salida y la convierte en valor.

Un valor entre comillas dobles se trata como un solo argumento, hagan lo que hagan los espacios. Tu script lo agradece.

Explicación

  • La asignación nunca lleva espacios alrededor del =.
  • Las comillas dobles guardan espacios; las simples literal total.
  • $(...) ejecuta un subshell y guarda su stdout.
  • ${var:-porDefecto} aporta un default ante variable vacía.
  • $? guarda el código del último comando.

Errores comunes

  • Partir rutas con espacios por no comillar la variable.
  • Asignar con espacios: nombre = valor (comando no encontrado).
  • Usar comillas simples y que el contenido no interpole variables.

Buenas prácticas

  • Comilla doble TODO lo que pueda contener espacios.
  • Usa ${1:?mensaje} para argumentos obligatorios.
  • Valida las variables críticas al inicio.

Ejercicio

  1. Crea un script que copie un origen a un destino parametrizado.
  2. Usa $(date +%F) para nombres con fecha.
  3. Protege una ruta con espacios usando comillas.

Resumen

  • Variables y argumentos hacen los scripts parametrizables.
  • Las comillas dobles preservan valores con espacios.
  • $(comando) convierte salidas del sistema en valores útiles.
