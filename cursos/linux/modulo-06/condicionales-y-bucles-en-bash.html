Condicionales y bucles en Bash

💻 Básico 11 min Linux y Terminal para Backend Módulo 6 · Scripting y automatización

Introducción

Un script poderoso decide y repite: si el backup existe, salta; para cada archivo, verifica; mientras el proceso no termine, espera.

if, for y while convierten tus recetas en programas que se adaptan al estado del sistema en lugar de asumirlo.

Definición

if evalúa una condición (test) y decide; for recorre una lista; while repite mientras la condición se cumpla. Todos viven con fi y done para cerrar su bloque.

Por qué importa. Automatizar sin decidir ni repetir es solo pegar comandos. Con condicionales y bucles tus scripts resuelven casos reales: reintentos, validaciones y barridos.

Cuándo usarlo. Úsalos para verificar estados (existe el archivo, hay conexión), procesar colecciones de archivos o esperar a que un proceso termine.

Conceptos clave

  • if [ condicion ]; then … fi evalúa una condición.
  • El test [ -f archivo ], [ -z var ], [ -n var ] son los básicos.
  • for item in lista; do … done recorre cada elemento.
  • while [ condicion ]; do … done repite mientras se cumpla.
  • break sale del bucle; continue salta el resto de la vuelta.

Ejemplo básico

Un script que decide según exista un archivo y recorre una lista.

Ejemplo intermedio

Esperar con while a que un proceso termine, con salida controlada.

Ejemplo real

Un script de mantenimiento que recorre archivos viejos por fechas y decide su destino.

  • Usa -f, -d y -z para verificar archivos, directorios y vacíos.
  • Los bucles escriben pocas líneas que hacen mucho.
  • Siempre un limite de reintentos en los while.

Los bucles con for recogen patrones (ls *.log), y el continue salta elementos sin matar el proceso.

Explicación

  • El test [ -f ] devuelve verdadero si el archivo existe.
  • for recorre cualquier lista separada por espacios.
  • while mantiene el bucle vivo mientras la condición valga.
  • El contador INTENTOS con $((...)) permite límites.
  • break/continue afinan el control dentro de los bucles.

Errores comunes

  • Olvidar el then/fi y lanzar errores de sintaxis.
  • Dejar un while sin condición de salida (bucle infinito).
  • Comparar strings con -eq (eso es numérico).

Buenas prácticas

  • Escribe la condición entre corchetes con espacios: [ x ].
  • Usa [[ ]] en bash moderno para más operadores.
  • Limita cualquier while a unos pocos reintentos.

Ejercicio

  1. Escribe un if que valide la existencia de un archivo de config.
  2. Recorre con for los servicios y reporta su estado.
  3. Crea un while que espere un proceso con límite.

Resumen

  • if decide, for recorre y while espera.
  • Los tests con [ ] verifican archivos, strings y números.
  • Todo bucle repetitivo lleva límite para no colgarse.
