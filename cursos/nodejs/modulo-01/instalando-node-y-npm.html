Instalando Node.js y npm

⚙️ Intermedio 8 min Node.js desde cero hasta avanzado Módulo 1 · Introducción a Node.js

Qué vas a instalar

Node.js es un runtime que ejecuta JavaScript fuera del navegador. Al instalarlo, recibes dos herramientas en una:

  • node: el intérprete que ejecuta tus scripts.
  • npm: el gestor de paquetes oficial, con más de dos millones de paquetes publicados.

La vía más sencilla y recomendada es descargar el instalador desde la página oficial de Node.js y elegir la línea LTS (Long Term Support): recibe soporte y actualizaciones de seguridad durante años, lo que importa en producción.

Instalación por sistema

En Windows puedes usar el instalador .msi o el gestor choco. En macOS, el gestor nativo brew. En Linux, el gestor oficial de Node (NodeSource) ofrece las versiones más recientes por apt.

También existe nvm (Node Version Manager), que permite instalar y alternar varias versiones de Node en la misma máquina. Es la herramienta favorita de los equipos que trabajan en varios proyectos porque cada proyecto puede pedir una versión distinta.

package.json es el corazón de cualquier proyecto Node: guarda el nombre, la versión, los scripts y las dependencias. Lo estudiaremos en detalle en el módulo 2.

Ejercicio

  1. Instala Node.js (LTS) en tu sistema por el método que prefieras.
  2. Ejecuta node -v y npm -v y anota ambas versiones.
  3. Abre el REPL con node y calcula el resultado de 10 * 3 + 2.
  4. Crea una carpeta de proyecto y ejecuta npm init -y. Abre el package.json generado y localiza los campos name y main.

Resumen

  • Node.js incluye el runtime node y el gestor npm.
  • La versión LTS es la recomendada para producción.
  • node -v y npm -v verifican el entorno.
  • node sin argumentos abre la consola interactiva (REPL).
  • npm init -y crea el package.json de tu proyecto.
