Módulo 1 · Introducción a Node.js

Instala Node.js, entiende qué pasa al ejecutar un script y descubre el modelo basado en eventos.

5 lecciones ≈ 48 min JavaScript básico recomendado

Objetivos del módulo

✔Instalar Node.js y npm y comprobar su versión desde la terminal.
✔Ejecutar tu primer script de JavaScript del lado del servidor.
✔Entender qué es el runtime V8 y las APIs nativas que aporta Node.
✔Usar los módulos core path, fs y os en programas reales.
✔Explicar el event loop: la razón de que Node nunca se bloquee esperando.
