Módulos core: path, fs y os

⚙️ Intermedio 10 min Node.js desde cero hasta avanzado Módulo 1 · Introducción a Node.js

¿Por qué módulos core?

Node separa sus capacidades en módulos: paquetes de funciones relacionados que cargas cuando los necesitas. Los módulos core vienen dentro de Node (no hay que instalarlos) y se importan con require("node:modulo").

El prefijo node: deja claro que es un módulo nativo y evita confusiones con paquetes de npm del mismo nombre.

path: rutas sin dolor

Trabajar con rutas a mano es frágil porque Windows y Unix usan separadores distintos (\ frente a /). El módulo path normaliza y compone rutas para cualquier plataforma.

Cuando tu programa necesita saber dónde está su propio código, node nos regala dos ayudantes: __dirname (carpeta del archivo) y __filename (ruta completa del archivo). Son imprescindibles para localizar recursos como plantillas o configuraciones.

fs: sistema de archivos

El módulo fs (file system) lee, escribe, mueve y elimina archivos y directorios. Todo lo que hagas con archivos tiene versiones síncronas (bloquean) y asíncronas (recomendadas en servidores).

En un servidor HTTP elige siempre las versiones asíncronas: una llamada síncrona detendría la atención de todas las peticiones mientras espera al disco. Las síncronas quedan para scripts de arranque o CI.

os: el sistema operativo

El módulo os proporciona información de la máquina: arquitectura, memoria, red y CPUs. Es útil para logs de despliegue, métricas y configuraciones.

Una buena práctica de operaciones: en el arranque de la app, registrar una línea de logs con plataforma, CPUs y memoria para saber en qué servidor está corriendo cada instancia.

Ejercicio

  1. Crea datos.txt con dos líneas y léelo de forma síncrona y asíncrona.
  2. Usa path.join para construir la ruta de un archivo en la subcarpeta logs y muéstrala.
  3. Crea config.json y cárgalo combinando fs + path + JSON.parse.
  4. Registra en la consola la arquitectura y la memoria libre de tu máquina con os.

Resumen

  • Los módulos core se importan con require("node:modulo").
  • path compone y analiza rutas: join, dirname, basename, extname.
  • fs maneja archivos; prefiere las versiones asíncronas en servidores.
  • os informa de la máquina: plataforma, CPUs y memoria.
  • Combinar módulos core resuelve la mayoría de tareas de arranque de un servicio.
