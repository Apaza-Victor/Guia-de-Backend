En el navegador, console.log escribe en las DevTools. En Node, escribe en la terminal: no hay pantalla, ni DOM, ni ventanas. El mismo lenguaje, un entorno completamente distinto.

Node.js vs navegador

JavaScript nació en el navegador, pero Node lo sacó de allí. Las diferencias esenciales que debes interiorizar:

  • Sin DOM: no existen document, window ni alert.
  • Con acceso al sistema: Node puede leer archivos, escuchar puertos y lanzar procesos.
  • Globales propias: process describe el proceso actual; require y module montan el sistema de módulos.
  • Mismo lenguaje: funciones, objetos, promesas y async/await funcionan igual.

El global process

process es la ventana de tu programa hacia el sistema operativo: versión de Node, argumentos, variables de entorno y salida del proceso.

Prueba a ejecutarlo así: node hola.js Ana. Verás que los argumentos llegan a process.argv: las dos primeras posiciones son siempre la ruta de Node y la del script.

Resumen

  • Node ejecuta JavaScript fuera del navegador: no hay DOM ni window.
  • Los scripts se ejecutan con node archivo.js.
  • process expone versión, plataforma, argumentos y variables de entorno.
  • process.stdin y el módulo readline permiten leer la entrada del usuario.
  • El código de salida determina si el proceso terminó bien (0) o con error (1).
