Node.js desde cero hasta avanzado

Aprende JavaScript del lado del servidor: Node.js, npm, HTTP, Express, REST APIs y arquitectura escalable para el backend moderno.

10 semanas 8 módulos · 38 lecciones Node.js · Express · npm

¿Qué vas a aprender?

Node.js lleva JavaScript al servidor: el mismo lenguaje del frontend, ahora para construir APIs, servicios y herramientas rápidas y escalables. Aprenderás desde cómo funciona el event loop y la asincronía, hasta Express, bases de datos y el despliegue de aplicaciones en producción. Es la puerta de entrada al backend moderno basado en eventos, ideal para servicios en tiempo real y APIs de alto rendimiento.

Categoría⚙️ Backend

Objetivos de aprendizaje

✔Dominar el modelo de asincronía de Node.js: callbacks, promesas y async/await.
✔Crear servidores y APIs REST con Express: rutas, middlewares y manejo de errores.
✔Integrar bases de datos (MongoDB y MySQL) con drivers y ORMs.
✔Organizar el proyecto en capas: servicios, repositorios y validación.
✔Llevar tu aplicación a producción: configuración, logs y despliegue.

Requisitos previos

  • Fundamentos de Backend: conocer HTTP, cliente-servidor y request/response.
  • Programación para Backend: lógica, funciones y estructuras de datos.
  • JavaScript básico: variables, funciones y objetos, para agilizar la lectura del curso.

Tecnologías y herramientas

Node.js Express npm MongoDB JWT Docker

Módulos del curso

Ocho módulos que van del primer script al servicio en producción: el runtime, la asincronía, Express, datos y arquitectura.

1. Introducción a Node.js

Instala Node.js, entiende qué pasa al ejecutar un script y descubre el modelo basado en eventos.

5 lecciones≈ 42 min
  • Instalando Node.js y npm
  • Ejecutando tu primer script
  • El runtime de Node: V8 y APIs nativas
  • Módulos core: path, fs y os
  • El event loop explicado

2. Módulos y npm

Organiza tu código en módulos y aprende a gestionar dependencias con el registro de npm.

5 lecciones≈ 45 min
  • Módulos CommonJS y ES Modules
  • Creando tus propios módulos
  • npm: init, install y scripts
  • Dependencias, devDependencies y lockfile
  • Versionando y publicando paquetes

3. Asincronía avanzada

Callbacks, promesas y async/await: escribe código no bloqueante y entiende la concurrencia.

5 lecciones≈ 52 min
  • Callbacks y el infierno de callbacks
  • Promesas y encadenamiento
  • async/await y try/catch
  • Métodos útiles: Promise.all y Promise.race
  • Procesos en paralelo con Worker Threads

4. HTTP y Express

Del módulo http a Express: rutas, middlewares, parámetros y respuestas JSON profesionales.

5 lecciones≈ 55 min
  • El módulo http: servidores desde cero
  • Introducción a Express
  • Rutas: query y path params
  • Middlewares y validación
  • Manejo de errores centralizado

5. Bases de datos

Conecta tus APIs con datos reales: MongoDB con Mongoose y SQL con MySQL.

5 lecciones≈ 55 min
  • Node y las bases de datos
  • MongoDB y el modelo de documentos
  • Mongoose: esquemas y modelos
  • MySQL con consultas seguras
  • Migraciones y seed de datos

6. REST APIs con Node

Construye una API completa: diseño REST, autenticación JWT, validación y tests.

5 lecciones≈ 55 min
  • Diseño REST aplicado
  • CRUD completo con Express
  • Validación de entrada con Zod
  • Autenticación con JWT y refresh tokens
  • Testing básico con supertest

7. Arquitectura escalable

Separa responsabilidades: controladores, servicios, repositorios y configuración por entorno.

4 lecciones≈ 42 min
  • Separación por capas
  • Patrones de servicio y repositorio
  • Variables de entorno y config
  • Estructura de carpetas y buenas prácticas

8. Producción y despliegue

Logs, variables de entorno, gestores de procesos y contenedores para un servidor confiable.

4 lecciones≈ 40 min
  • Logging y monitoreo básico
  • Variables de entorno en producción
  • PM2: gestor de procesos
  • Dockerizando tu aplicación Node
