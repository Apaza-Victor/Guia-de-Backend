Versionando y publicando paquetes

⚙️ Intermedio 9 min Node.js desde cero hasta avanzado Módulo 2 · Módulos y npm

Semver: mayor.menor.patch

Casi todos los paquetes de npm siguen Semantic Versioning (SemVer), un contrato en tres números:

  • MAJOR: cambios que no son compatibles hacia atrás. El 1 a 2 significa "puede que se rompa tu código".
  • MINOR: nuevas funcionalidades compatibles.
  • PATCH: correcciones de errores sin cambios de comportamiento.

La regla de oro: 1.2.3 = major 1, minor 2, patch 3. Un bugfix sube el patch; una función nueva, el minor; un cambio que rompe, el major.

Rangos de versiones en package.json

En las dependencias casi nunca escribes una versión exacta: escribes un rango. npm resuelve el rango y el lockfile congela la elección exacta.

El caret ^ es el predeterminado: permite minor y patch dentro del mismo major. La práctica recomendada: escribir ^ y dejar que el lockfile fije lo exacto.

Publicar tu primer paquete

Publicar en el registro de npm es gratuito para paquetes públicos. El flujo básico:

npm version además crea un tag de Git si estás en un repositorio, conectando versión de paquete y commit.

Qué entra en el paquete

El campo main apunta al archivo que se cargará al hacer require("util-precios"). El script prepublishOnly ejecuta los tests justo antes de publicar: una red de seguridad gratuita.

Ejercicio

  1. Crea un paquete mínimo con util-precios: una función y su package.json con files y prepublishOnly.
  2. Ejecuta npm pack para generar el tarball y abre el .tgz para inspeccionar su contenido.
  3. Traduce al papel: ¿qué rompe un version major para tus consumidores?
  4. Si te atreves, crea una cuenta en npm y publica el paquete de prueba.

Resumen

  • SemVer: MAJOR rompe, MINOR añade, PATCH corrige.
  • Los rangos como ^1.2.3 permiten actualizaciones seguras y el lockfile congela lo exacto.
  • npm publish sube al registro; npm version controla el salto.
  • files decide qué se distribuye y prepublishOnly corre los tests.
  • Escribir * como versión es una bandera roja de mantenibilidad.
