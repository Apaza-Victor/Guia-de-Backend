npm init, install y scripts

⚙️ Intermedio 10 min Node.js desde cero hasta avanzado Módulo 2 · Módulos y npm

package.json: la ficha del proyecto

Todo proyecto Node orbita en torno a package.json: nombre, versión, descripción, scripts y dependencias. Ya lo creaste con npm init -y en el módulo 1; ahora vamos a dominarlo.

El asistente te pedirá datos que verás en el archivo final: name (sin mayúsculas ni espacios), version, description, main (archivo de entrada) y license.

Instalar paquetes

Con npm install bajas paquetes del registro y los guardas en node_modules. Por defecto se registran como dependencia de producción (clave dependencies).

La bandera --save-dev guarda en devDependencies: herramientas solo para desarrollar (linters, test runners), no para correr el servicio. La instalación global se reserva para utilidades de terminal.

Scripts: cientos de comandos en tu mano

Los scripts convierten comandos largos en atajos documentados. Se definen en package.json y se lanzan con npm run.

Los nombres start y test se pueden ejecutar sin run. Otros scripts (como dev) necesitan npm run <nombre>.

Ejercicio

  1. En la carpeta de proyecto del módulo 1, crea server.js con el ejemplo de Express.
  2. Instala express como dependencia de producción.
  3. Instala nodemon como devDependency.
  4. Añade los scripts start y dev y arranca el servidor con cada uno.

Resumen

  • npm init crea el package.json.
  • npm install descarga paquetes a node_modules.
  • --save-dev separa herramientas de desarrollo de las de producción.
  • Los scripts de package.json automatizan comandos comunes.
  • npm start y npm test van sin run; los demás, con npm run.
