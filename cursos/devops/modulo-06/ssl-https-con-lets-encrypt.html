SSL y HTTPS con Let's Encrypt

🔥 Avanzado 12 min DevOps para Backend Módulo 6 · DevOps en el Backend

Por qué HTTPS es obligatorio

Sin HTTPS, las credenciales y los datos que envía tu API viajan en texto plano: cualquiera en la red puede leerlos. Los navegadores además marcan los sitios sin cifrado y las APIs modernas solo aceptan conexiones seguras. Let's Encrypt emite certificados gratis y válidos 90 días, y Certbot los instala y renueva automáticamente.

Instalar y pedir el certificado

Requisito: tu dominio debe apuntar al servidor y Nginx debe estar sirviendo algo en el puerto 80.

Respondiendo las preguntas de Certbot dejas configurado el redireccionamiento HTTP → HTTPS y el plan de renovación.

Verificar que todo está bien

  • Accede con https://api.tudominio.com y mira el candado en el navegador.
  • Comprueba que HTTP redirige: curl -I http://api.tudominio.com debe responder 301.
  • Valida el certificado con un servicio externo o openssl s_client -connect api.tudominio.com:443.

Ejercicio

  1. Si tienes un dominio, emite un certificado con certbot --nginx.
  2. Verifica el redireccionamiento automático de HTTP a HTTPS.
  3. Realiza certbot renew --dry-run y confirma que la renovación funciona.

Resumen

  • HTTPS protege datos y es requisito de las APIs modernas.
  • Let's Encrypt + Certbot dan certificados gratis con renovación automática.
  • El redireccionamiento 301 evita caídas por quienes aún usen HTTP.
  • Prueba la renovación con --dry-run para no llevarte sorpresas.
