Despliegue completo: API con Nginx

🔥 Avanzado 16 min DevOps para Backend Módulo 6 · DevOps en el Backend

La receta completa

Este tutorial final une todas las piezas del módulo en un despliegue de una API real (Flask + Gunicorn + Nginx + systemd + HTTPS). Es el flujo que usarás en cualquier proyecto que mire a producción.

Estructura del servidor

1. Gunicorn como servidor WSGI

Flask solo sirve en desarrollo; para producción se usa un servidor WSGI real (Gunicorn para Python, Uvicorn para FastAPI). Instálalo y configura workers según CPU:

3. Nginx recibe el tráfico

Activa el site y prueba configuración: sudo ln -s ... && sudo nginx -t && sudo nginx -s reload.

4. Certificado y verificación final

Checklist de producción

  • ✔ La API escucha solo en 127.0.0.1; Nginx (público) es la única puerta.
  • ✔ HTTPS activo con redirección 301 desde HTTP.
  • ✔ systemd reinicia la API si muere.
  • ✔ Variables de entorno desde EnvironmentFile, sin secrets en el repo.
  • ✔ Logs estructurados y rotados; healthcheck y métricas expuestos.

Ejercicio

  1. Despliega una API tuya con Gunicorn + systemd + Nginx siguiendo esta receta.
  2. Comprueba que la API no es accesible por el puerto 8000 desde afuera (firewall/escucha local).
  3. Rompe deliberadamente la app y verifica que systemd la reinicia y Nginx reintenta.

Resumen

  • Gunicorn sirve WSGI con varios workers; Flask solo no sirve en producción.
  • systemd mantiene la API viva y la levanta al arrancar.
  • Nginx + TLS + 301 forman la entrada pública segura.
  • Healthcheck, métricas y logs completan el despliegue definitivo.
