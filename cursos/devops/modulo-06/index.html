Módulo 6 · DevOps en el Backend

La infraestructura que sostiene una API de producción: proxy, HTTPS, automatización y observabilidad.

🔥 Avanzado DevOps para Backend Nivel: Avanzado

Objetivos del módulo

Con este módulo llevarás tu API de "funciona en localhost" a "soporta usuarios reales": conectándola detrás de un proxy, protegiéndola con HTTPS y automatizando su operación.

  • Exponer múltiples servicios con Nginx como reverse proxy.
  • Obtener certificados SSL gratis con Let's Encrypt.
  • Escribir tu infraestructura como código versionado.
  • Registrar logs y métricas básicos que valen oro.
  • Desplegar una API completa con Nginx + un servidor WSGI.

5 lecciones · ~65 min · producción real para tu Backend.

1

Reverse proxy con Nginx

Cómo Nginx recibe el tráfico y lo entrega a tu API, con balanceo incluido.

SSL y HTTPS con Let's Encrypt

12 min · seguridad

4

Logs y monitoreo básico

12 min · observabilidad
5

Despliegue completo: API con Nginx

Todo junto: WSGI, systemd, Nginx y HTTPS sirviendo una API real.

16 min · proyecto real
