⚙️ DevOps para Backend

Conecta desarrollo y operaciones con prácticas DevOps: automatiza pipelines de integración y despliegue continuo, configura CI/CD con GitHub Actions y GitLab CI, y lleva tu código del repositorio a producción de forma confiable.

6 semanas 6 módulos · 52 lecciones DevOps · CI/CD · Automatización

¿Qué vas a aprender?

DevOps no es solo una herramienta, es una cultura. En este curso aprenderás los principios del movimiento DevOps, a diseñar y ejecutar pipelines de CI/CD, a automatizar pruebas y despliegues con GitHub Actions y GitLab CI, a gestionar servidores con infraestructura como código y a monitorear aplicaciones en producción. Todo con ejemplos aplicados a proyectos Backend reales.

Objetivos del curso

✔Entender la cultura DevOps y por qué transforma la forma de desarrollar software.
✔Diseñar pipelines de integración continua que ejecuten tests y linting automáticamente.
✔Configurar GitHub Actions para automatizar desde el commit hasta el despliegue.
✔Crear pipelines con GitLab CI para proyectos Backend multi-etapa.
✔Implementar despliegue continuo (CD) con estrategias de blue-green y canary.
✔Gestionar variables de entorno, secrets y configuraciones por ambiente.
✔Integrar Docker en pipelines para despliegues consistentes y reproducibles.

Requisitos previos

  • Conocimientos de Git y control de versiones (branches, merges, pull requests).
  • Experiencia básica con Backend (al menos un lenguaje de servidor).
  • Familiaridad con Docker es recomendable pero no obligatoria.
  • Un repositorio en GitHub o GitLab para practicar los pipelines.

Tecnologías y herramientas

CI/CD GitHub Actions GitLab CI Docker Shell YAML Deploy Monitoreo
