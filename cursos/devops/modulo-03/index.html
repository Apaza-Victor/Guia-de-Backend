Módulo 3 · GitHub Actions

Construye pipelines de integración y despliegue continuo con GitHub Actions: workflows, jobs, steps, triggers y secretos, todo declarado en YAML.

5 lecciones ≈ 60 min Nivel avanzado

Objetivos del módulo

✔Entender qué es un workflow de GitHub Actions y su estructura YAML.
✔Configurar triggers que ejecutan el pipeline en el momento correcto.
✔Organizar jobs y steps con runners, matrices y ejecución condicional.
✔Gestionar secrets y variables de forma segura en los repositorios.
✔Desplegar una aplicación Backend de forma automática desde Actions.
