Hacerlo pasar de verdad

«assertSame» compara valor y tipo. Es la aserción por defecto cuando sabés el resultado exacto.

Detalle importante: declare(strict_types=1) mantiene el PHP estricto. Con ella, '5' nunca pasa un parámetro int, y assertSame detecta el mal tipo al instante.

Los 3 estados de un test

Ejercicio

  1. Instala PHPUnit 11 en un proyecto mínimo con Composer.
  2. Crea phpunit.xml y una suite «Unit».
  3. Código: una clase Calculadora con dividir().
  4. Escribe el test, hazlo fallar una vez y luego arréglalo.

Resumen

  • PHPUnit se instala con Composer como dependencia dev.
  • phpunit.xml enruta suites y autoload.
  • Un test falso vale menos que nada: provocá el fallo.
  • verde → comportamiento esperado; error → arreglá el test.
