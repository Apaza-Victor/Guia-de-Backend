🧪 Testing Backend

Aprende a escribir tests confiables para tus APIs y aplicaciones Backend. Desde unit tests con Jest y pytest hasta pruebas end-to-end que simulan al usuario real. Si no lo testeas, no existe.

5 semanas 6 módulos · 48 lecciones Testing · QA · TDD

¿Qué vas a aprender?

El testing es el pilar de cualquier Backend profesional. En este curso aprenderás a diseñar estrategias de testing, escribir pruebas unitarias, de integración y end-to-end, usar mocks y stubs, aplicar TDD en tu flujo de trabajo y medir la cobertura de código. Usarás herramientas reales como Jest, pytest, PHPUnit y Vitest, y entenderás cómo integrar tests en un pipeline de CI/CD.

Nivel🔧 Intermedio
Duración5 semanas
Módulos6

Categoría🧪 Testing

Objetivos del curso

✔Entender la pirámide de testing y diseñar una estrategia efectiva.
✔Escribir tests unitarios que validen lógica aislada de negocio.
✔Crear tests de integración que verifiquen el contrato con bases de datos y servicios externos.
✔Implementar pruebas end-to-end que simulen flujos completos del usuario.
✔Domina mocks, stubs y spies para aislar dependencias en tus tests.
✔Aplica TDD (Test-Driven Development) como metodología de desarrollo.
✔Mide y mejora la cobertura de código con herramientas reales.
✔Integra tests automatizados en pipelines de CI/CD.

Requisitos previos

  • Conocimientos básicos de al menos un lenguaje Backend (Node.js, Python o PHP).
  • Familiaridad con peticiones HTTP y estructura de APIs REST.
  • Un editor de código y terminal configurados en tu máquina.
  • Ganas de escribir código más confiable y profesional.

Tecnologías y herramientas

Jest pytest PHPUnit Vitest Supertest Mock / Stub TDD Cobertura

Módulos del curso

Seis módulos que te llevan desde los fundamentos del testing hasta la integración completa con CI/CD. Aprenderás con ejemplos prácticos en cada paso.

1. Fundamentos del Testing

¿Por qué testear? La pirámide de testing, tipos de pruebas (unitaria, integración, E2E), el ciclo de vida de un test y las convenciones que hacen que los tests sean mantenibles.

8 lecciones≈ 72 min
Ver módulo

2. Unit Testing en la Práctica

Escribe tu primer test unitario con Jest, pytest o PHPUnit. Aprende a mockear dependencias, usar spies y assertions que describan el comportamiento esperado.

9 lecciones≈ 85 min
Ver módulo

3. Tests de Integración

Prueba la interacción entre componentes reales: bases de datos, archivos y servicios. Usa bases de datos en memoria y contenedores para tests reproducibles.

8 lecciones≈ 78 min
Ver módulo

4. Pruebas End-to-End (E2E)

Simula al usuario real con herramientas E2E: Supertest para APIs HTTP, Playwright para flujos completos. Valida desde la capa HTTP hasta la respuesta del servidor.

8 lecciones≈ 80 min
Ver módulo

5. TDD y Buenas Prácticas

Test-Driven Development: escribe el test antes del código. Ciclo Red-Green-Refactor, testing de APIs REST, manejo de errores y casos edge.

8 lecciones≈ 75 min
Ver módulo

6. Métricas y CI/CD

Mide cobertura de código, detecta regresiones, integra tests en pipelines de GitHub Actions y GitLab CI. Cierra el círculo con un proyecto final completo.

7 lecciones≈ 68 min
