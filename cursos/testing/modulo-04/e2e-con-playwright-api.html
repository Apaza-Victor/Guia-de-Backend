E2E con Playwright sobre la API

🔧 Intermedio 13 min Testing Backend Módulo 4 · E2E

El navegador como cliente real

El E2E de backend a veces necesita el comportamiento de un navegador real: cookies, redirecciones, CORS, tokens en localStorage. Playwright lo trae sin esfuerzo y además sirve para golpear tu API desde playwright.request sin UI.

Instalar y arrancar tu backend

Con webServer, Playwright espera a que tu app esté viva antes de correr los tests.

Golpear la API con playwright.request

Interceptar red y validar payloads

Interceptar el tráfico te permite asegurar qué pide tu front sin espiar con devtools.

Compartir la sesión: storageState

Juntar todo: Supertest + Playwright

Ejercicio

  1. Arranca tu backend y configura Playwright con webServer.
  2. Escribe 2 tests de API con request.
  3. Añade 1 test con página real que haga login.

Resumen

  • Playwright levanta tu backend y lo prueba como real.
  • request para API fina; page para el comportamiento real.
  • Intercepta responses para verificar las llamadas del front.
  • storageState para arrancar logueado y estable.
