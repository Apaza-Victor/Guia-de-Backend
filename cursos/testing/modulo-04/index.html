Módulo 4 · Pruebas End-to-End

Un flujo completo como lo ve un cliente: la petición entra por HTTP, camina toda la app y vuelve. Pocos, pero críticos.

Progreso del curso

Objetivos de aprendizaje

  • Escribir pruebas E2E de HTTP con Supertest contra la app levantada.
  • Encadenar flujos completos: registrarse, loguear, comprar.
  • Usar Playwright para validar API desde el navegador real.
  • Corre E2E en CI de forma estable y paralela.
