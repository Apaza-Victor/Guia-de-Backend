Red, Green, Refactor

🔧 Intermedio 15 min Testing Backend Módulo 5 · TDD

El ritmo que se aprende andando

Tres estados, tres pasos, cero ambigüedad:

ROJO: el fallo con motivo

Al correr: «Class Porcentaje not found». Fallo correcto: el código no existe aún. Si el test fallara por otra razón, algo está mal en el propio test.

VERDE: el mínimo que pasa

Sin florituras, sin casos extra, sin «podría servir para…». El código exacto para este test.

Crecer con casos pequeños

REFACTOR: cambiarlo sin tocar el verde

Los tres errores clásicos

Ejercicio

  1. Implementa IVA (16 %) con TDD completo: rojo → verde → refactor.
  2. Agrega 3 casos: base 0, base negativa, base con decimales.
  3. Refactoriza a constantes y verifica el verde tras cada paso.

Resumen

  • ROJO: fallo con motivo correcto.
  • VERDE: mínimo indispensable.
  • REFACTOR: mejorar con red de seguridad.
  • Pasos pequeños, suite siempre corriendo.
