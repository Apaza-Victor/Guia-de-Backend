Módulo 3 · HTTP

HTTP es el idioma que hablan el navegador y el servidor. Aquí aprendes a leerlo, escribirlo y depurarlo: es la habilidad más útil de un Backend.

12 lecciones ≈ 109 min Módulo 2 recomendado

Objetivos del módulo

✔Entender qué es HTTP y de qué protege HTTPS.
✔Leer un request y un response HTTP como un mensaje en verso.
✔Usar headers, body, query parameters y path parameters con criterio.
✔Conocer cookies, cache-control, content-type y los códigos de estado.
