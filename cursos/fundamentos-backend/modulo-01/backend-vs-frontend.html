Backend vs Frontend

🌱 Principiante 10 min Fundamentos de Backend Módulo 1 · Introducción

Introducción

Volvamos al restaurante. El frontend es la sala: los meseros, los menús, la música y la decoración. Es todo lo que el cliente ve e interactúa. El backend es la cocina y la administración: nadie la ve, pero sin ella no hay comida.

En programación, el frontend es la parte de la aplicación que se ejecuta en el dispositivo del usuario (navegador o móvil) y que se encarga de la interfaz: textos, botones, animaciones y lo que el usuario percibe. El backend corre en un servidor, es invisible y produce los datos y las acciones reales.

¿Dónde está la frontera?

La regla práctica es la siguiente: si el código se ejecuta en tu dispositivo, es frontend. Si se ejecuta en el servidor, es backend. Lo que comparten es Internet: el frontend pide y el backend responde por HTTP.

FrontendBackend
Se ejecuta en el navegador o appSe ejecuta en el servidor
HTML, CSS, JavaScriptPHP, Python, Node.js, Java…
Pinta la interfazProcesa datos y lógica
Usa la APIConstruye la API
Puede verse sin Internet si hay cachéNecesita siempre estar disponible

Ambos mundos se tocan en la API: el frontend hace una petición fetch a una URL y el backend le responde con datos (normalmente JSON). Esa conversación es lo que estudiaremos a fondo en el módulo de HTTP.

Ejemplo: el muro de una red social

Abre una red social. El frontend dibuja encabezados, fotos y botones de «Me gusta». Cuando haces clic, el frontend envía al backend: «marca como me gusta el post 452». El backend comprueba si estás logueado, registra el voto en la base de datos y responde «ok, 123 corazones». El frontend solo actualiza el número en pantalla. Nada del trabajo de verdad ocurre en tu móvil.

Ejercicio

  1. Clasifica estas tareas como frontend, backend o ambas: cambiar el color de un botón, guardar el pedido en una tabla, validar que la tarjeta de crédito tenga 16 dígitos en la app, calcular el precio con IVA en el servidor, animar una imagen.
  2. Explica con tus palabras por qué la validación importante debe hacerse en el backend aunque el frontend ya la haga.

Resumen

  • El frontend se ejecuta en el dispositivo del usuario: interfaz y experiencia.
  • El backend se ejecuta en el servidor: datos, lógica, seguridad y APIs.
  • Se comunican por HTTP usando la API del backend.
  • El frontend puede embellecer, pero no inventa datos: depende del backend.
