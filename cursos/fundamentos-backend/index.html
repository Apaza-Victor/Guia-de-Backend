🌱 Fundamentos de Backend

Aprende qué es el Backend, cómo funciona Internet, HTTP, la arquitectura web y los fundamentos que todo desarrollador Backend debe dominar desde el primer día.

6 semanas 5 módulos · 55 lecciones Backend · Web · HTTP

¿Qué vas a aprender?

Este curso es la puerta de entrada al desarrollo Backend. No necesitas experiencia previa: empieza desde cero, con lenguaje claro, ejemplos reales y ejercicios prácticos en cada lección. Al terminar entenderás qué ocurre detrás de cada clic, de cada petición y de cada API, y estarás listo para aprender cualquier lenguaje de servidor (PHP, Node.js, Python…) con una base sólida.

Objetivos del curso

✔Entender qué es el Backend y por qué existe.
✔Comprender cómo funciona Internet y el protocolo HTTP.
✔Conocer la arquitectura cliente-servidor y los modelos de despliegue.
✔Dominar los formatos de comunicación: JSON, XML, formularios y tiempo real.
✔Tener una base sólida para cualquier curso Backend posterior.

Requisitos

  • Ninguno. Solo ganas de aprender y un navegador moderno.
  • Es recomendable (no obligatorio) tener Python o Node.js instalado para probar los ejemplos.
  • Curiosidad técnica: preguntarte cómo funciona todo por dentro.

Tecnologías que verás

Backend Web HTTP Internet DNS JSON REST WebSockets
