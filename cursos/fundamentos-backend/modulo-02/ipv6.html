IPv6

🌱 Principiante 7 min Fundamentos de Backend Módulo 2 · Internet y la Web

Introducción

IPv6 es la versión 6 del protocolo IP y la solución definitiva al problema de direcciones de IPv4. Sus direcciones usan 128 bits en lugar de 32: un número casi inimaginable de direcciones, suficiente para dar una a cada grano de arena del planeta (y con margen).

Para un backend moderno, conocer IPv6 te prepara para un mundo donde las IPs dejan de estar en escasez y las «direcciones privadas» dejan de necesitarse.

Cómo se lee una IP IPv6

  • Formato hexadecimal: 8 grupos de 4 dígitos hex separados por «:». Ej.: 2001:0db8:85a3:0000:0000:8a2e:0370:7334.
  • Regla para abreviar: los ceros a la izquierda de un grupo se quitan, y un bloque entero de «0000» consecutivos se resume con «::» (una sola vez).
  • Loopback: ::1 es el localhost de IPv6 (el viejo 127.0.0.1).
  • Sin NAT global: cada máquina puede tener una dirección pública propia; ya no hace falta compartir una sola.

En las URLs, las IP IPv6 van entre corchetes: http://[2001:db8::1]:3000.

Ejemplo: del agotamiento al alivio

Con IPv4 sobraban ~4.300 millones de direcciones para el planeta. Con IPv6 hay ~3,4 × 10^38: un número que en la práctica nunca se termina. Los equipos y redes que nazcan hoy tendrán dirección propia siempre, y las técnicas de ahorro (NAT) dejarán de ser necesarias.

Resumen

  • IPv6 usa 128 bits: un océano de direcciones de sobra.
  • Se escribe en hexadecimal con grupos separados por «:».
  • «::1» es localhost; «::» abrevia bloques de ceros.
  • Con IPv6 cada máquina puede tener dirección pública propia.
