El Navegador

🌱 Principiante 8 min Fundamentos de Backend Módulo 2 · Internet y la Web

Introducción

El navegador es el cliente por excelencia de la web: el programa que recibe HTML del servidor y lo convierte en una página que puedes leer y tocar. Chrome, Firefox, Edge y Safari son los más famosos.

Para el backend tiene una importancia doble: es el consumidor de tus respuestas y, gracias a sus herramientas de desarrollador, tu laboratorio para ver qué le llega al usuario.

Qué hace un navegador, por dentro

  • El motor de renderizado: lee el HTML+CSS y pinta la página en pantalla.
  • El motor de JavaScript: ejecuta las interacciones y las peticiones fetch.
  • La caché: guarda copias de respuestas para no volver a descargarlas.
  • Cookies y almacenamiento: recuerdan preferencias y sesiones.
  • DevTools (F12): la ventana secreta: pestañas de Elementos, Red, Consola y Aplicación.

El navegador también impone normas de seguridad importantes que el backend debe respetar (aunque las verás en el Módulo 3): solo envía cookies al dominio correcto y bloquea el acceso a datos de otros orígenes (CORS).

Ejemplo: así «ves» una petición fallida

Abre una web cualquiera, pulsa F12 y ve a la pestaña Red. Verás la lista de todas las peticiones que el documento generó. Cada elemento muestra el método, la URL, el estado (200, 404, 500…) y el tiempo. Es la vista más real del ciclo request-response: el navegador es tu testigo.

Código: el navegador como socio del backend

El navegador ejecuta este código para pedir datos a un servidor y pintarlos. El backend solo se encargó de responder el JSON.

Abre YouTube, pulsa F12, ve a Consola, pega el código y ejecútalo: el navegador (cliente) pidió datos a un servidor real y los mostró.

Ejercicio

  1. Visita 3 webs y en DevTools → Red, busca al menos una petición con estado 200 y otra que use JSON.
  2. Ejecuta el código de arriba en la consola y describe lo que ves.
  3. Responde: ¿el navegador podría inventar datos si el servidor no responde? ¿De qué depende?

Resumen

  • El navegador convierte HTML en páginas y ejecuta JavaScript.
  • Gestiona caché, cookies y seguridad de dominios.
  • DevTools es el laboratorio para ver requests y responses reales.
  • El backend debe responder bien, porque el navegador solo muestra lo que recibe.
