La Web

🌱 Principiante 8 min Fundamentos de Backend Módulo 2 · Internet y la Web

Introducción

La World Wide Web (la WWW) no es lo mismo que Internet: Internet es la red física; la Web es un servicio que corre sobre esa red y que organiza millones de documentos conectados. Es como comparar el asfalto (Internet) con los carteles que muestran las calles (la web).

Para el backend, la web tiene una definición muy práctica: documentos HTML enlazados entre sí, servidos por HTTP. Comprender esa definición te libera de la presión de «saber todo de internet»: la web solo pide cuatro cosas.

Los cuatro grandes de la web

  • HTML (HyperText Markup Language): el lenguaje en el que están escritas las páginas. Piezas como el texto, imágenes y botones se describen con etiquetas.
  • URL (Uniform Resource Locator): la dirección única de cada documento: https://sitio.com/articulos/3.
  • HTTP/HTTPS: el protocolo que define el intercambio de petición y respuesta.
  • Navegadores: los lectores que interpretan HTML y muestran la página al usuario.

El estándar que une esto (la forma en que documentos y URLs se relacionan) es el URI: el «cartel oficial». En la práctica, cuando hablas de web, casi siempre te refieres a estos cuatro componentes.

Ejemplo: una "página" no es un archivo suelto

Cuando abres una web «de tienda», la página HTML que ves es solo la punta del iceberg: el navegador descarga el HTML, luego pide el CSS, después el JavaScript y finalmente los datos del producto al backend. La web moderna no es un montón de archivos flotando: es una serie de peticiones bien orquestadas, y cada una es un pequeño trabajo del backend.

Código: la web detrás de la web

Este servidor entrega un documento HTML (la «página») con el estilo y un dato dinámico, demostrando qué significa «servir la web».

La hora sale del servidor (dato dinámico), no está escrita a mano. Eso es una web «viva»: contenido que depende de la lógica del servidor.

Ejercicio

  1. Ejecuta el servidor y abre la URL. Haz clic en el enlace otra: como no existe, el servidor... observa bien qué pasa.
  2. Explica la diferencia entre Internet y la Web con un ejemplo cotidiano.
  3. Escribe las URLs de 5 páginas y separa en ellas: protocolo, dominio y ruta.

Resumen

  • La web es un servicio sobre Internet: documentos HTML enlazados por URLs y servidos por HTTP.
  • Sus cuatro pilares: HTML, URL, HTTP y navegadores.
  • Las páginas modernas son varias peticiones que el backend debe orquestar.
  • Servir HTML dinámico desde el servidor es el corazón de la web clásica.
