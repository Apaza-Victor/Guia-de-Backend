¿Cómo funciona Internet?

🌱 Principiante 12 min Fundamentos de Backend Módulo 2 · Internet y la Web

Introducción

Cuando tu petición HTTP sale del navegador hacia el servidor, ¿qué pasa por el camino? Internet es la infraestructura que hace posible el backend: una enorme red global de cables y equipos que conecta millones de computadoras entre sí.

Como desarrollador backend no necesitas ser ingeniero de redes, pero necesitas el modelo mental: red, IPs, paquetes y protocolos. Las siguientes lecciones del módulo profundizan cada pieza.

Las piezas de la red

  • Cables y fibra óptica: el «asfalto» físico. La mayor parte de Internet son cables submarinos.
  • Routers y switches: los «cruces de calles» que deciden hacia dónde va cada paquete.
  • Paquetes: los datos no viajan enteros: se trocean en paquetes pequeños que pueden tomar caminos distintos y se reúnen al final.
  • Direcciones IP: la «dirección postal» de cada computadora (lo verás a fondo pronto).
  • Protocolos: las reglas de conversación. TCP asegura que nada se pierda; IP decide el destino; HTTP/HTTPS escribe el contenido.

Metáfora que funciona: mandar un libro por correo trozado en muchas cartas numeradas. Cada carta viaja sola, puede cambiar de ruta, y el destinatario las reordena según el número para reconstruir el libro. En tu terminal, ping es una «carta» de prueba que va y vuelve; traceroute te muestra el camino de saltos.

Ejemplo: qué pasa al pedir una web

  1. Tu navegador traduce ejemplo.com a una IP usando el DNS.
  2. Tu equipo corta la petición en paquetes y los envía al router de tu casa.
  3. Cada router intermedio reenvía los paquetes hacia el servidor (quizá en rutas diferentes).
  4. El servidor reconstruye la petición, prepara la respuesta y la devuelve troceada también.
  5. Tu navegador la reordena y pinta la página.
Por eso a veces una web se «cae» solo para ti: puede fallar un tramo de la ruta, no el servidor. Y por eso el backend se optimiza para responder pocos y pequeños paquetes.

Código: ver la red desde tu terminal

Dos comandos para «ver» la red en acción. Ejecútalos en tu terminal (en Windows usa PowerShell).

El primero mide «¿yo llego al servidor y vuelvo?». El segundo muestra los routers intermedios (cada línea es un salto). El tercero te muestra la dirección IP que esconde el dominio.

Ejercicio

  1. Ejecuta ping ejemplo.com y observa el tiempo de ida y vuelta. Pruébalo con google.com y compara.
  2. Ejecuta tracert google.com y cuenta cuántos saltos hay hasta el destino.
  3. Explica con tus palabras por qué los datos viajan en trozos y no enteros.

Resumen

  • Internet es una red global de cables, routers y protocolos.
  • Los datos viajan troceados en paquetes, reordenados al llegar.
  • IP identifica, TCP asegura, HTTP/HTTPS da el formato de las peticiones web.
  • El backend depende de esta infraestructura para cada request y response.
