Direcciones IP

🌱 Principiante 9 min Fundamentos de Backend Módulo 2 · Internet y la Web

Introducción

Una dirección IP es el número único que identifica a cada dispositivo en una red. Abreviatura de Internet Protocol address. Sin IP, un paquete no sabe a quién entregar el mensaje; como una dirección postal para computadoras.

Para el backend es oro: cuando «subes» tu aplicación a un servidor, le das una IP propia (la dirección de tu «negocio»). Y cuando lees las peticiones entrantes, una IP dice quién te está llamando.

IP pública vs IP privada

  • IP pública: la dirección con la que un dispositivo se ve en Internet. Tu casa suele compartir y rotar una con el ISP.
  • IP privada: direcciones internas dentro de tu red local (tu router, impresora, teléfono). 192.168.x.x y 10.x.x.x son las más comunes. Se repiten en millones de redes porque son locales.
  • IP fija vs dinámica: un servidor necesita una IP fija (o un DNS), porque los clientes la buscan siempre. Tu casa suele recibir una dinámica, que cambia con el tiempo.

El traductor de casa (el router) hace «NAT»: recibe el paquete en su IP pública y lo reparte internamente por IPs privadas. Por eso muchas máquinas comparten una sola IP pública.

Ejemplo: una IP por cada cosa

Cuando el navegador pide https://185.199.108.153 (una IP de GitHub), está escribiendo directamente en el «buzón» de esa computadora. Si esa IP cambiara cada semana sin aviso, nadie la encontraría. Ese problema lo resuelve el DNS y los dominios, que verás enseguida.

Resumen

  • IP = matrícula única de un dispositivo en una red.
  • Pública = visible en Internet; privada = interna a tu red local.
  • Los servidores necesitan IP fija o DNS para que los encuentren.
  • El router hace NAT: una IP pública, muchas privadas.
