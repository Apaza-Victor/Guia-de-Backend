Módulo 3 · Datos y resiliencia

Cada servicio es dueño de sus propios datos: base de datos por servicio, sagas para coordinar transacciones distribuidas, reinstentos inteligentes, circuit breaker para aislar fallos y el despliegue de todo el ecosistema con Docker y Kubernetes.

5 lecciones ≈ 56 min Arquitectura para Backend

Objetivos del módulo

✔Modelar base de datos por servicio y la propiedad de los datos.
✔Diseñar transacciones distribuidas con sagas de coreografía y orquestación.
✔Aplicar timeouts, reintentos con backoff y operaciones idempotentes.
✔Implementar circuit breaker con estados cerrado, abierto y medio-abierto.
✔Desplegar microservicios con Docker, Kubernetes y despliegues canary.
