🧩 Microservicios

Divide tu Backend monolítico en servicios pequeños e independientes que escalan por separado. Aprende a definir límites de contexto, comunicarlos entre sí, descubrirlos dinámicamente y exponerlos con un API Gateway.

6 semanas 6 módulos · 54 lecciones Arquitectura · Microservicios

¿Qué vas a aprender?

Los microservicios son la evolución del Backend de las grandes plataformas. En este curso aprenderás a identificar los límites correctos de cada servicio, a elegir los mecanismos de comunicación (sync vs async), a registrar y descubrir servicios en un entorno dinámico, y a centralizar el ingreso de tráfico con un API Gateway. Todo con un enfoque pragmático: cuándo adoptarlos y cuándo un monolito es mejor.

Objetivos del curso

✔Comprender las ventajas y los costos reales de la arquitectura de microservicios.
✔Definir límites de contexto usando Domain-Driven Design (DDD) y bounded contexts.
✔Diseñar la comunicación sincrónica (REST/gRPC) y asincrónica (eventos/colas).
✔Implementar descubrimiento de servicios con Consul o Kubernetes.
✔Configurar un API Gateway para ruteo, autenticación y rate limiting.
✔Gestionar bases de datos descentralizadas (data per service).
✔Desplegar y escalar microservicios con Docker y CI/CD independiente.

Requisitos previos

  • Experiencia sólida construyendo APIs Backend.
  • Conocimientos de Docker, bases de datos y fundamentos de redes.
  • Familiaridad con REST y formatos como JSON.
  • Curiosidad por la arquitectura de software a gran escala.

Tecnologías y herramientas

REST gRPC API Gateway Kubernetes Docker DDD Consul Eventos
