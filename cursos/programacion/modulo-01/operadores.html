Operadores y expresiones

12 min Principiante PHP Fundamentos de programación

Introducción

Los operadores son las herramientas con las que un programa hace cosas: sumar importes, comparar contraseñas, unir condiciones de acceso. Sin ellos, el código solo guarda datos que no transforma.

Definición

Un operador es un símbolo que produce un valor a partir de uno o más operandos. Se agrupan en: aritméticos (+ - * / %), de asignación (= += -=), de comparación (== === != < > <= >=), lógicos (&& || !) y de concatenación (.). La prioridad decide el orden en que se evalúan: como en matemáticas, primero paréntesis, luego multip licación, luego suma.

Conceptos clave

Lo que más aparece en backend:

  • Aritméticos: $iva = $base * 0.21;, $resto = 10 % 3; (módulo).
  • Comparación estricta: === compara tipo y valor; == solo valor.
  • Lógicos: && (y), || (o), ! (negación).
  • Asignación combinada: $total += $precio; acorta $total = $total + $precio;.
  • Interpolación: "Hola, $nombre" vs concatenar con ..

Ejemplo básico

Operadores aritméticos y de concatenación en acción:

PHParitmetica.php
$base = 100;
$iva  = $base * 0.21;
$total = $base + $iva;

echo $total;                 // 121
echo "\n";
echo 17 % 5;                 // 2 (resto de dividir 17/5)
echo "\n";
echo "Mensaje " . "concatenado";

Ejemplo intermedio

Comparaciones estrictas: el error clásico de 0 == "texto":

PHPcomparacion.php
$clave = "admin";
echo ($clave == "admin") ? "si"  : "no";   // si
echo "\n";
echo (0 == "texto")   ? "igual" : "distinto"; // igual (!!)
echo "\n";
echo (0 === "texto")  ? "igual" : "distinto"; // distinto

Ejemplo real

En un if, los operadores lógicos unen condiciones. Este es el típico control de acceso:

PHPacceso.php
$estaLogueado = true;
$esAdmin      = false;
$edad         = 25;

if ($estaLogueado && ($esAdmin || $edad >= 18)) {
    echo "Acceso permitido";
} else {
    echo "Acceso denegado";
}

Código completo

Un código completo de cálculo de precio con descuento, IVA y redondeo, tal como aparecería en un carrito de compras:

PHPcarrito-completo.php
<?php

declare(strict_types=1);

$importe   = 240.00;
$descuento = 0.10;   // 10%
$iva       = 0.21;

$neto         = $importe * (1 - $descuento);
$totalConIva  = $neto * (1 + $iva);
$totalRedondeado = round($totalConIva, 2);

$pagado = false;

echo "Neto: $neto\n";
echo "Total con IVA: $totalRedondeado\n";
echo "Pagado: " . ($pagado ? "sí" : "no") . "\n";

$totalRedondeado += 0.00;   // ejemplo de asignación combinada
echo "Comprobación: {$totalRedondeado}";

Explicación

El módulo % entrega el resto de una división y es clave para validar paridad, paginar o repartir turnos. Las comparaciones estrictas (===) te salvan del error histórico de PHP por el que 0 == "texto" es verdadero.

En acceso.php, la prioridad de && sobre || hace que el paréntesis sea esencial. En el carrito, los paréntesis controlan el orden: primero descuento, luego IVA, y round() deja el resultado en dos decimales — crítico al tratar dinero.

Errores comunes

  • Usar = (asignación) donde iba == o === (comparación).
  • Comparar con == valores de distinto tipo: usa ===.
  • Olvidar paréntesis y que la prioridad juegue en tu contra.
  • Mezclar lógica con & (bit a bit) en vez de &&.
  • Acumular $total = $total + $x en vez de $total += $x.

Buenas prácticas

  • Usa paréntesis en expresiones de más de dos operadores, aunque no "técnicamente" los necesites.
  • Compara siempre con === y !== en backend.
  • Prefiere las asignaciones combinadas (+=, -=) para acumuladores.
  • Nombra los operadores auxiliares: $esBono = ($total >= 100);.

Ejercicio

Calculadora de propinas

Dificultad: Fácil

Escribe un script que, con $cuenta = 85.40; y $propina = 0.15;:

  1. Calcule el importe de propina y el total a pagar, redondeado a 2 decimales.
  2. Decida con lógica y === si el total es mayor que 100 y muestre un mensaje.
  3. Use % para saber si el número de comensales ($comensales = 4) divide la cuenta sin resto (página cada comensal por igual).

Resumen

  • Operadores aritméticos, de comparación estricta, lógicos y de asignación combinada.
  • === compara tipo y valor; evita mitos de ==.
  • La prioridad importa: usa paréntesis para que se lea tu intención.
  • El módulo % y round() son imprescindibles en backend.
