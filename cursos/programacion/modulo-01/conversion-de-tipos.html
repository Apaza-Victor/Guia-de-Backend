Conversión de tipos

10 min Principiante PHP Fundamentos de programación

Introducción

Los datos no siempre llegan con el tipo que necesitas: un formulario envía "36" (texto) y tu función espera int; JSON entrega objetos y tu código quiere arrays. La conversión de tipos resuelve esa diferencia de forma controlada.

Definición

La conversión (casting) transforma un valor de un tipo a otro. PHP hace conversión implícita cuando conviene (sumar "3" + 4) y permite la explícita con (int), (float), (string), (bool) o funciones como intval() y strval(). La implícita es cómoda; la explícita es predecible.

Conceptos clave

Las conversiones que más usarás:

  • String → int/float: (int) "3" → 3; (float) "19.99" → 19.99.
  • int → string: (string) 42 → "42".
  • A bool: (bool) "" → false; casi todo lo demás → true.
  • Funciones seguras: intval(), floatval() desde cadenas externas.
  • strict_types: con declare(strict_types=1) las funciones rechazan tipos incorrectos en vez de convertirlos.

Ejemplo básico

Casings explícitos y funciones de conversión:

PHPcasting.php
$edadTexto = "36";
$edad      = (int) $edadTexto;      // 36 (int)
echo $edad + 1;                     // 37

$precio    = "19.99";
$total     = (float) $precio * 2;   // 39.98
echo "\n$total";

Ejemplo intermedio

Lo que llega de un formulario siempre es texto; conviértelo antes de usarlo:

PHPformulario.php
// Simula datos de un formulario web
$cantidad = "3";     // viene como string
$precio   = "12.5";  // también

$total = intval($cantidad) * floatval($precio);
echo "Total: $total";

Ejemplo real

Con strict_types, si la función espera int y llega un string, PHP lanza TypeError en lugar de "arreglarlo" silenciosamente:

PHPstrict.php
<?php
declare(strict_types=1);

function mesesEnDias(int $meses): int {
    return $meses * 30;
}

echo mesesEnDias(2);          // 60
// echo mesesEnDias("2");     // TypeError (con strict_types)

Código completo

Código completo: parsear una entrada de usuario y transformarla a los tipos correctos antes de procesarla:

PHPutils-entrada.php
<?php

declare(strict_types=1);

// Entradas simuladas (en producción vendrían de $_GET / $_POST)
$entradaEdad    = "21";
$entradaMonto   = "150.75";
$entradaActivo  = "1";

$edad = (int) $entradaEdad;              // 21
$monto = (float) $entradaMonto;          // 150.75
$activo = (bool) $entradaActivo;         // true (cualquier string no vacío)

$suscripcion = $edad >= 18 && $activo;
$precioFinal = $monto > 100 ? $monto * 0.9 : $monto;

echo "Edad: $edad | Monto: $precioFinal | Suscripción: " . ($suscripcion ? "OK" : "NO");

Explicación

En casting.php el cast (int) y (float) deja claro el tipo nuevo; la aritmética sigue funcionando porque los operandos ya son numéricos. En formulario.php, intval() y floatval() son más tolerantes con texto sucio (devuelven 0 si no pueden convertir).

El ejemplo estricto muestra la filosofía moderna: falla pronto, falla claro. Y el util completo mezcla casts, condición lógica y operador ternario para convertir la entrada de un usuario de texto a datos de negocio fiables.

Errores comunes

  • Convertir "12,50" (coma decimal española) y obtener 12 en vez de 12.5.
  • Creer que (bool) "0" es false: es true (la cadena no está vacía).
  • Confiar en la conversión implícita con datos externos: valida antes de convertir.
  • Olvidar strict_types y que funciones se "arreglen" solas con tipos raros.

Buenas prácticas

  • Convierte explícitamente toda entrada externa (formularios, JSON, querystrings).
  • Activa declare(strict_types=1) en todos tus archivos.
  • Prefiere intval()/floatval() para texto que podría estar sucio.
  • Valida el rango tras convertir: $edad = max(0, (int) $entrada);.

Ejercicio

Procesador de entradas

Dificultad: Media
  1. Recibe (simuladas) $inputPrecio = "49.99" y $inputUnidades = "2".
  2. Conviértelas a float e int y calcula el total.
  3. Muestra true si el total supera 100 usando (bool) sobre la comparación.
  4. Comprueba qué devuelve (int) "abc" y anótalo (pista: 0).

Resumen

  • PHP convierte tipos implícitamente, pero lo profesional es hacerlo explícito.
  • Casts: (int), (float), (string), (bool).
  • intval() y floatval() para entradas externas.
  • declare(strict_types=1) endurece tus funciones.
