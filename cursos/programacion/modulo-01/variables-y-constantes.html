Variables y constantes

10 min Principiante PHP Fundamentos de programación

Introducción

Todo programa necesita guardar información: un nombre de usuario, el precio de un producto, el número de intentos de acceso. En programación, esa información se guarda en variables y constantes. Dominar estos dos conceptos es el primer paso para escribir cualquier programa de backend, desde un login hasta una API completa.

Definición

Una variable es un espacio de memoria con nombre que almacena un valor que puede cambiar durante la ejecución. Una constante es un valor que se define una sola vez y no se puede modificar. En PHP las variables se identifican con el signo $ seguido del nombre, y las constantes se definen con define() o const.

La primera regla de oro: un nombre debe decir qué contiene. $email es mejor que $x.

Conceptos clave

Conceptos que debes dominar en esta lección:

  • Declaración: el valor se crea la primera vez que se asigna (no hace falta declarar el tipo).
  • Asignación: el operador = guarda un valor en la variable.
  • Mutabilidad: las variables cambian; las constantes, no.
  • Scope propio de PHP: los nombres distinguen mayúsculas en variables ($Dato ≠ $dato).
  • Convención: variables en camelCase, constantes en MAYÚSCULAS.

Ejemplo básico

Asignamos dos variables y una constante, y las mostramos con echo:

PHPvariables.php
$usuario = "ada_lovelace";
$edad = 36;
echo $usuario;         // ada_lovelace
echo "\n";
echo $edad + 1;        // 37 (la variable no cambia)

Ejemplo intermedio

Las variables se reutilizan en cálculos y se pueden incrustar dentro de cadenas con comillas dobles:

PHPcarrito.php
$precio = 150.50;
$cantidad = 3;
$total = $precio * $cantidad;

echo "Productos: $cantidad\n";
echo "Total a pagar: $total €";

Ejemplo real

En backend las constantes guardan configuración (que nunca cambia en ejecución) y las variables guardan estado (contadores, acumuladores, datos de la petición):

PHPconfig.php
define("BD_HOST", "localhost");
define("BD_NOMBRE", "tienda");

$peticiones = 0;
const TIEMPO_ESPERA_SEG = 5;

$peticiones++;                       // ahora vale 1
echo "Conectando a " . BD_HOST . "/" . BD_NOMBRE;
echo "Espera permitida: " . TIEMPO_ESPERA_SEG . " seg";

Código completo

El archivo código completo reúne estado mutable (variables) e inmutabilidad (constantes) tal como lo haría una pequeña herramienta de servidor:

PHPapp-boletin.php
<?php

declare(strict_types=1);

// ------------------ Constantes de configuracion ------------
const APP_NOMBRE   = "Boletín API";
const APP_VERSION  = "1.0.0";
const MAX_INTENTOS = 3;

// ------------------ Estado de la aplicacion ----------------
$intentos = 0;
$usuarioActual = "invitado";

// Registramos dos intentos de login fallidos
$intentos += 1;
$intentos += 1;

printf(
    "App: %s v%s | Usuario: %s | Intentos: %d de %d\n",
    APP_NOMBRE,
    APP_VERSION,
    $usuarioActual,
    $intentos,
    MAX_INTENTOS
);

Explicación

En variables.php vemos que echo imprime texto y que la operación $edad + 1 no modifica el valor guardado: solo lo lee. En carrito.php las variables se combinan con operadores (multiplicación) y las comillas dobles interpolan el valor de $cantidad y $total dentro del texto.

En config.php, define() crea constantes globales y const otra forma equivalente. El operador ++ suma 1 a una variable, y el punto (.) concatena cadenas.

En el caso real, la configuración del servidor se mantiene constante (no cambia entre petición y petición), mientras la cantidad de intentos de login varía: por eso cada una usa su herramienta adecuada.

Errores comunes

Errores típicos de quien empieza:

  • Olvidar el símbolo $ al usar la variable: echo usuario; genera un error.
  • Referenciar una variable antes de asignarle valor: PHP usa null y puede ocultar bugs.
  • Escribir el nombre con distinta mayúscula ($Usuario vs $usuario): son variables distintas.
  • Intentar redefinir una constante: PHP lanza una advertencia y mantiene el primer valor.
  • Poner caracteres inválidos en el nombre (espacios, guiones) o empezar por un número.

Buenas prácticas

Buenas prácticas desde el día uno:

  • Usa nombres descriptivos y en camelCase: $totalPedido, no $t.
  • Define las constantes al inicio del archivo o en un módulo de configuración.
  • Inicializa siempre la variable antes de usarla.
  • Usa const para constantes locales y define() para config global.
  • No cambies el tipo de una variable sin necesidad: la lectura del código se complica.

Ejercicio

Perfil de usuario en el servidor

Dificultad: Media

Crea un archivo perfil.php que:

  1. Defina las constantes APLICACION (valor "Backend Academy") y ACCESO_LIMITADO (valor true).
  2. Cree las variables $nombre, $nivel y $leccionesCompletadas con datos de un estudiante.
  3. Aumente en 2 las lecciones completadas y muestre: "Estudiante: Ada — Nivel: principiante — Lecciones: 4".

Pista: usa interpolación de variables en comillas dobles y opera con las variables antes de imprimir.

Resumen

  • Las variables guardan valores que pueden cambiar; en PHP se escriben con $.
  • Las constantes no cambian y se crean con define() o const.
  • La asignación usa el operador = y echo imprime valores.
  • Nombres descriptivos y constantes en MAYÚSCULAS son la convención profesional.
