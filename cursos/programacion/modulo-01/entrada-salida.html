Entrada, salida y comentarios

10 min Principiante PHP Fundamentos de programación

Introducción

Un programa que solo calcula en silencio no es útil: necesita recibir datos (entrada) y mostrar resultados (salida). En backend la "entrada" suele ser una petición HTTP y la "salida" una respuesta o un log; aquí lo verás en forma de consola con echo y readline().

Definición

La entrada son los datos que el programa recibe; la salida es lo que devuelve. En PHP de consola se usa echo, print o printf() para salir y readline(), fgets(STDIN) o argv para entrar. Los comentarios son texto que PHP ignora: sirven para explicar el código a otros y a tu yo del futuro.

Conceptos clave

Lo esencial de entrada/salida y comentarios:

  • echo imprime una o varias cadenas; print_r() imprime arrays legibles.
  • printf() formatea: printf("Valor: %.2f", 9.5).
  • readline() lee una línea escrita por el usuario.
  • Comentarios de línea: // texto y # texto; de bloque: /* texto */.
  • PHPDoc genera documentación: /** @param int $n */.

Ejemplo básico

Salida simple, con formato y entrada por consola:

PHPio-basico.php
echo "Hola desde el backend";        // salida simple
print_r(["uno", "dos", "tres"]);     // salida de array

// Entrada por consola
$nombre = readline("¿Cuál es tu nombre? ");
echo "Hola, $nombre";

Ejemplo intermedio

Con printf() controlas decimales y relleno; muy útil para reportes y logs:

PHPprintf.php
printf("Usuario: %s | Sesión: %d | Saldo: %.2f\n", "ada", 7, 152.5);
// -> Usuario: ada | Sesión: 7 | Saldo: 152.50

Ejemplo real

Los comentarios correctos en acción, incluyendo PHPDoc para funciones:

PHPcomentarios.php
/**
 * Calcula el IVA de un importe.
 * @param float $importe Base sin IVA.
 * @param float $tasa   Porcentaje de IVA (0.21 = 21%).
 * @return float Importe con IVA.
 */
function conIva(float $importe, float $tasa = 0.21): float {
    // margen de seguridad: nunca importes negativos
    $importe = max(0, $importe);
    return $importe * (1 + $tasa);
}

echo conIva(100);   // 121

Código completo

Código completo: una mini calculadora de consola que lee entrada, valida y formatea la salida:

PHPcalculadora.php
<?php

declare(strict_types=1);

/*
 * Mini calculadora de consola.
 * Recibe dos números y una operación; devuelve el resultado.
 */

echo "=== Calculadora Backend ===\n";

// Entrada (en una API real vendría en la petición)
$numeroA = readline("Número A: ");
$numeroB = readline("Número B: ");
$operador = readline("Operador (+, -, *, /): ");

$a = (float) $numeroA;
$b = (float) $numeroB;

switch ($operador) {
    case "+":
        $resultado = $a + $b;
        break;
    case "-":
        $resultado = $a - $b;
        break;
    case "*":
        $resultado = $a * $b;
        break;
    case "/":
        $resultado = $b == 0 ? null : $a / $b;
        break;
    default:
        $resultado = null;
}

if ($resultado === null) {
    echo "Operación no válida o división entre cero\n";
} else {
    printf("Resultado: %.2f\n", $resultado);
}

Explicación

La salida con echo y print_r() cubre el 90 % de la depuración diaria. printf() es el formato fino: %s string, %d entero, %.2f decimal con dos cifras. La entrada con readline() se lee siempre como texto, por eso la convertimos con casts de la lección anterior.

Los comentarios explican el porqué (la decisión, la restricción), no el qué (eso ya lo dice el código). El PHPDoc documenta la firma de la función y permite a los editores autocompletar. En la calculadora, el bloque /* */ describe el script y cada // marca una decisión.

Errores comunes

  • Escribir comentarios que repiten el código ($x++; // incrementar x).
  • Leer una entrada y usarla como número sin convertirla.
  • Olvidar cerrar /* con */ y romper todo el archivo.
  • Imprimir arrays con echo (muestra "Array"): usa print_r().
  • Dejar comentarios obsoletos que ya no describen el código.

Buenas prácticas

  • Comenta el porqué, no el qué.
  • Documenta funciones con PHPDoc (params, retorno).
  • Pon la entrada al inicio y la salida al final de la lógica.
  • En backend, usa logs/consola para salida y valida toda entrada externa.

Ejercicio

Registro de visitas

Dificultad: Fácil
  1. Pide con readline() el nombre del visitante.
  2. Suma 1 a un contador $visitas y muestra con printf(): "Visitas: N — Último: nombre".
  3. Añade un comentario de bloque que explique el propósito del script y uno de línea para el contador.

Resumen

  • Salida: echo, print_r(), printf().
  • Entrada de consola: readline() (siempre texto; convierte con casts).
  • Comentarios de línea // y bloque /* */; PHPDoc para funciones.
  • Comenta el porqué, no traduzcas el código.
