Tipos de datos

12 min Principiante PHP Fundamentos de programación

Introducción

Los datos de un servidor no son solo números: son nombres, fechas, precios con decimales, respuestas sí/no y estados que aún no tienen valor. Cada clase de dato se llama tipo, y elegir el correcto evita errores sutiles en producción.

Definición

Un tipo de dato describe qué clase de valor guarda una variable y qué operaciones admite. PHP 8 trabaja con tipos escalares como string, int, float y bool, y tipos compuestos como array y object (que verás en módulos posteriores). Aunque PHP convierte tipos automáticamente, lo profesional es declararlos para evitar sorpresas.

Conceptos clave

Los cuatro tipos escalares que debes reconocer sin dudar:

  • int — números enteros (-5, 0, 1200).
  • float — números con decimales (19.99, 3.1416).
  • string — cadenas de texto ("Ada", 'Backend').
  • bool — verdadero o falso (true / false).
  • null — ausencia de valor, clave para campos opcionales.

Ejemplo básico

PHP permite asignar cualquier tipo a una variable. La función var_dump() revela el tipo y el valor:

PHPtipos.php
$nombre  = "Ada Lovelace";   // string
$anios   = 36;               // int
$peso    = 54.5;             // float
$activo  = true;             // bool
$apodo   = null;             // null

var_dump($nombre, $anios, $peso, $activo, $apodo);

Ejemplo intermedio

Declara el tipo esperado en los parámetros y en el retorno con type declarations (PHP 7 y 8):

PHPtipos-parametros.php
function sumar(int $a, int $b): int {
    return $a + $b;
}

echo sumar(3, 4);        // 7
echo "\n";
echo sumar("3", "4");    // 7: PHP convierte las cadenas a int

Ejemplo real

En un endpoint real los datos llegan como texto (JSON, formularios) y hay que tratarlos por su tipo correcto. Aquí simulamos decidir si un pedido es "gratis" según el importe (float) y el estado (bool):

PHPpedidos.php
$pedidoTotal = 152.75;       // float: importe con decimales
$esVip       = true;         // bool: flag del cliente
$cuponAplicado = null;       // null: aún sin decidir

if ($pedidoTotal >= 150.0 && $esVip) {
    $cuponAplicado = true;   // ahora es true
    echo "Envío gratis confirmado ($pedidoTotal €)";
} else {
    echo "Envío con coste estándar";
}

Código completo

Un código completo que usa todos los tipos escalares en una factura sencilla:

PHPfactura.php
<?php

declare(strict_types=1);

function formatearFactura(string $cliente, int $unidades, float $precio, bool $ivaIncluido): string {
    $importe = $unidades * $precio;
    $fila    = "Cliente: $cliente | Unidades: $unidades | Total: $importe";

    return $ivaIncluido ? $fila . " (IVA incluido)" : $fila . " (sin IVA)";
}

echo formatearFactura("Ada", 2, 24.99, true);
echo "\n";
echo formatearFactura("Alan", 1, 9.5, false);

Explicación

var_dump() es tu mejor amigo al empezar: imprime tipo y valor y evita adivinar. Las type declarations en parámetros y retorno convierten los errores de tipo en errores claros en lugar de fallos silenciosos.

En pedidos.php combinas condiciones con && y cambias null a true: típico flujo de validación de backend. En la factura, la función recibe cada tipo declarado (string, int, float, bool) y devuelve un string, con el operador ternario condicion ? a : b.

Errores comunes

  • Sumar "10" (string) con 5 (int): PHP lo convierte, pero confía en que conviene y pierdes el control.
  • Comparar con == entre tipos distintos (por ejemplo 0 == "texto"): usa === para tipo y valor.
  • Olvidar que "1.5" es un string aunque parezca número.
  • Usar null cuando necesitabas false o 0: son valores distintos.

Buenas prácticas

  • Declara tipos en parámetros y retornos desde el principio.
  • Prefiere bool con nombres de pregunta: $esActivo, $tieneDescuento.
  • Usa int para IDs y cantidades; float solo para importes/medidas.
  • No confundas null con valores por defecto: null significa "sin valor".

Ejercicio

Inventario tipado

Dificultad: Fácil

Escribe un script que:

  1. Declare: $producto (string), $stock (int), $precioUnitario (float) y $disponible (bool).
  2. Calcule el valor total del stock y lo muestre con echo: "Producto Teclado — Stock 12 — Valor 191.88".
  3. Use var_dump() sobre una variable sin asignar para ver que es null.

Resumen

  • Los tipos base son int, float, string, bool y null.
  • Usa var_dump() para inspeccionar valores y tipos.
  • Declara tipos en funciones para atrapar errores a tiempo.
  • Prefiere comparaciones estrictas (===) en backend.
