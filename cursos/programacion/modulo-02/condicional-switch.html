La estructura switch

10 min Principiante PHP Control de flujo

Introducción

Cuando una variable se compara contra muchas opciones, una cascada de elseif se vuelve ruidosa. Para eso existen switch y, desde PHP 8, match: formas ordenadas de elegir entre muchas alternativas.

Definición

switch compara una expresión contra múltiples case con comparación no estricta (==) y ejecuta el primero que coincida; default atrapa el resto. match (PHP 8) es su evolución: compara estrictamente (===), es una expresión (devuelve un valor) y no necesita break.

Conceptos clave

  • switch: si omitas el break, sigue ejecutando el siguiente caso.
  • Varios case seguidos sin break comparten la misma rama.
  • match devuelve el valor de la rama elegida; se asigna a una variable.
  • En match puedes agrupar condiciones con comas: 200, 201 => ....
  • En match la rama default es obligatoria si quieres evitar excepciones.

Ejemplo básico

Un switch clásico. Observa cómo cada rama termina en break:

PHPswitch.php
$metodo = "POST";

switch ($metodo) {
    case "GET":
        echo "Leer recurso";
        break;
    case "POST":
        echo "Crear recurso";
        break;
    case "PUT":
        echo "Actualizar recurso";
        break;
    case "DELETE":
        echo "Eliminar recurso";
        break;
    default:
        echo "Método no soportado";
}

Ejemplo intermedio

match es más limpio, estricto y devuelve un valor:

PHPmatch.php
$codigo = 404;

$mensaje = match ($codigo) {
    200, 201   => "Éxito",
    301, 302   => "Redirección",
    400, 404   => "Error del cliente",
    500, 503   => "Error del servidor",
    default    => "Código desconocido",
};

echo $mensaje;

Ejemplo real

Un mini router: decidir qué controlador responde según la ruta de la URL:

PHProuter.php
<?php
function responder(string $ruta): string {
    return match ($ruta) {
        "/inicio"    => "Devuelve la vista de inicio",
        "/usuarios"  => "Devuelve la lista de usuarios",
        "/productos" => "Devuelve el catálogo de productos",
        default      => "Registra 404 y devuelve página no encontrada",
    };
}

echo responder("/usuarios");

Código completo

Código completo: traducir códigos de estado HTTP a mensajes para una API, una de las tareas más repetidas del backend:

PHPestados-http.php
<?php

declare(strict_types=1);

function estadoHttp(int $codigo): string {
    return match ($codigo) {
        200 => "OK",
        201 => "Creado",
        204 => "Sin contenido",
        400 => "Petición incorrecta",
        401 => "No autenticado",
        403 => "Sin permisos",
        404 => "No encontrado",
        500 => "Error interno del servidor",
        default => "Código no documentado",
    };
}

foreach ([200, 404, 500] as $codigo) {
    echo "$codigo: " . estadoHttp($codigo) . "\n";
}

Explicación

En switch.php, el break corta la ejecución; sin él el intérprete "cae" al siguiente caso y produce bugs difíciles. En match.php eso desaparece: cada flecha => es una rama única, agrupa condiciones con comas y, como es una expresión, puedes asignar su resultado.

El router y el traductor de estados muestran el patrón real: input pequeño (una ruta, un código) y output decidido. Con match, asegurar con default evita la excepción UnhandledMatchError cuando llega un valor inesperado.

Errores comunes

  • Olvidar el break en switch y ejecutar ramas de más.
  • Creer que switch compara estrictamente: usa match para eso.
  • Poner default a la mitad: el intérprete no reordena, así que mejor al final.
  • Usar match sin default y que salte UnhandledMatchError.

Buenas prácticas

  • Prefiere match en PHP 8 para comparaciones estrictas y ramas reutilizables como valores.
  • Mantén la lista de casos completa y documenta qué hace el default.
  • Si la lógica de cada rama supera dos líneas, llama a una función en vez de ponerla ahí.

Ejercicio

Días de la semana

Dificultad: Fácil
  1. Con $dia = 3, usa match para mostrar el nombre del día (1=lunes … 7=domingo).
  2. Agrupa 6 y 7 como "Fin de semana" en una sola rama con coma.
  3. Añade un default que muestre "Número de día inválido".

Resumen

  • switch: comparación no estricta, necesita break.
  • match: estricto, expresión con valor y ramas agrupadas con comas.
  • El default atrapa lo inesperado y en match te libra de excepciones.
