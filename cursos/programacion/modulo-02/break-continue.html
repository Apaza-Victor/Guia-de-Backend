break y continue: control fino de bucles

8 min Principiante PHP Control de flujo

Introducción

A veces no quieres recorrer todo el array: quieres saltarte algo o parar en cuanto encuentres lo que buscas. Ahí entran break y continue, los dos interruptores finos del bucle.

Definición

break termina el bucle de inmediato: ya no se repite más. continue salta a la siguiente iteración sin ejecutar el resto del bloque actual. Ambos aceptan un número opcional para controlar bucles anidados: break 2 corta dos niveles a la vez. Úsalo con moderación y siempre dentro del bucle que quieres controlar.

Conceptos clave

  • break: salida inmediata del bucle (queda interrumpido).
  • continue: ignora el resto de la vuelta y pasa a la siguiente.
  • Usa break para "encontrar y salir" en búsquedas.
  • Usa continue para filtrar: "si no cumple, sáltalo".
  • break N y continue N afectan a N niveles de anidado.

Ejemplo básico

break corta el bucle en cuanto llega al 5:

PHPbreak.php
for ($i = 1; $i <= 10; $i++) {
    if ($i === 5) {
        break;              // salimos sin imprimir el 5
    }
    echo "$i ";
}
// Salida: 1 2 3 4

Ejemplo intermedio

continue salta lo que no quieres:

PHPcontinue.php
for ($i = 1; $i <= 6; $i++) {
    if ($i % 2 === 0) {
        continue;           // nos saltamos los pares
    }
    echo "$i ";
}
// Salida: 1 3 5

Ejemplo real

Juntos implementan busqueda con filtro, un patrón real:

PHPfiltro.php
$partidas = [
    ["jugador" => "Ana",  "puntos" => 120],
    ["jugador" => "Luis", "puntos" => 85],
    ["jugador" => "Nora", "puntos" => 200],
];

foreach ($partidas as $partida) {
    if ($partida["puntos"] < 100) {
        continue;                       // no alcanza el mínimo; saltamos
    }
    echo "Partida válida: {$partida['jugador']}\n";
}

Código completo

Código completo: procesar usuarios con validaciones, saltando inactivos y parando en el objetivo:

PHPbusqueda.php
<?php

declare(strict_types=1);

$usuarios = [
    ["nombre" => "Ana",  "activo" => true],
    ["nombre" => "Luis", "activo" => false],
    ["nombre" => "Nora", "activo" => true],
];

foreach ($usuarios as $usuario) {
    if (!$usuario["activo"]) {
        continue;   // ignora cuentas inactivas
    }

    if ($usuario["nombre"] === "Nora") {
        echo "Encontrado: {$usuario['nombre']}\n";
        break;      // ya tenemos lo que buscábamos
    }

    echo "Procesando a {$usuario['nombre']}\n";
}

Explicación

En break.php el bucle ni siquiera llega a imprimir el 5: la interrupción es total. En continue.php, en cambio, el 4 se evalúa pero su cuerpo "se salta" y el bucle sigue en el 5.

El patrón de negocio aparece en busqueda.php: primero filtramos con continue (no proceses inválidos), luego buscamos con break (para en cuanto lo encuentres). Así recorres el mínimo de datos y comunicas tu intención con claridad. Y son tu salvoconducto contra bucles infinitos: un break de seguridad tras N vueltas nunca está de más.

Errores comunes

  • Usar break cuando querías continue (y viceversa): el flujo cambia por completo.
  • Añadir continue al final del bloque: no hace nada y confunde.
  • Romper más niveles de los que hay con break 3: se detiene todo el script.
  • Depender del valor que sobresale: documenta siempre qué termina cada interrupción.

Buenas prácticas

  • Primero condiciones de filtro (continue), después de éxito (break).
  • Si el bucle se complica, extrae la lógica a una función que devuelva el resultado y evita saltos.
  • Usa break 2 con moderación: dos niveles ya son demasiados.

Ejercicio

Detector de spam

Dificultad: Media
  1. Con $mensajes = ["hola", "", "oferta!" , "adiós"]:
  2. Saltate los vacíos con continue.
  3. Si llega "oferta!", imprime "Spam detectado" y para el bucle con break.
  4. Imprime cada mensaje no vacío antes del spam.

Resumen

  • break termina el bucle; continue salta la vuelta.
  • Patrón backend: filtrar con continue, encontrar y parar con break.
  • Evita anidados profundos y usa los saltos con intención clara.
