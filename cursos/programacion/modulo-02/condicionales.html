Condicionales: if, else y elseif

12 min Principiante PHP Control de flujo

Introducción

Un programa sería aburrido si siempre siguiera el mismo camino. El backend está lleno de decisiones: ¿el usuario tiene permiso?, ¿el producto tiene stock?, ¿el pago fue aceptado? Las estructuras condicionales son la forma de tomar esas decisiones.

Definición

La estructura if evalúa una condición booleana: si es true ejecuta un bloque, y opcionalmente else ejecuta otro cuando es false. Con elseif encadenas varias comprobaciones en orden. Eso es todo: verdadero y falso deciden el camino.

Conceptos clave

  • if (condicion) { ... } — se ejecuta si la condición es true.
  • else { ... } — el resto de casos (sin condición nueva).
  • elseif (condicion) { ... } — encadena una nueva comprobación; se evalúan en orden y solo entra la primera que sea verdadera.
  • La condición siempre se evalúa como booleano: cualquier valor se convierte (0, "" y null son "falsy").
  • Respeta la sangría: el anidado se lee, o no se lee.

Ejemplo básico

El caso más simple: una condición, dos caminos.

PHPedad.php
$edad = 16;

if ($edad >= 18) {
    echo "Mayor de edad: acceso permitido";
} else {
    echo "Menor de edad: acceso restringido";
}

Ejemplo intermedio

Con elseif evalúas rangos en orden. El orden importa: lo primero que cumpla gana.

PHPnota.php
$nota = 8.5;

if ($nota >= 9) {
    echo "Sobresaliente";
} elseif ($nota >= 7) {
    echo "Notable";
} elseif ($nota >= 5) {
    echo "Aprobado";
} else {
    echo "Necesita repasar";
}

Ejemplo real

Las condiciones combinadas con operadores lógicos modelan permisos reales de una aplicación:

PHPacceso-rol.php
$rol       = "editor";
$activo    = true;
$bloqueado = false;

if ($rol === "admin") {
    echo "Panel completo";
} elseif ($rol === "editor" && $activo && !$bloqueado) {
    echo "Panel con permisos de edición";
} elseif ($rol === "editor") {
    echo "Cuenta pendiente de activación";
} else {
    echo "Acceso de solo lectura";
}

Código completo

Código completo: decidir el flujo de un pedido según el estado, típico de cualquier tienda online:

PHPpedido-estado.php
<?php

declare(strict_types=1);

$estado    = "pagado";
$pagado    = true;
$stockOk   = true;

if (!$pagado) {
    echo "Esperando el pago del pedido";
} elseif (!$stockOk) {
    echo "Sin stock: notificar y reembolsar";
} elseif ($estado === "pagado") {
    echo "Generar etiqueta de envío y actualizar stock";
} else {
    echo "Estado desconocido, revisar manualmente";
}

Explicación

En edad.php ves la forma canónica: siempre hay dos caminos posibles y el else atrapa el resto. En nota.php, elseif evita anidar cheques uno dentro de otro; cada rama añade una restricción nueva y el orden garantiza el rango correcto.

El acceso por rol combina && y ! y coloca los casos más restrictivos primero. En el pedido, invertir el orden con if (!...) al inicio permite "abortar" flujos inválidos temprano y que cada rama solo se preocupe de su tarea.

Errores comunes

  • Escribir if ($edad = 18) (asignación) en vez de == o ===: siempre es verdadero.
  • Confiar en valores "falsy" sin conocerlos: "" y "0" son distintos en PHP 8.
  • Olvidar el else: si no hay camino para el resto, el programa se queda sin acción.
  • Anidar en exceso: tres niveles de if es señal de que la lógica debería dividirse.
  • Evaluar condiciones con efectos secundarios (llamadas a funciones) que se repiten.

Buenas prácticas

  • Compara con === siempre en backend.
  • Primero las condiciones de error o bloqueo; después el camino feliz.
  • Pon condiciones simples al inicio; las complejas las esconde una función con nombre.
  • Usa switch o match cuando un valor se compara contra muchas opciones.

Ejercicio

Validador de contraseñas

Dificultad: Fácil

Con las variables $contrasena = "clave123" y $confirma = "clave123":

  1. Si son distintas, muestra "Las contraseñas no coinciden".
  2. Si son iguales pero la longitud es menor que 8, muestra "La contraseña es corta".
  3. En el resto de casos muestra "Contraseña aceptada".

Pista: usa $contrasena === $confirma y strlen($contrasena) < 8.

Resumen

  • if, elseif y else toman decisiones ordenadas.
  • La condición siempre termina siendo un booleano.
  • Ordena primero los casos de bloqueo y usa ===.
  • Poco anidamiento: una decisión por fin de control.
