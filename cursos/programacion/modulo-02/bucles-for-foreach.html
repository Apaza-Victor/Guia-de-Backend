Bucles for y foreach

12 min Principiante PHP Control de flujo

Introducción

Cuando sabes cuántas veces repetir o quieres recorrer una colección, los bucles for y foreach son los más cómodos y seguros del backend.

Definición

for (inicial; condicion; paso) { ... } concentra en una línea el contador y su avance: for ($i = 0; $i < 10; $i++). foreach ($coleccion as $elemento) recorre cada elemento de un array sin contadores manuales ni condiciones de salida: es la opción preferida siempre que recorres datos.

Conceptos clave

  • for: para repeticiones con contador conocido (paginación, tablas).
  • foreach ($arr as $valor): recorre solo los valores.
  • foreach ($arr as $clave => $valor): también da la clave/índice.
  • foreach recorre arrays, objetos y todo lo iterable.
  • for puede ir hacia atrás o con pasos mayores que 1.

Ejemplo básico

Tabla de multiplicar con for:

PHPtabla.php
for ($i = 1; $i <= 5; $i++) {
    $producto = 3 * $i;
    echo "3 x $i = $producto\n";
}

Ejemplo intermedio

Con foreach recorres una colección sin tocar índices:

PHPfrutas.php
$frutas = ["manzana", "pera", "uva"];

foreach ($frutas as $indice => $fruta) {
    echo "[$indice] $fruta\n";
}

Ejemplo real

Recorrer una lista de pedidos (arrays asociativos, que verás a fondo en el módulo 4):

PHPpedidos.php
$pedidos = [
    ["id" => 1, "estado" => "pendiente", "total" => 45.5],
    ["id" => 2, "estado" => "enviado",   "total" => 120.0],
];

foreach ($pedidos as $pedido) {
    echo "Pedido {$pedido['id']}: {$pedido['estado']} — {$pedido['total']} €\n";
}

Código completo

Código completo: paginación con for y resumen con foreach, tal y como verías al construir listados en una API:

PHPlistados.php
<?php

declare(strict_types=1);

// Paginación: 10 elementos por página
$elementos = 10;
$porPagina = 4;
$paginas = (int) ceil($elementos / $porPagina);

echo "Total de páginas: $paginas\n";
for ($p = 1; $p <= $paginas; $p++) {
    echo "Página $p: elementos " .
         ((($p - 1) * $porPagina) + 1) . " al " . min($p * $porPagina, $elementos) . "\n";
}

// Resumen de ventas
$ventas = [12.5, 43.0, 8.75, 90.1];
$total = 0;
foreach ($ventas as $venta) {
    $total += $venta;
}
printf("Ingresos del día: %.2f €\n", $total);

Explicación

En tabla.php el for declara, evalúa y avanza en una sola línea; es la marca de un contador bien controlado. foreach, en cambio, no lleva contador: itera sobre los datos y es imposible salirse del límite.

En los pedidos, {$pedido['id']} interpola dentro de comillas dobles usando llaves para no confundir al intérprete con el índice. En el caso real, el for calcula la paginación (repetición conocida) y el foreach acumula ventas (recorrido de datos).

Errores comunes

  • Usar for para recorrer arrays cuando foreach es más seguro.
  • Poner ; al final del for y que el bloque se ejecute igualmente… de forma separada.
  • Modificar el array mientras lo recorres con foreach: usa for o copia.
  • Olvidar la llave {$...} cuando hay punto o índice dentro de una cadena interpolada.

Buenas prácticas

  • Prefiere foreach sobre for para recorrer colecciones.
  • Nombra el elemento en plural/singular: foreach ($pedidos as $pedido).
  • Acumula resultados (como el total de ventas) con += fuera del bucle.

Ejercicio

Top 3 de ciudades

Dificultad: Media
  1. Define $ciudades = ["Madrid", "Lima", "CDMX", "Bogotá"].
  2. Recórrelas con foreach mostrando el ranking y el nombre.
  3. Usa un for que cuente de 2 en 2 desde 0 hasta 8 y muestre $i.

Resumen

  • for = contador conocido; foreach = recorrer colecciones.
  • foreach ... as $clave => $valor da clave y valor.
  • Casi siempre: si recorres datos, usa foreach.
