Bucles while y do-while

10 min Principiante PHP Control de flujo

Introducción

Tomar decisiones no basta: a veces hay que repetir. Reintentar un envío, leer mensajes de una cola, sumar intentos de login… los bucles con while y do-while repiten código mientras una condición se cumpla.

Definición

while (condicion) { ... } evalúa la condición antes de cada vuelta; si es false desde el principio, el bloque no se ejecuta ni una vez. do { ... } while (condicion); ejecuta el bloque primero y comprueba después: garantiza al menos una iteración. El riesgo de ambos es el bucle infinito si nunca cambias el valor que decide.

Conceptos clave

  • La condición decide: true = repetir, false = salir.
  • Algo dentro del bloque debe cambiar la condición, o nunca terminará.
  • Contadores (como $intentos++) son el control más común.
  • do-while sirve para validar entrada: pregunta al menos una vez.
  • En backend, los while suelen procesar colas hasta vaciarse.

Ejemplo básico

Un contador controla cuántas vueltas damos:

PHPcontador.php
$intentos = 0;

while ($intentos < 3) {
    echo "Intento número " . ($intentos + 1) . "\n";
    $intentos++;
}

Ejemplo intermedio

do-while: pide la entrada al menos una vez y repite hasta que sea válida:

PHPmenu.php
$opcion = "";

do {
    $opcion = readline("Elige (1) ver (2) crear (0) salir: ");
} while (!in_array($opcion, ["0", "1", "2"], true));

echo "Has elegido la opción $opcion";

Ejemplo real

Procesar una cola de mensajes hasta vaciarla, como haría un worker:

PHPcola.php
$pendientes = 4;

while ($pendientes > 0) {
    echo "Enviando mensaje... quedan $pendientes\n";
    $pendientes--;
}

echo "Cola vacía";

Código completo

Código completo: reintentos con espera máxima, patrón muy usado en integraciones externas:

PHPreintentos.php
<?php

declare(strict_types=1);

$maxReintentos = 3;
$reintento = 0;
$enviado = false;

// Simula servicio externo inestable
function enviarPago(): bool { return rand(0, 9) < 4; }

while ($reintento < $maxReintentos && !$enviado) {
    $reintento++;
    echo "Intento de pago $reintento\n";
    $enviado = enviarPago();
    if (!$enviado && $reintento < $maxReintentos) {
        sleep(1);   // espera antes de reintentar
    }
}

echo $enviado
    ? "Pago confirmado en el intento $reintento"
    : "Pago fallido tras $maxReintentos intentos";

Explicación

En contador.php, el incremento $intentos++ es lo que acerca la condición a false; sin esa línea, el bucle no termina nunca. En menu.php, do-while garantiza preguntar una vez antes de comprobar, exactamente lo que quieres al capturar entrada del usuario.

La cola y los reintentos muestran el patrón de backend: mientras quede trabajo o mientras queden oportunidades, seguimos. La condición combinada $reintento < $maxReintentos && !$enviado detiene el bucle por agotamiento o por éxito.

Errores comunes

  • Olvidar modificar la condición y crear un bucle infinito (que puede tumbar el servidor).
  • Reiniciar el contador dentro del bucle: se resetea cada vuelta.
  • Usar while cuando necesitas al menos una ejecución: usa do-while.
  • Comparar con == en la condición de salida y acabar antes de tiempo.

Buenas prácticas

  • Limita siempre las iteraciones (máximo de reintentos, tope de tiempo).
  • Mueve la condición compleja a una función con nombre.
  • En producción, añade un break de seguridad tras N vueltas.

Ejercicio

Contador regresivo

Dificultad: Fácil
  1. Crea $segundos = 10 y un while que imprima cada segundo y decremente.
  2. Cuando llegue a 0, muestra "¡Tiempo agotado!".
  3. Añade una condición de escape: si una variable $cancelado es true, corta con break.

Resumen

  • while comprueba antes; do-while después (mínimo una vuelta).
  • Algo debe acercar la condición a false en cada iteración.
  • Los bucles procesan colas, reintentos y entrada repetida.
