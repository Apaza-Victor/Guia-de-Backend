Arrays asociativos (mapas)

12 min Principiante PHP Estructuras de datos

Introducción

Una lista con índices numéricos no dice nada de qué es cada valor. Cuando los datos tienen nombre — "usuario", "email", "edad" — necesitas la estructura clave-valor: el array asociativo.

Definición

Un array asociativo (o mapa/diccionario) guarda pares clave => valor. Se declara con ["clave" => "valor"] y se accede con la clave: $usuario["email"]. En backend es como modelas un registro de base de datos o un objeto JSON antes de serializarlo.

Conceptos clave

  • Declaración: $pedido = ["id" => 1, "total" => 45.5];.
  • Acceso: $pedido["id"]; si no existe la clave, PHP avisa (mejor comprobar con isset()).
  • Añadir/actualizar: $pedido["estado"] = "enviado";.
  • Recorrer claves y valores: foreach ($mapa as $clave => $valor).
  • Fusionar: array_merge($base, $extra) (las claves de $extra ganan).

Ejemplo básico

Un registro modelado como clave-valor:

PHPusuario.php
$usuario = [
    "id"    => 7,
    "nombre" => "Ada",
    "email"  => "ada@example.com",
];

echo $usuario["nombre"];              // Ada
$usuario["activo"] = true;            // nueva clave
echo isset($usuario["email"]) ? "tiene email" : "sin email";

Ejemplo intermedio

Recorrer un mapa con clave y valor:

PHPconfig.php
$configuracion = [
    "host"  => "localhost",
    "puerto" => 3306,
    "ssl"   => false,
];

foreach ($configuracion as $clave => $valor) {
    echo "$clave = $valor\n";
}

Ejemplo real

La fusión con valores por defecto es un patrón omnipresente:

PHPmerging.php
$opciones = ["tema" => "oscuro", "notificaciones" => false];
$porDefecto = [
    "tema"          => "claro",
    "idioma"        => "es",
    "notificaciones" => true,
];

$final = array_merge($porDefecto, $opciones);
print_r($final);

Código completo

Código completo: transformar datos del usuario a JSON para una API y leerlos después:

PHPjson.php
<?php

declare(strict_types=1);

$perfil = [
    "nombre"   => "Alan Turing",
    "rol"      => "científico",
    "lenguajes" => ["PHP", "Inglés"],
];

// Serializar a JSON (respondemos a la petición)
$json = json_encode($perfil, JSON_UNESCAPED_UNICODE);
echo $json . "\n";

// Leer de vuelta
$recuperado = json_decode($json, true);   // true = array asociativo
echo "Rol: {$recuperado['rol']}\n";
echo "Idioma: {$recuperado['lenguajes'][1]}\n";

Explicación

Los asociativos modelan cosas, no solo listas: cada campo tiene nombre y sentido. Actualizar y añadir campos es natural ($usuario["activo"] = true) y isset() evita leer claves inexistentes.

El patrón de configuración con array_merge permite que el llamador sobreescriba solo lo que quiere. Y en el caso real, la cadena array ⇄ JSON con json_encode/json_decode es exactamente lo que ocurre en cada API: recibes JSON, lo conviertes a mapa, procesas y devuelves JSON.

Errores comunes

  • Usar array_filter/búsquedas pensando en índices numéricos cuando son claves.
  • Leer una clave sin isset() y recibir avisos de PHP.
  • Olvidar que array_merge con claves numéricas las reindexa.
  • En foreach, confundir $clave y $valor.

Buenas prácticas

  • Cuando los datos tienen nombre, usa asociativos; cuando son una secuencia, listas numéricas.
  • Comprueba con isset($mapa["clave"]) antes de leer; con ?? da un valor por defecto.
  • Prefiere json_encode(..., JSON_UNESCAPED_UNICODE) para conservar tildes.

Ejercicio

Ficha de producto

Dificultad: Fácil
  1. Crea un asociativo con nombre, precio y disponible.
  2. Añade la clave categoria con valor "tecnología".
  3. Recórrelo mostrando "clave: valor" y genera su JSON.

Resumen

  • Asociativos = pares clave-valor; acceso por clave.
  • isset(), ?? y array_merge son tus aliados.
  • json_encode/json_decode conectan PHP con las APIs.
