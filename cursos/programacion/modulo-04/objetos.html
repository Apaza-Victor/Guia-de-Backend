Objetos y estructuras de datos

14 min Intermedio PHP Estructuras de datos

Introducción

Hasta ahora los datos eran listas y mapas. Pero un perfil de usuario, un pedido o un producto se comportan mejor como objetos: entidades con propiedades que agrupan datos y lógica. Esta lección te presenta los objetos de forma práctica, antes de la POO completa del módulo 5.

Definición

En PHP, un objeto es una instancia de una clase o del caso simple stdClass. Con (object) [...] conviertes un array a objeto y accedes con $->propiedad; y un array de objetos modela una lista de entidades. Los objetos se pasan por referencia: si lo modificas en una función, el original cambia.

Conceptos clave

  • Crear: $p = (object) ["nombre" => "Teclado"];.
  • Acceso: $p->nombre; escribes $p->precio = 25;.
  • Recorrer propiedades: foreach ($p as $prop => $valor).
  • JSON: json_decode($json) devuelve un objeto (sin el segundo arg true).
  • Semántica de objeto: las entidades se sienten "cosa viva" con estado.

Ejemplo básico

De array asociativo a objeto y vuelta:

PHPstdclass.php
$datos = ["nombre" => "Monitor 24\"", "precio" => 199.5];

$objeto = (object) $datos;
echo $objeto->nombre . "\n";
echo $objeto->precio . "\n";

$objeto->stock = 12;      // añadir propiedad
print_r((array) $objeto);

Ejemplo intermedio

Respuestas JSON gestionadas como objetos:

PHPrespuesta.php
$json  = '{"ok": true, "mensaje": "Producto creado", "id": 42}';
$res   = json_decode($json);          // objeto, no array

echo $res->mensaje . "\n";
echo $res->ok ? "Éxito" : "Error";
echo " id=$res->id";

Ejemplo real

Lista de objetos con funciones que los procesan:

PHPlista-objetos.php
$productos = [
    (object) ["nombre" => "Ratón", "precio" => 15],
    (object) ["nombre" => "Teclado", "precio" => 45],
];

function totalizar(array $lista, float $tasaIva): float {
    $suma = 0;
    foreach ($lista as $item) {
        $suma += $item->precio;
    }
    return $suma * (1 + $tasaIva);
}

printf("Total con IVA: %.2f €\n", totalizar($productos, 0.21));

Código completo

Código completo: un envío de notificación manejado como objeto, tal como lo recibe una API:

PHPnotificacion.php
<?php

declare(strict_types=1);

$payload = json_decode('{
    "tipo": "email",
    "destinatarios": ["ada@example.com"],
    "asunto": "Tu pedido va en camino",
    "contenido": "El paquete #1243 se ha enviado."
}');

function enviar(object $notificacion): string {
    return sprintf(
        "Enviando %s a %s — \"%s\"\n",
        $notificacion->tipo,
        implode(", ", $notificacion->destinatarios),
        $notificacion->asunto
    );
}

echo enviar($payload);

Explicación

stdClass es el "objeto anónimo" de PHP: útil para datos, no para lógica. Convertir (object) un array hace que propiedades se accedan con flecha, y json_decode devuelve objetos por defecto — razón de que en APIs veas el operador -> por todas partes.

En lista-objetos.php, la función recibe objetos aunque el llamador los creara como arrays: el tipo comunica la forma. En la notificación, el objeto llega tal cual del JSON y una función lo procesa. Observa que los objetos se pasan por referencia: si modificas una propiedad dentro de la función, el original lo nota.

Errores comunes

  • Usar $obj["clave"] con objetos (es ->clave) y viceversa con arrays.
  • Leer una propiedad inexistente sin comprobar isset().
  • Olvidar que json_decode sin segundo arg devuelve objetos.
  • Modificar un objeto en una función sin avisar al llamador (referencia).

Buenas prácticas

  • Para datos planos, asociativos o stdClass; para entidades con lógica, clases (módulo 5).
  • Clava un isset($obj->prop ?? "defecto") al trabajar con JSON externo.
  • Tipa los parámetros como object cuando esperas entidades.

Ejercicio

Perfil en objeto

Dificultad: Media
  1. Decodifica el JSON '{"nombre":"Ada","edad":36}' como objeto.
  2. Añade la propiedad activo = true al objeto.
  3. Escribe una función que reciba el objeto tipado y lo "salude".

Resumen

  • Objetos con stdClass y acceso por ->.
  • json_decode devuelve objetos; JSON_UNESCAPED en el encode.
  • Los objetos se pasan por referencia.
