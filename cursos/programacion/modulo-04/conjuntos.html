Conjuntos y colecciones

10 min Intermedio PHP Estructuras de datos

Introducción

En ocasiones lo único que importa es si un elemento está, no cuántas veces aparece ni en qué orden. Los conjuntos (sets) modelan colecciones de elementos únicos y sus operaciones de comparación.

Definición

PHP no tiene un tipo set nativo, pero se implementa con arrays asociativos cuyas claves son los elementos: las claves son únicas por diseño. A partir de ahí, array_keys() recupera los elementos, isset() comprueba pertenencia en O(1) y operaciones como intersección o diferencia salen de funciones nativas de PHP.

Conceptos clave

  • Set con claves: $vistos = ["u1" => true, "u2" => true];.
  • Pertenencia instantánea: isset($vistos["u2"]).
  • Intersección: array_intersect_key($a, $b).
  • Diferencia: array_diff_key($a, $b).
  • Duplicados se evitan solos: añadir la misma clave no crea una segunda.

Ejemplo básico

Eliminar duplicados de una lista convirtiéndola en conjunto de claves:

PHPunicos.php
$nombres = ["ana", "luis", "ana", "nora", "luis"];

$unicos = [];
foreach ($nombres as $nombre) {
    $unicos[$nombre] = true;   // las claves se pisan solas
}

print_r(array_keys($unicos));

Ejemplo intermedio

Comprobar pertenencia al vuelo (muy usado en sesiones y en listas de bloqueo):

PHPbloqueos.php
$bloqueados = ["ip:192.168.1.9" => true, "ip:10.0.0.5" => true];

function estaBloqueado(string $direccion, array $lista): bool {
    return isset($lista[$direccion]);
}

echo estaBloqueado("ip:192.168.1.9", $bloqueados)
    ? "Acceso denegado"
    : "Acceso permitido";

Ejemplo real

Intersección y diferencia con array_intersect_key / array_diff_key:

PHPinterseccion.php
$pjuegA = ["php" => true, "sql" => true, "js" => true];
$pjuegB = ["sql" => true, "python" => true];

$comunes = array_intersect_key($pjuegA, $pjuegB);
$soloA   = array_diff_key($pjuegA, $pjuegB);

echo "Comunes: " . implode(", ", array_keys($comunes));
echo " Solo en A: " . implode(", ", array_keys($soloA));

Código completo

Código completo: recomendaciones por intereses superpuestos:

PHPrecomendador.php
<?php

declare(strict_types=1);

function aSet(array $elementos): array {
    $set = [];
    foreach ($elementos as $e) {
        $set[$e] = true;
    }
    return $set;
}

$miNivel   = aSet(["PHP", "JS", "SQL"]);
$nivelCurso = aSet(["JS", "SQL", "Python", "Go"]);

$aprendere = array_diff_key($nivelCurso, $miNivel);
echo "Del curso aprenderás: " . implode(", ", array_keys($aprendere)) . "\n";

$coinciden = array_intersect_key($miNivel, $nivelCurso);
echo "Ya sabes: " . implode(", ", array_keys($coinciden)) . "\n";

Explicación

El truco del set en PHP: usar claves garantiza unicidad (el "ana" repetido pisa la misma clave) y isset() sobre ellas es la comprobación más rápida que existe. Es la base de listas de bloqueo, sesiones y cachés.

array_intersect_key devuelve las claves presentes en ambos conjuntos (intersección) y array_diff_key las que solo están en el primero (diferencia). Con ellos, "qué debería estudiar" se resuelve con una línea y sin bucles. El recomendador combina ambas para saber qué aprenderás y qué ya dominas.

Errores comunes

  • Confundir array_intersect_key (por claves) con array_intersect (por valores).
  • Buscar pertenencia con in_array cuando podrías usar claves e isset().
  • Olvidar que los valores true del set no se usan: array_keys() los recupera.

Buenas prácticas

  • Estandariza los elementos (strtolower, trim) antes de meterlos en el set.
  • Envuelve la lógica en funciones pequeñas (aSet(), estaBloqueado()).
  • Para sets grandes en memoria, considera librerías Ds (Data Structures).

Ejercicio

Lista de permitidos

Dificultad: Media
  1. Crea la lista $permitidos = aSet(["admin", "editor"]).
  2. Implementa tieneAcceso(string $rol): bool con isset.
  3. Prueba "admin" (true), "invitado" (false) y comprueba que añadir "admin" dos veces no crea duplicados.

Resumen

  • El set PHP = claves de un asociativo; unicidad y pertenencia rápida.
  • array_intersect_key / array_diff_key comparan conjuntos.
  • Ideal para bloqueos, sesiones y recomendaciones.
