Estructuras anidadas

12 min Intermedio PHP Estructuras de datos

Introducción

El mundo real no es plano: un pedido contiene productos; un usuario tiene direcciones; una categoría tiene hijos. Las estructuras anidadas —arrays de arrays, objetos dentro de objetos— modelan esas jerarquías, y son el formato natural de JSON y de las bases de datos.

Definición

Una estructura anidada es una colección cuyos elementos son a su vez colecciones. En PHP: un array de arrays ($matriz = [[1,2],[3,4]]), un array de objetos, u objetos con propiedades que son arrays. Accedes encadenando índice/flecha: $pedidos[0]["productos"][1]["nombre"].

Conceptos clave

  • Matriz: $tabla[0][1] — fila y columna.
  • Lista de mapas: el formato de cada registro de una consulta.
  • Objetos anidados: $usuario->direccion->ciudad.
  • Recorrer con foreach anidados, uno por nivel.
  • JSON anidado: resume todos estos casos al serializar.

Ejemplo básico

Una matriz (tabla) recorrida por niveles:

PHPmatriz.php
$tabla = [
    [1, 2],
    [3, 4],
];

foreach ($tabla as $fila) {
    foreach ($fila as $celda) {
        echo $celda . " ";
    }
    echo "\n";
}

Ejemplo intermedio

Lista de pedidos con productos dentro (dos niveles de foreach):

PHPpedidos-nest.php
$pedidos = [
    [
        "id" => 1,
        "productos" => [
            ["nombre" => "Teclado", "ud" => 1],
            ["nombre" => "Ratón",   "ud" => 2],
        ],
    ],
    [
        "id" => 2,
        "productos" => [
            ["nombre" => "Monitor", "ud" => 1],
        ],
    ],
];

foreach ($pedidos as $pedido) {
    echo "Pedido {$pedido['id']}:\n";
    foreach ($pedido["productos"] as $prod) {
        echo "  - {$prod['nombre']} x{$prod['ud']}\n";
    }
}

Ejemplo real

Objetos anidados desde JSON, resolviendo senderos con seguridad:

PHPjson-nest.php
$json = '{"usuario":{"nombre":"Ada","perfil":{"nivel":"admin"}}}';
$datos = json_decode($json);

# acceso encadenado
echo $datos->usuario->perfil->nivel . "\n";   // admin

# acceso seguro si no sabemos si existe
$nivel = $datos->usuario->perfil->nivel ?? "invitado";
echo "Nivel: $nivel\n";

Código completo

Código completo: un árbol de categorías que se recorre con recursión (de la lección dedicada):

PHParbol-catalogo.php
<?php

declare(strict_types=1);

$catalogo = [
    ["titulo" => "Libros", "hijos" => [
        ["titulo" => "Tecnología", "hijos" => [
            ["titulo" => "PHP 8", "hijos" => []],
        ]],
        ["titulo" => "Negocios", "hijos" => []],
    ]],
    ["titulo" => "Software", "hijos" => [
        ["titulo" => "Editores", "hijos" => []],
    ]],
];

function imprimirArbol(array $nodos, string $sangria = ""): void {
    foreach ($nodos as $nodo) {
        echo $sangria . $nodo["titulo"] . "\n";
        imprimirArbol($nodo["hijos"], $sangria . "  ");
    }
}

imprimirArbol($catalogo);

Explicación

El truco del JSON anidado es leer con la misma curvatura con la que escribiste: cada nivel se recorre con un foreach o se abre con una clave/flecha más. En el pedido, la "una lista de" se traduce directo a bucle anidado.

El operador ?? da un valor por defecto cuando el camino no existe, protegiendo frente a JSON con campos ausentes — algo habitual. Y el árbol de catálogos une dos lecciones: estructuras anidadas + recursión, el tándem perfecto para jerarquías de profundidad variable.

Errores comunes

  • Mezclar notación: $obj->arr[0]->prop funciona, pero perderse es fácil.
  • Recorrer un solo nivel cuando los datos tienen más: se olvidan datos.
  • Leer caminos de JSON externo sin ?? ni isset().
  • Anidar 6 niveles de arrays mezclados con objetos sin comentar la forma.

Buenas prácticas

  • Documenta la forma de la estructura (contrato) si viene de una API externa.
  • Usa ?? en cada segmento dudoso del camino.
  • Para jerarquías, prefiere recursión a bucles infinitos con profundidad desconocida.

Ejercicio

Menú restaurante

Dificultad: Media
  1. Crea la estructura $menu con dos categorías, cada una con un plato (nombre, precio).
  2. Con dos foreach, imprime "Categoría — Plato — 12.5 €".
  3. Convertir a JSON y de vuelta a objeto; muestra el nombre del primer plato encadenando accesos.

Resumen

  • El JSON/BD real son estructuras anidadas: haznos el favor de conocerlos.
  • Un nivel de foreach por nivel de colección.
  • ?? y recursión para jerarquías seguras.
