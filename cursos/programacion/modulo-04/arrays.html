Arrays: la base de los datos

14 min Principiante PHP Estructuras de datos

Introducción

Guardar un dato suelto es fácil; lo difícil es guardar muchos y hacerlo bien. Los arrays son la caja de herramientas básica del backend para agrupar listas de valores: usuarios, pedidos, resultados de una consulta…

Definición

Un array es una colección ordenada de valores accesibles por su índice (que empieza en 0). Se declara con array(...) o con corchetes [...]. Las funciones del lenguaje para arrays son numerosas: count(), array_push(), in_array(), array_merge(), sort(), array_sum()… Dominar unas pocas te lleva muy lejos.

Conceptos clave

  • Declaración: $frutas = ["manzana", "pera"];.
  • Acceso: $frutas[0] → "manzana"; el índice empieza en 0.
  • Añadir: $frutas[] = "uva"; (al final).
  • Tamaño: count($frutas).
  • Convertir a string: implode(", ", $frutas).

Ejemplo básico

Crear, leer y ampliar una lista:

PHParray.php
$ciudades = ["Madrid", "Lima"];

echo $ciudades[0];            // Madrid
echo "\n";
$ciudades[] = "Bogotá";       // añadimos al final
echo count($ciudades);        // 3
echo "\n";
echo implode(", ", $ciudades);

Ejemplo intermedio

Recorrerlos y comprobarlos es pan de cada día:

PHPrecorrido.php
$edades = [25, 31, 19, 44];

foreach ($edades as $edad) {
    if ($edad >= 30) {
        echo "$edad años: adulto\n";
    }
}

if (in_array(19, $edades, true)) {
    echo "Hay un joven de 19 años\n";
}

Ejemplo real

Unir listas y totalizarlas, como en un informe:

PHPresumen.php
$primera = [1, 2, 3];
$segunda = [4, 5];

$todas = array_merge($primera, $segunda);
echo "Suma: " . array_sum($todas) . "\n";    // 15
echo "Media: " . array_sum($todas) / count($todas) . "\n";

sort($todas);
echo "Mayor: " . end($todas) . "\n";         // 5

Código completo

Código completo: actividad diaria con totales y un tope:

PHPventas.php
<?php

declare(strict_types=1);

$ventas = [120.5, 80.0, 210.75, 45.5, 300.0];

$total = array_sum($ventas);
$minimo = min($ventas);
$maximo = max($ventas);

printf("Ventas: %d registros | Total: %.2f € | Min: %.2f | Max: %.2f\n",
    count($ventas), $total, $minimo, $maximo);

if ($total > 500) {
    echo "Objetivo del día superado\n";
} else {
    echo "Aún por debajo del objetivo\n";
}

Explicación

Los índices son como las posiciones de una mesa: el primer asiento es el 0. $ciudades[] = "Bogotá" añade sin saber cuál es el último índice, lo ideal para ir creciendo al vuelo.

El recorrido con foreach y la comprobación con in_array(..., true) (estricta) cubren la mayor parte de los usos. En el resumen, array_merge combina listas y las funciones min/max/sum sustituyen bucles manuales. Memoria: count() es el primer reflejo cuando llega una lista.

Errores comunes

  • Acceder a $arr[count($arr)] cuando el último índice es count-1.
  • Usar in_array() sin el tercer parámetro true y aceptar coincidencias flojas.
  • Modificar el array mientras lo recorres con foreach.
  • Olvidar que sort() modifica el array original en vez de devolver uno nuevo.

Buenas prácticas

  • Usa foreach para recorrer y funciones (array_sum, array_map…) para transformar.
  • Confirma siempre que el índice existe antes de leerlo en datos externos.
  • Un array describe una lista; si necesitas pares clave-valor, pasa a asociativos (siguiente lección).

Ejercicio

Estadísticas de un curso

Dificultad: Fácil
  1. Crea $notas = [7, 9, 5, 8, 6].
  2. Muestra la media, la nota máxima y la mínima.
  3. Di si alguna nota es un 10 con in_array y muestra un mensaje.

Resumen

  • Arrays = listas ordenadas; índice desde 0; count() da el tamaño.
  • [] añade; implode/explode convierten con strings.
  • Apóyate en las funciones nativas (sum, merge, in_array).
