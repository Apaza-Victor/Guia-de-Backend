¿Qué vas a aprender?

Domina la lógica de programación: variables, tipos de datos, control de flujo, funciones, estructuras de datos, POO y código profesional para escribir backend limpio en cualquier lenguaje. Los ejemplos usan PHP 8.

Nivel🌱 Principiante
Duración8 semanas
Módulos7
Lecciones36

Objetivos de aprendizaje

✔Pensar como programador y resolver problemas por pasos
✔Dominar variables, tipos de datos, operadores y control de flujo
✔Escribir funciones reutilizables y limpias
✔Aplicar estructuras de datos y programación orientada a objetos
✔Escribir código profesional: modular, legible y con manejo de errores

Requisitos previos

  • Haber completado el curso Fundamentos de Backend
  • Un editor de código (VS Code) y PHP 8 instalado, o usar el simulador del navegador
  • Constancia: practica cada lección antes de avanzar.

Módulos del curso

7 módulos con 36 lecciones en total.

Módulo 1 · Fundamentos de programación

5 lecciones≈ 54 min

Aprende los cimientos de la programación orientada al backend: variables, constantes, tipos de datos, operadores, conversión de tipos y la entrada y salida de datos con comentarios profesionales.

  1. Variables y constantes
  2. Tipos de datos
  3. Operadores y expresiones
  4. Conversión de tipos
  5. Entrada, salida y comentarios
Empezar módulo

Módulo 2 · Control de flujo

5 lecciones≈ 52 min

Domina if, else, elseif, switch, while, do-while, for y foreach, además del control fino con break y continue, para escribir la lógica que decide y repite en un backend real.

  1. Condicionales: if, else y elseif
  2. La estructura switch
  3. Bucles while y do-while
  4. Bucles for y foreach
  5. break y continue: control fino de bucles
Empezar módulo

Módulo 3 · Funciones

5 lecciones≈ 58 min

Aprende a definir funciones, manejar parámetros y argumentos, entender el ámbito de las variables, utilizar funciones anónimas y callbacks y resolver problemas con recursividad.

  1. Funciones: definir y retornar
  2. Parámetros y argumentos
  3. Ámbito (scope) de las variables
  4. Funciones anónimas y callbacks
  5. Recursividad
Empezar módulo

Módulo 4 · Estructuras de datos

5 lecciones≈ 62 min

Organiza la información de tu backend con arrays indexados, arrays asociativos, conjuntos, objetos y estructuras anidadas, las piezas con las que se modela cualquier API.

  1. Arrays: la base de los datos
  2. Arrays asociativos (mapas)
  3. Conjuntos y colecciones
  4. Objetos y estructuras de datos
  5. Estructuras anidadas
Empezar módulo

Módulo 5 · Programación Orientada a Objetos

5 lecciones≈ 66 min

Construye sistemas mantenibles con POO: clases, objetos, atributos, métodos, constructores, encapsulamiento, herencia, polimorfismo, abstracción e interfaces.

  1. Clases y objetos
  2. Atributos, métodos y constructores
  3. Encapsulamiento: public, private y protected
  4. Herencia
  5. Polimorfismo, abstracción e interfaces
Empezar módulo

Módulo 6 · Código profesional

6 lecciones≈ 68 min

Eleva tu código al nivel profesional: modularización, Clean Code, principios SOLID, DRY y KISS, debugging y manejo de errores con excepciones.

  1. Modularización
  2. Clean Code
  3. Principios SOLID
  4. DRY y KISS
  5. Debugging y herramientas
  6. Manejo de errores y excepciones
Empezar módulo

Módulo 7 · Trabajo en equipo y herramientas

5 lecciones≈ 58 min

Cierra el curso trabajando como en un equipo real: control de versiones con Git, pull requests, entornos de configuración, herramientas esenciales del backend y el camino del código hasta producción.

  1. Git para programadores
  2. Colaboración con pull requests
  3. Entornos de desarrollo y configuración
  4. Herramientas esenciales del backend
  5. Del código al despliegue
