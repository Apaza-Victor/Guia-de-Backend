Clean Code

10 min Intermedio PHP Código profesional

Introducción

El código se escribe una vez y se lee cincuenta. Clean Code son un conjunto de hábitos que hacen que la lectura sea tan natural como la escritura: nombres que dicen la verdad, funciones diminutas y código que no necesita explicación.

Definición

El término viene de Robert C. Martin ("Uncle Bob"): un código es limpio cuando cualquiera puede leer una función y entender su propósito sin contexto previo. Se consigue con: nombres expresivos, funciones que hacen una sola cosa, pocos parámetros, comentarios solo cuando aportan, y consistencia en estilo.

Conceptos clave

  • Nombres que revelan intención: $fechaCaducidad, no $fc.
  • Funciones pequeñas (5-15 líneas) que hacen una sola cosa.
  • Pocos parámetros: 0–2 ideales; 5+ piden un objeto de opciones.
  • Comentarios que explican el porqué, no traducen el qué.
  • Consistencia: mismo estilo en TODO el proyecto.

Ejemplo básico

Misma lógica, dos versiones. Primero el bosque de código malo:

PHPmalo.php
// MAL: qué significa?
function m(float $a, float $b, float $c): float {
    $x = $a * $b;
    if ($c > $x) { $c = $x; }
    return $c;              // ¿qué devuelve? ¿por qué?
}
PHPlimpio.php
// BIEN: la intención es obvia
function aplicarDescuento(float $precio, float $descuento, float $maximo): float {
    $precioConDescuento = $precio * (1 - $descuento);
    return min($precioConDescuento, $maximo);
}

Ejemplo intermedio

Comentarios que aportan frente a comentarios ruido:

PHPcomentarios.php
// MAL: traduce el código
$x = $x + 1;   // sumar 1 a x

// BIEN: explica una decisión
// El servidor espera timestamps UTC; convertimos local -> UTC aquí.
$cuando = new DateTimeImmutable("now", new DateTimeZone("UTC"));

Ejemplo real

Código con múltiples responsabilidades, refactorizado a funciones de una sola cosa:

function guardarOrden(array $items, $usuario) { /* 40 líneas mezcladas */ }

// DESPUÉS
function calcularTotal(array $lineas): float {
    return array_sum(array_map(fn($l) => $l["precio"] * $l["ud"], $lineas));
}

function validarUsuario($user): bool {
    return $user !== null && $user->activo === true;
}

function registrarOrden(array $lineas, $user): void {
    if (!validarUsuario($user)) {
        throw new RuntimeException("Usuario no válido");

    $total = calcularTotal($lineas);

Código completo

Código completo: un flujo delgado y legible construido por funciones que se explican solas:

PHPflujo-limpio.php
<?php

declare(strict_types=1);

function emailValido(string $email): bool {
    return str_contains($email, "@") && strlen($email) <= 254;
}

function esAdulto(int $edad): bool {
    return $edad >= 18;
}

function puedeRegistrarse(string $email, int $edad): bool {
    return emailValido($email) && esAdulto($edad);
}

$email  = "ada@example.com";
$edad   = 36;

if (puedeRegistrarse($email, $edad)) {
    echo "Registro permitido para $email";
} else {
    echo "Registro denegado";
}

Explicación

Compara las dos versiones del descuento: la "buena" nombra parámetros, variables y resultados con intención, y min() comunica la regla mejor que mil comentarios. En los comentarios, el segundo explica una decisión (la conversión a UTC), que el código no transmite.

La refactorización divide la orden en cuatro funciones de una sola cosa: cada una se prueba sola, se entiende sola y se reutiliza sola. El flujo final combina predicados simples (emailValido, esAdulto) en una decisión compuesta que se lee como una frase.

Errores comunes

  • Nombres crípticos ($t, $data, $aux).
  • Funciones de 50+ líneas que hacen validar, calcular, persistir e imprimir.
  • Comentarios que repiten el código (quedan obsoletos y mienten).
  • Inconsistencia de estilo (comillas, sangría, nomenclatura) entre archivos.

Buenas prácticas

  • Un concepto, un nombre; un nombre, un concepto (consistencia).
  • Refactoriza en cuanto hueles duplicación o "una cosa más" en la función.
  • Usa herramientas estáticas (PHPStan, Psalm, lint) para uniformar el estilo.

Ejercicio

Limpia el desaguisado

Dificultad: Media

A partir de este código sucio, reescríbelo limpio:

PHPsucio.php
$n = 70; $p = 1.5; $t = $n * $p; if ($t > 100) { echo "alto"; }

Pista: nombres que revelen intención, función que calcule el total y una comprobación con nombre.

Resumen

  • Nombres expresivos, funciones pequeñas, pocos parámetros.
  • Comenta el porqué, no el qué.
  • Consistencia y lectura fácil por encima de ingenio.
