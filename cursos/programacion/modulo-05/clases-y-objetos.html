Clases y objetos

14 min Intermedio PHP Programación Orientada a Objetos

Introducción

Los arrays y stdClass organizan datos, pero el código serio necesita estructuras con diseño. La programación orientada a objetos (POO) agrupa estado (atributos) y comportamiento (métodos) en unidades reutilizables llamadas clases.

Definición

Una clase es el plano; un objeto es la instancia creada a partir del plano. Se define con class Nombre { ... } y se instancia con new Nombre(). El operador -> accede a atributos y métodos del objeto. Nombradas en PascalCase (cada palabra con mayúscula inicial).

Conceptos clave

  • Clase: molde con estado y comportamiento (definición).
  • Objeto: instancia concreta, con sus propios valores.
  • Atributos: las propiedades del objeto (public $nombre).
  • Métodos: funciones dentro de la clase que usan $this.
  • new crea instancias; varias instancias comparten el molde pero no los datos.

Ejemplo básico

La clase más simple con un atributo y un método:

PHPclase.php
class Usuario {
    public $nombre;

    public function saludar(): string {
        return "Hola, soy $this->nombre";
    }
}

$ada = new Usuario();
$ada->nombre = "Ada";
echo $ada->saludar();

Ejemplo intermedio

Dos instancias independientes del mismo molde:

PHPinstancias.php
class Producto {
    public $nombre;
    public $precio;
}

$teclado  = new Producto();
$teclado->nombre = "Teclado";
$teclado->precio = 45.0;

$raton  = new Producto();
$raton->nombre = "Ratón";
$raton->precio = 15.0;

echo $teclado->nombre . " | " . $raton->nombre;

Ejemplo real

Métodos que operan sobre el estado del objeto:

PHPcarrito.php
class Carrito {
    public array $items = [];

    public function agregar(string $item): void {
        $this->items[] = $item;
    }

    public function contar(): int {
        return count($this->items);
    }
}

$carrito = new Carrito();
$carrito->agregar("teclado");
$carrito->agregar("ratón");
echo $carrito->contar();   // 2

Código completo

Código completo: una clase pedido con subtotal, IVA y total, usada en el día a día de una tienda:

PHPpedido.php
<?php

declare(strict_types=1);

class Pedido {
    public string $cliente;
    public array $lineas = [];
    public const IVA = 0.21;

    public function agregarLinea(string $producto, float $precio, int $ud): void {
        $this->lineas[] = [
            "producto" => $producto,
            "precio" => $precio,
            "ud" => $ud,
        ];
    }

    public function subtotal(): float {
        $suma = 0.0;
        foreach ($this->lineas as $linea) {
            $suma += $linea["precio"] * $linea["ud"];
        }
        return $suma;
    }

    public function total(): float {
        return round($this->subtotal() * (1 + self::IVA), 2);
    }
}

$p = new Pedido();
$p->cliente = "Ada";
$p->agregarLinea("Teclado", 45.0, 1);
$p->agregarLinea("Ratón", 15.0, 2);

printf("Cliente: %s | Total: %.2f €\n", $p->cliente, $p->total());

Explicación

En clase.php, $this conecta el método con esa instancia concreta: cada objeto tiene su propio nombre. En el ejemplo de instancias, el molde Producto produce dos objetos con datos distintos: definir una clase no crea nada hasta que no escribes new.

El carrito demuestra el valor real: el estado (la lista) y las operaciones (agregar/contar) viven juntos, protegidos como unidad. En el pedido final, los métodos subtotal() y total() encapsulan el cálculo y self::IVA accede a la constante de la clase.

Errores comunes

  • Olvidar new: sin instancia, los métodos no existen.
  • Usar $this fuera de un método o confundir self (clase) con $this (instancia).
  • Dejar atributos públicos que cualquiera pueda corromper (llegará el encapsulamiento).
  • Nombrar la clase en minúscula: la convención es PascalCase.

Buenas prácticas

  • Una clase representa una entidad o un concepto único de negocio.
  • Los métodos deben expresar acciones (agregarLinea(), total()).
  • Empieza con POO simple: atributos y métodos directos, sin sobre-diseñar.

Ejercicio

Clase Cuenta

Dificultad: Fácil
  1. Crea class Cuenta con atributo público $saldo (número).
  2. Métodos depositar(float $d): void y retirar(float $r): void que ajusten $this->saldo.
  3. Instancia dos cuentas, haz depósitos y retiros, y muestra ambos saldos.

Resumen

  • Clase = molde; objeto = instancia con new.
  • $this conecta métodos con el objeto actual; self:: con la clase.
  • Atributos + métodos = estado y comportamiento juntos.
