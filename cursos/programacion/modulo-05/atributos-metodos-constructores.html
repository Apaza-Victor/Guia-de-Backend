Atributos, métodos y constructores

14 min Intermedio PHP Programación Orientada a Objetos

Introducción

Una clase con atributos públicos que se rellenan a mano es un riesgo: alguien olvida asignar un valor y el objeto nace incompleto. Los constructores resuelven esto garantizando que cada objeto arranque bien formado.

Definición

El método __construct(...) se ejecuta automáticamente al hacer new. En PHP 8 puedes declarar atributos directamente en el constructor con property promotion: public function __construct(public string $nombre) {}, que crea el atributo y lo asigna en una sola línea. Los métodos (getters) exponen el estado y los setters lo controlan.

Conceptos clave

  • __construct() inicializa cada nueva instancia.
  • Constructor con parámetros = objeto siempre completo al nacer.
  • Property promotion (PHP 8): public function __construct(public string $nombre).
  • Getters: getNombre(): string { return $this->nombre; }.
  • Setters con validación: setPrecio(float $p) que rechace negativos.

Ejemplo básico

Constructor clásico con asignación manual:

PHPconstructor.php
class Producto {
    public string $nombre;
    public float $precio;

    public function __construct(string $nombre, float $precio) {
        $this->nombre = $nombre;
        $this->precio = $precio;
    }
}

$p = new Producto("Teclado", 45.0);
echo $p->nombre . " — " . $p->precio;

Ejemplo intermedio

Con property promotion (PHP 8) el código se reduce a lo esencial:

PHPpromocion.php
class Producto {
    public function __construct(
        public string $nombre,
        public float $precio = 0.0
    ) {}
}

$p = new Producto("Monitor");
$p2 = new Producto("Ratón", 15.0);
echo $p->nombre . " | " . $p2->precio;

Ejemplo real

Setters y getters que validan antes de aceptar:

PHPsetters.php
class Cliente {
    public function __construct(
        private string $nombre,
        private float $descuento = 0.0
    ) {}

    public function getNombre(): string {
        return $this->nombre;
    }

    public function setDescuento(float $descuento): void {
        if ($descuento < 0.0 || $descuento > 0.5) {
            throw new InvalidArgumentException("Descuento no válido");
        }
        $this->descuento = $descuento;
    }

    public function getDescuento(): float {
        return $this->descuento;
    }
}

$c = new Cliente("Ada");
$c->setDescuento(0.2);
echo $c->getNombre() . " — " . ($c->getDescuento() * 100) . "%";

Código completo

Código completo: un pedido que valida sus líneas desde el constructor:

PHPpedido-validado.php
<?php

declare(strict_types=1);

class LineaPedido {
    public function __construct(
        public readonly string $producto,
        public readonly float $precio,
        public readonly int $cantidad
    ) {
        if ($precio < 0 || $cantidad <= 0) {
            throw new InvalidArgumentException("Línea de pedido inválida");
        }
    }
}

class Pedido {
    private array $lineas = [];

    public function agregar(LineaPedido $linea): void {
        $this->lineas[] = $linea;
    }

    public function total(): float {
        $suma = 0.0;
        foreach ($this->lineas as $linea) {
            $suma += $linea->precio * $linea->cantidad;
        }
        return $suma;
    }
}

$p = new Pedido();
$p->agregar(new LineaPedido("Teclado", 45.0, 1));
$p->agregar(new LineaPedido("Ratón", 15.0, 2));
echo "Total: {$p->total()} €";

Explicación

El constructor convierte "crear objeto" en "crear objeto correcto": con parámetros obligatorios es imposible tener un Producto sin nombre. La promoción de propiedades comprime declaración y asignación en una línea sin perder legibilidad.

Los getters/setters añaden una capa de control: setDescuento() rechaza valores absurdos antes de tocar el estado, manteniendo el objeto siempre coherente. Y en el pedido final, el constructor de LineaPedido valida la propia línea y readonly (PHP 8.1) impide que cambie después de nacer.

Errores comunes

  • Olvidar el constructor y dejar atributos sin inicializar.
  • No validar en setters: cualquier valor entra y corrompe el estado.
  • Crear getters que devuelven $this sin control (fine si lo quieres deliberadamente).
  • Confundir readonly con valores que "nunca cambian": solo impide escribir tras la construcción.

Buenas prácticas

  • Exige en el constructor todo lo que el objeto necesita para ser válido.
  • Valida en setters y en el constructor; expón con getters lo mínimo.
  • Usa readonly para datos inmutables (IDs, fechas, config).

Ejercicio

Libreta de gastos

Dificultad: Media
  1. Crea class Gasto con promotion de concepto (string) y importe (float).
  2. Lanza InvalidArgumentException si el importe es ≤ 0.
  3. Crea 3 gastos, súmalos en un array y muestra el total.

Resumen

  • __construct garantiza objetos válidos; la promoción lo simplifica.
  • Getters leen, setters validan.
  • readonly protege la inmutabilidad.
