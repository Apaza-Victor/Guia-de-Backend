Funciones: definir y retornar

12 min Principiante PHP Funciones

Introducción

Repetir la misma lógica en varios sitios es la receta del desastre: cualquier cambio hay que aplicarlo en cada copia. Las funciones empaquetan una tarea con nombre para usarla cuando haga falta y cambiar el comportamiento en un solo lugar.

Definición

Una función es un bloque de código reutilizable con un nombre, que recibe entrada (parámetros), hace un proceso y devuelve un resultado con return. Se define con function nombre(...) { ... } y se llama con nombre(...). En PHP, las funciones son globales: puedes llamarlas antes de definirlas.

Conceptos clave

  • Definición: function calcularIva(float $base): float { return $base * 1.21; }.
  • Llamada: $total = calcularIva(100);.
  • return termina la función inmediatamente y entrega el valor.
  • Sin return la función devuelve null.
  • Los nombres en camelCase y con verbo: obtenerUsuario(), no usuario().

Ejemplo básico

La función más pequeña posible:

PHPsaludo.php
function saludar(): void {
    echo "Hola desde el backend\n";
}

saludar();
saludar();   // la reutilizamos cuantas veces queramos

Ejemplo intermedio

Con parámetros y retorno, la función calcula cualquier importe:

PHPiva.php
function conIva(float $base, float $tasa): float {
    return $base * (1 + $tasa);
}

echo conIva(100.0, 0.21);   // 121
echo "\n";
echo conIva(50.0, 0.10);    // 55

Ejemplo real

Componer funciones pequeñas para resolver tareas mayores:

PHPcompuesta.php
function formatearMoneda(float $valor): string {
    return number_format($valor, 2, ",", ".") . " €";
}

function totalConEnvio(float $subtotal, float $envio): string {
    $total = $subtotal + $envio;
    return formatearMoneda($total);
}

echo totalConEnvio(120.5, 6.99);
// 127,49 €

Código completo

Código completo: funciones como las de un carrito real, con tipos estrictos:

PHPnormalizador.php
<?php

declare(strict_types=1);

function convertirTexto(string $texto): string {
    return trim(preg_replace('/\s+/', ' ', $texto));
}

function normalizar(string $producto): string {
    return strtolower($producto);
}

function prepararNombre(string $nombre): string {
    return ucwords(convertirTexto(normalizar($nombre)));
}

echo prepararNombre("  ana  MARIA lopez ");   // Ana Maria Lopez

Explicación

En saludo.php la función devuelve void (sin valor) y solo provoca un efecto (imprimir). En iva.php la entrada son dos números y la salida un número; meter el cálculo en una función permite usarlo con cualquier base o tasa sin copiar la fórmula.

El ejemplo compuesto muestra la composición: una función llama a otra. El normalizador encadena tres pasos (recortar, minúsculas, capitalizar); cada función es diminuta y se prueba por separado. Así se construye el backend: piezas pequeñas y testables.

Errores comunes

  • Definir la función dentro de un if o bucle: se vuelve condicional y confunde.
  • Olvidar return y recibir null en vez del valor.
  • Escribir echo dentro y además retornar: doble salida inesperada.
  • Duplicar lógica en vez de extraerla a una función.

Buenas prácticas

  • Una función, una responsabilidad; nombre en forma de verbo.
  • Declara tipos en parámetros y retorno.
  • Mantén las funciones cortas (5-15 líneas suele ser buena señal).
  • Devuelve datos, no imprimas, salvo utilidades de presentación.

Ejercicio

Conversor de temperaturas

Dificultad: Fácil
  1. Crea celsiusAFahrenheit(float $c): float con la fórmula $c * 9 / 5 + 32.
  2. Crea fahrenheitACelsius(float $f): float (inversa: ($f - 32) * 5 / 9).
  3. Muestra la conversión de 100 °C y de 32 °F.

Resumen

  • Una función empaqueta entrada, proceso y salida bajo un nombre.
  • return entrega el valor y termina la función.
  • Compón funciones pequeñas en vez de escribir monolitos.
