Funciones anónimas y callbacks

12 min Intermedio PHP Funciones

Introducción

En backend, las funciones viajan como datos: las pasas a otras funciones para que decidan cuándo ejecutarlas. Ordenar una lista con tu propio criterio, responder a un evento, reaccionar cuando acaba una tarea… todo eso se hace con funciones anónimas y callbacks.

Definición

Una función anónima (closure) es una función sin nombre que se asigna a una variable: $fn = function (int $x): int { return $x * 2; };. Un callback es cualquier función, nombrada o anónima, que se pasa como argumento a otra función para que esta la invoque. La cláusula use ($var) captura variables del ámbito exterior dentro del closure.

Conceptos clave

  • Asignación: $duplicar = fn(int $x): int => $x * 2; (arrow fn, PHP 7.4+).
  • Arrow functions capturan automáticamente el ámbito por valor.
  • Callback como argumento: array_map($fn, $datos).
  • use ($v) importa variables exteriores en closures clásicos.
  • Los callbacks permiten inyectar comportamiento sin acoplar.

Ejemplo básico

De función anónima a arrow function:

PHPanonimas.php
$clasica = function (int $x): int {
    return $x * 2;
};

$flecha = fn(int $x): int => $x * 2;

echo $clasica(5) . " y " . $flecha(5);   // 10 y 10

Ejemplo intermedio

Callbacks con array_map y array_filter:

PHPmap-filter.php
$precios = [10, 25, 50, 100];

$conIva = array_map(fn($p) => $p * 1.21, $precios);
$caros  = array_filter($precios, fn($p) => $p > 30);

print_r($conIva);
print_r($caros);

Ejemplo real

Capturar del ámbito exterior con use o con arrow functions:

PHPcambio.php
$tasa = 0.10;

$descuento = fn($valor) => $valor * (1 - $tasa);

echo $descuento(100);   // 90

Código completo

Código completo: procesar una lista de pedidos con callbacks y orden personalizado:

PHPpedidos-callbacks.php
<?php

declare(strict_types=1);

$pedidos = [
    ["id" => 1, "total" => 45.5],
    ["id" => 2, "total" => 120.0],
    ["id" => 3, "total" => 8.75],
];

$labels = array_map(
    fn($p) => "Pedido {$p['id']}: {$p['total']} €",
    $pedidos
);

print_r($labels);

usort($pedidos, fn($a, $b) => $a["total"] <=> $b["total"]);
echo "Más barato: {$pedidos[0]['total']} €\n";

Explicación

Las funciones anónimas se asignan y se llaman igual que las nombradas; las arrow functions son su forma compacta (capturan el ámbito sin use). array_map transforma cada elemento y array_filter selecciona los que cumplen la condición: ambos reciben un callback y lo aplican.

En cambio.php el closure captura $tasa del exterior, un patrón fabuloso para configurar funciones. Y con usort, el operador navío <=> devuelve -1/0/1 y ordena según tu criterio. Nada de esto requiere nombre de función: el comportamiento se inyecta al vuelo.

Errores comunes

  • Al usar call_user_func y pasar un closure: asigna el resultado, no la llamada.
  • Olvidar el punto y coma tras el cierre del closure (actúa como declaración).
  • Creer que use ($x) modifica $x: hace una copia (usa &$x para mutar).
  • Pasarse de anidadas: un closure de 20 líneas dentro de una llamada se lee peor que una función nombrada.

Buenas prácticas

  • Una línea: arrow function; varias líneas: closure o función nombrada.
  • Prefiere array_map/array_filter sobre bucles manuales cuando no haya efectos secundarios.
  • Si un callback se repite, dale nombre con function o const en PHP 8.1+.

Ejercicio

Filtro de stock

Dificultad: Media
  1. Define $productos = ["teclado" => 5, "ratón" => 0, "monitor" => 2].
  2. Con array_filter y una arrow function, quédate con los que tienen stock > 0.
  3. Con array_map, devuelve "teclado: 5 uds".

Resumen

  • Funciones anónimas = function ($x) { ... }; arrow = fn($x) => ....
  • Callbacks inyectan comportamiento en array_map, array_filter, usort…
  • Captura el ámbito con use (closures) o automáticamente (arrows).
