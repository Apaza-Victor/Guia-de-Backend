Módulo 1 · Introducción a PHP

Instala tu entorno, escribe tu primer script y domina la sintaxis base: variables, tipos, operadores y salida.

5 lecciones ≈ 47 min Sin requisitos

Objetivos del módulo

✔Instalar PHP 8 y un editor recomendado, verificando el entorno desde la terminal.
✔Escribir y ejecutar el primer script PHP usando el intérprete y el servidor integrado.
✔Dominar las etiquetas <?php ?>, los comentarios y la salida con echo y print.
✔Declarar variables, constantes y usar los tipos de datos y la coerción de PHP 8.
✔Aplicar operadores aritméticos, de comparación, lógicos y de asignación en expresiones reales.
