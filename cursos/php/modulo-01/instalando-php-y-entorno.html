Instalando PHP y configurando el entorno

⚙️ Intermedio 8 min PHP desde cero hasta avanzado Módulo 1 · Introducción a PHP

Qué necesitas

Para seguir este curso solo necesitas tres piezas: un intérprete de PHP versión 8 o superior, un editor de textos y una terminal. No hace falta instalar una base de datos todavía: los primeros módulos funcionan perfectamente con PHP puro.

Puedes usar cualquier editor moderno. Visual Studio Code con la extensión «PHP Intelephense» es una opción gratuita y popular porque te ofrece resaltado de sintaxis, autocompletado y detección de errores mientras escribes.

  • PHP 8.x: el intérprete del lenguaje (incluye el servidor web integrado).
  • Editor: VS Code, PHPStorm, Sublime Text u otro de tu preferencia.
  • Terminal: PowerShell en Windows, Terminal en macOS o la consola de Linux.

Instalación por sistema operativo

La forma más rápida de instalar solo el intérprete es usando el gestor de paquetes de tu sistema. En Windows puedes usar Chocolatey; en macOS, Homebrew, y en las distribuciones de Linux basadas en Debian, apt.

Si prefieres un entorno «todo en uno» con Apache y MySQL para más adelante, XAMPP (Windows, macOS y Linux) o Laragon (Windows) son alternativas muy usadas en el mundo profesional porque incluyen PHP, un servidor web y MySQL en un solo paquete.

Ejercicio

  1. Instala PHP 8 en tu sistema siguiendo el método que prefieras.
  2. Ejecuta php -v y anota la versión exacta que tienes.
  3. Ejecuta php -m y busca si aparece el módulo pdo.
  4. Crea una carpeta mis-proyectos, inicia el servidor con php -S localhost:8000 y confirma que responde en el navegador.

Resumen

  • PHP 8 se instala con el gestor de paquetes de tu sistema o con paquetes como XAMPP.
  • php -v verifica la instalación y php -m lista los módulos.
  • El servidor de desarrollo se levanta con php -S localhost:8000.
  • El archivo index.php dentro de la carpeta se ejecuta al entrar a la URL raíz.
