Tu primer script: hola mundo

⚙️ Intermedio 7 min PHP desde cero hasta avanzado Módulo 1 · Introducción a PHP

Tu primer script

Crea un archivo llamado hola.php con el siguiente contenido. Los archivos de PHP pueden vivir en cualquier carpeta, pero lo normal es agruparlos dentro de un directorio de proyecto.

Todo el código del lenguaje se escribe dentro de las etiquetas <?php ... ?>. Sin ellas, PHP no sabe qué texto debe interpretar como código y qué texto debe enviar tal cual al resultado.

Desde la terminal y desde el navegador

PHP puede ejecutarse de dos formas: como un script de consola o como un programa web.

Para la línea de comandos, ejecuta el archivo directamente con el intérprete:

En el primer caso verás el texto Hola, mundo! impreso en la consola. Para la versión web, levanta el servidor de desarrollo php -S localhost:8000 en la carpeta del proyecto y visita http://localhost:8000/hola.php: el navegador hará la petición HTTP, PHP lo ejecutará en el servidor y devolverá el resultado.

echo y print: escribir en la salida

Las dos construcciones más usadas para generar texto son echo y print. Ambos imprimen a la salida, pero echo permite varios argumentos y es ligeramente más rápido.

Observa la otra novedad: el punto (.) encadena strings y PHP_EOL representa un salto de línea que funciona en cualquier sistema operativo.

También puedes escribir <?= ?>, la etiqueta corta de eco, que es exactamente lo mismo que <?php echo ... ?>:

Ejercicio

  1. Escribe hola.php con tu nombre dentro del mensaje, por ejemplo «Hola, Ana», y ejecútalo con php hola.php.
  2. Levanta el servidor de desarrollo y comprueba que el navegador muestra el mismo texto.
  3. Modifica el archivo para que imprima tu nombre con echo y tu edad con print en dos líneas.

Resumen

  • El código PHP va dentro de <?php ... ?>.
  • Se ejecuta igual desde la terminal que desde el servidor web.
  • echo y print generan la salida; <?= ?> es la abreviatura de echo.
  • El punto «.» concatena textos y PHP_EOL añade un salto de línea portable.
