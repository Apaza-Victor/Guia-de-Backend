Sintaxis básica y etiquetas PHP

⚙️ Intermedio 10 min PHP desde cero hasta avanzado Módulo 1 · Introducción a PHP

Las etiquetas de PHP

PHP es un lenguaje de plantilla: se escribe mezclado con HTML y solo se ejecuta la porción marcada por las etiquetas de apertura y cierre. La etiqueta completa es <?php ... ?>.

Cuando el servidor recibe una petición, procesa el archivo de arriba a abajo: lo que está dentro de las etiquetas se ejecuta como programa PHP y lo que está fuera se envía tal cual al cliente.

  • <?php ?>: la etiqueta estándar, la única recomendada.
  • <?= ?>: etiqueta corta de eco, equivalente a <?php echo ?>.
  • <? ?>: etiqueta corta normal, desaconsejada y a menudo desactivada.

En un archivo formado solo por código PHP se recomienda no cerrar la etiqueta al final: el carácter de cierre puede añadir un espacio o salto de línea accidental a la respuesta, un error clásico que genera el aviso «headers already sent».

Instrucciones y punto y coma

Cada instrucción de PHP termina con un punto y coma (;). Es el equivalente al punto final de una oración: si lo omites, el intérprete no sabe dónde acaba la sentencia y lanza un error de sintaxis.

Los espacios y saltos de línea no importan para la ejecución, igual que en JavaScript o Python. La indentación es solo para que el código sea legible. Hay una excepción: estructuras como if, for o foreach no llevan punto y coma después del bloque, solo al final de las instrucciones internas.

Comentarios

Los comentarios no se ejecutan: sirven para documentar y aclarar el código. PHP reconoce tres estilos.

Sensibilidad a mayúsculas

En PHP las variables y los nombres de archivo/claves distinguen mayúsculas, pero las palabras clave del lenguaje (if, echo, foreach…) y los nombres de funciones no distinguen. Es decir: ECHO funciona, pero $Nombre y $nombre son variables distintas.

Como buena práctica, define un estilo y mantenlo siempre: $camelCase para variables y snake_case para funciones es una combinación muy común en proyectos PHP.

Ejercicio

  1. Crea perfil.php con un encabezado HTML <h1> y dos instrucciones de echo dentro de PHP.
  2. Añade un comentario multilínea que explique qué hace tu script.
  3. Elimina a propósito el punto y coma de una instrucción y ejecuta el archivo. Lee el mensaje de error y corrige el fallo.
  4. Comprueba que echo y ECHO producen el mismo resultado.

Resumen

  • El código se escribe entre <?php ?>; la etiqueta corta <?= ?> solo imprime.
  • Cada instrucción termina con punto y coma.
  • Los comentarios se escriben con //, # o /* */.
  • Las variables distinguen mayúsculas; las palabras clave del lenguaje no.
  • En archivos de solo PHP se omite la etiqueta de cierre final.
