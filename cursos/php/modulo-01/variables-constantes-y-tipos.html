Variables, constantes y tipos de datos

⚙️ Intermedio 12 min PHP desde cero hasta avanzado Módulo 1 · Introducción a PHP

Variables

Una variable es una caja con nombre que guarda un valor. En PHP todas las variables empiezan con el símbolo $ seguido de un nombre que puede contener letras, números (no al inicio) y guiones bajos.

PHP es un lenguaje con tipado dinámico: la misma variable puede cambiar de tipo en marcha. No declaras el tipo, solo asignas. Las comillas dobles permiten interpolar variables dentro del texto, mientras que las comillas simples no.

Tipos de datos escalares

PHP 8 tiene cuatro tipos escalares básicos y dos tipos especiales que encontrarás todo el tiempo:

  • int: números enteros, como 42 o -17.
  • float: números decimales, como 3.14.
  • string: cadenas de texto, como "Hola".
  • bool: true o false.
  • null: la ausencia de valor.
  • array: colecciones de datos (lo verás a fondo en el módulo 3).

Constantes

Una constante es un valor con nombre que no cambia durante la ejecución. Se define con define() o con la palabra clave const. Por convención se escriben en MAYÚSCULAS.

La diferencia práctica: const se usa dentro de una clase o desde el nivel superior del archivo y se compila en tiempo de carga; define() es una función y puede usarse dentro de bloques condicionales.

Coerción y strict_types

Por defecto, PHP intenta convertir automáticamente los tipos cuando haces operaciones mezcladas: un string como "25" se convierte a int al sumar. A esto se le llama coerción y, aunque resulta cómoda, puede ocultar errores.

Si quieres desactivar la coerción en el paso de argumentos, coloca declare(strict_types=1); como primera línea del archivo. Así los parámetros con tipo de función recibirán solo valores de ese tipo y se lanzará a un TypeError si no cumplen.

Ejercicio

  1. Crea variables para tu nombre, edad, altura (con decimales) y si estudia backend (booleano). Imprímelas con comillas dobles.
  2. Define la constante ANTIGUEDAD_MINIMA con valor 18 y úsala en una frase.
  3. Ejecuta var_dump(100 === 100.0) y explica por qué da false.
  4. Crea un archivo con declare(strict_types=1); y comprueba la diferencia que notas al sumar "10" + 2.

Resumen

  • Las variables empiezan con $ y tienen tipado dinámico.
  • Los tipos escalares son int, float, string, bool y null; array y object son compuestos.
  • Las comillas dobles interpolan variables; las simples no.
  • Las constantes se definen con define() o const y no cambian.
  • === compara valor y tipo; strict_types=1 desactiva la coerción en funciones.
