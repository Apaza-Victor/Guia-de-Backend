Módulo 1 · Introducción a PHP

5 lecciones≈ 47 min

Instala PHP, configura tu entorno de desarrollo y domina la sintaxis básica: etiquetas, variables, constantes, tipos de datos y operadores.

  1. Tu primer script: hola mundo
  2. Instalando PHP y configurando el entorno
  3. Operadores y expresiones
  4. Sintaxis básica y etiquetas PHP
  5. Variables, constantes y tipos de datos
Empezar módulo

Módulo 2 · Control de flujo y funciones

5 lecciones≈ 48 min

Toma decisiones con condicionales, repite trabajo con bucles y organiza tu código en funciones con parámetros por valor y por referencia.

  1. Alcance de variables (scope)
  2. Bucles: for, foreach y while
  3. Condicionales: if, else y match
  4. Funciones: definir, parámetros y retorno
  5. Parámetros por valor y por referencia
Empezar módulo

Módulo 3 · Arrays y estructuras de datos

5 lecciones≈ 54 min

Maneja arrays indexados y asociativos, recórrelos con foreach, procesa colecciones con array_map/filter/reduce y trabaja strings, archivos y JSON.

  1. Manipulación de archivos y JSON
  2. Arrays indexados y asociativos
  3. Funciones útiles: array_map, filter y reduce
  4. Recorriendo arrays con foreach
  5. Strings: funciones de texto y expresiones
Empezar módulo

Módulo 4 · PHP moderno

5 lecciones≈ 49 min

Aprovecha lo mejor de PHP 8: la expresión match, el operador nullsafe, arrow functions y closures, enums y el tipado estricto para escribir código expresivo y difícil de romper.

  1. La expresión match
  2. Operador nullsafe y null coalescing
  3. Arrow functions y closures
  4. Enums y tipos avanzados
  5. Tipos estrictos y declaraciones de tipo
Empezar módulo

Módulo 5 · Base de datos con PDO

5 lecciones≈ 54 min

Trabaja con bases de datos relacionales mediante PDO: conexión, consultas preparadas, transacciones, modos de fetch y una capa de datos encapsulada en repositorios.

  1. PDO: conexión y configuración
  2. Consultas preparadas con parámetros
  3. Transacciones: commit y rollback
  4. Modo fetch: asociativo, objeto y clase
  5. Repositorio y capa de datos
Empezar módulo

Módulo 6 · APIs y servicios

5 lecciones≈ 55 min

Diseña APIs REST en PHP puro: front controller, enrutado, controladores con respuestas HTTP, serialización JSON, autoload con Composer y middlewares para ordenar las peticiones.

  1. Front controller y enrutado
  2. Controladores y respuestas HTTP
  3. Serializando JSON desde PHP
  4. Composer: autoload y PSR-4
  5. Middlewares y ciclo de la petición
Empezar módulo

Módulo 7 · Seguridad y despliegue

4 lecciones≈ 44 min

Endurece tu PHP: contraseñas con password_hash, validación y saneamiento, cabeceras de seguridad con CSRF, y despliegue sobre Nginx con PHP-FPM y OPcache.

  1. Passwords con password_hash y password_verify
  2. Validación y saneamiento de entrada
  3. Cabeceras de seguridad y CSRF
  4. Despliegue con Nginx y PHP-FPM
