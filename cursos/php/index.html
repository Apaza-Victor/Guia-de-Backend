PHP desde cero hasta avanzado

El curso completo de PHP: sintaxis, POO, MySQL, Composer, MVC, seguridad y desarrollo de APIs REST de nivel profesional.

10 semanas 8 módulos · 39 lecciones PHP · MySQL · Composer · PDO

¿Qué vas a aprender?

PHP es el motor detrás de una gran parte de la web: impulsa proyectos de todos los tamaños, desde blogs pequeños hasta plataformas como WordPress o Laravel. En este curso partirás desde cero con la sintaxis moderna de PHP 8, luego dominarás la programación orientada a objetos, el acceso a bases de datos con PDO y la gestión de dependencias con Composer. Terminarás construyendo una aplicación completa en arquitectura MVC y exponiendo tus propios servicios mediante APIs REST, con buenas prácticas de seguridad en cada paso.

Objetivos de aprendizaje

✔Programar con soltura usando la sintaxis de PHP 8 y sus tipos modernos.
✔Aplicar programación orientada a objetos: clases, herencia, interfaces y traits.
✔Conectar y operar bases de datos MySQL con PDO y consultas preparadas.
✔Estructurar proyectos profesionales con Composer, namespaces y autoloading.
✔Construir APIs REST seguras siguiendo el patrón MVC.

Requisitos previos

  • Fundamentos de Backend: entender qué es el backend, HTTP y el modelo cliente-servidor.
  • Programación para Backend: lógica, funciones y POO en cualquier lenguaje.
  • Bases de Datos / SQL: nociones de tablas y consultas básicas (recomendable).

Tecnologías y herramientas

PHP MySQL Composer PDO MVC REST

Módulos del curso

Ocho módulos que avanzan de la sintaxis al nivel profesional: primero el lenguaje, luego bases de datos, Composer, MVC y, al final, APIs y seguridad.

1. Introducción a PHP

Instala tu entorno, escribe tu primer script y domina la sintaxis base: variables, tipos, operadores y salida.

5 lecciones≈ 45 min
  • Instalando PHP y configurando el entorno
  • Tu primer script: hola mundo
  • Sintaxis básica y etiquetas PHP
  • Variables, constantes y tipos de datos
  • Operadores y expresiones

2. Control de flujo y funciones

Condicionales, bucles y funciones reutilizables para que tus scripts tomen decisiones y organicen la lógica.

5 lecciones≈ 48 min
  • Condicionales: if, else y match
  • Bucles: for, foreach y while
  • Funciones: definir, parámetros y retorno
  • Parámetros por valor y por referencia
  • Alcance de variables (scope)

3. Arrays y estructuras de datos

Trabaja con colecciones: arrays indexados, asociativos, funciones de orden superior y manejo de strings.

5 lecciones≈ 50 min
  • Arrays indexados y asociativos
  • Recorriendo arrays con foreach
  • Funciones útiles: array_map, filter y reduce
  • Strings: funciones de texto y expresiones
  • Manipulación de archivos y JSON

4. Programación Orientada a Objetos

Clases, objetos, herencia, interfaces y traits: el estilo de programación que usan los frameworks modernos.

5 lecciones≈ 52 min
  • Clases y objetos
  • Propiedades, métodos y constructores
  • Encapsulamiento: public, private y protected
  • Herencia y polimorfismo
  • Interfaces, traits y clases anónimas

5. Bases de datos con PDO

Conecta tu código con MySQL de forma segura: PDO, consultas preparadas, transacciones y un CRUD completo.

5 lecciones≈ 55 min
  • Introducción a PDO y conexiones
  • Consultas preparadas y anti inyección
  • CRUD completo con MySQL
  • Transacciones y manejo de errores
  • Relaciones entre tablas en la práctica

6. Composer y dependencias

El gestor de paquetes de PHP: namespaces, autoloading, dependencias y el ecosistema Packagist.

4 lecciones≈ 38 min
  • Qué es Composer y por qué usarlo
  • Instalando paquetes con Packagist
  • Namespaces y autoloading PSR-4
  • Scripts y automatización de tareas

7. MVC y estructura de proyecto

Organiza tu código en Modelo-Vista-Controlador: rutas, controladores, vistas y servicios desacoplados.

5 lecciones≈ 50 min
  • El patrón MVC explicado
  • Front controller y router
  • Controladores y validación de entrada
  • Vistas y plantillas con HTML
  • Capas de servicio y repositorio

8. Seguridad y APIs REST

Protege tus aplicaciones y expón servicios: password_hash, JWT, buenas prácticas OWASP y APIs REST.

5 lecciones≈ 55 min
  • Seguridad básica: passwords y sesiones
  • Tokens JWT en PHP
  • Diseñando una API REST propia
  • Validación, errores y status codes
  • Buenas prácticas OWASP aplicadas a PHP
