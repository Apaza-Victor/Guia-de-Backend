Arrow functions y closures

⚙️ Intermedio 10 min PHP desde cero hasta avanzado Módulo 4 · PHP moderno

Introducción

Los callbacks son la herramienta favorita de PHP para procesar colecciones: transformar un array, filtrar una lista, reducir un total. Durante años hinchaban el código con sintaxis verbosa.

Las arrow functions de PHP 7.4 y su captura automática del ámbito simplifican estos callbacks a una sola expresión.

Definición

Una arrow function (fn) es una función anónima que devuelve una sola expresión y captura automáticamente las variables del ámbito exterior por valor. Una closure es una función anónima que captura variables explícitamente con use.

Por qué importa. Los callbacks cortos hacen el código de backend declarativo: al leer array_map(fn($p) => $p['total'], $pedidos) sabes al instante qué ocurre.

Cuándo usarlo. Usa fn para callbacks de una línea. Usa function () use (...) cuando la lógica necesite varias sentencias o capturar por referencia.

Conceptos clave

  • fn($x) => expresion devuelve la expresión sin return.
  • Las arrow functions capturan el ámbito exterior automáticamente por valor.
  • use ($var) declara qué variable exterior entra en una closure.
  • El paso por referencia en closures se hace con use (&$var).
  • Ambas son callables: servirán a array_map, array_filter y demás.

Ejemplo básico

Extraemos los importes de cada pedido con una arrow function de una sola línea.

Array
(
    [0] => 120.5
    [1] => 45.99
    [2] => 200
)

Ejemplo intermedio

Una closure captura una variable exterior con use y la usa dentro de su cuerpo.

Ejemplo real

En un backend, las closures se usan para fabricar filtros reutilizables según un umbral o un contexto de ejecución.

  • Devuelve callbacks desde funciones para componer filtros dinámicos.
  • Captura lo mínimo: cuantas menos variables exteriores, más predecible.
  • Prefiere fn para una línea y function con use para lógica ramificada.

Las arrow functions capturan por valor; si necesitas acumular estado entre llamadas, usa una closure con use (&$acumulador).

Explicación

  • fn captura el ámbito sin escribir use: es sintaxis consistente y corta.
  • Las arrow functions solo pueden tener una expresión como cuerpo.
  • use captura por valor por defecto; usa & para capturar por referencia.
  • Las closures son objetos Closure: se guardan, se pasan y se invocan.
  • Ambas funcionan igual como callables de array_map, filter o reduce.

Errores comunes

  • Intentar escribir más de una sentencia en una arrow function.
  • Olvidar use al capturar una variable exterior en una closure clásica.
  • Modificar una variable capturada por valor y esperar que persista.

Buenas prácticas

  • Usa fn para callbacks triviales y function + use para lógica mayor.
  • Nombra los parámetros del callback con intención: fn($pedido) y no fn($x).
  • Captura solo lo necesario para mantener el callback predecible.

Ejercicio

  1. Convierte una closure clásica de una línea en una arrow function.
  2. Filtra con array_filter los pedidos que superen un umbral capturado.
  3. Acumula un total con array_reduce y una arrow function.

Resumen

  • Las arrow functions devuelven una expresión y capturan el ámbito solo.
  • Las closures declaran sus capturas con use y soportan lógica ramificada.
  • Ambas convierten el procesamiento de colecciones en código legible.
