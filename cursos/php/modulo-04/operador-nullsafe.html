Operador nullsafe y null coalescing

⚙️ Intermedio 9 min PHP desde cero hasta avanzado Módulo 4 · PHP moderno

Introducción

Nada tira más un backend que un acceso a propiedad sobre un valor null. Cuando los datos vienen de una base de datos o de otra API, siempre puede faltar un campo, un objeto o un resultado.

PHP 8 añade el operador nullsafe (?->), que corta la cadena de accesos en cuanto encuentra null en lugar de lanzar error.

Definición

El operador nullsafe ?-> solo accede a la propiedad o método si el objeto previo no es null; si lo es, toda la expresión devuelve null. El null coalescing ?? aporta un valor por defecto cuando el resultado es null.

Por qué importa. Los datos de entrada son opcionales por naturaleza: un perfil sin dirección, un cliente sin plan, un resultado de consulta vacío. Encadenar accesos sin protección revienta en producción.

Cuándo usarlo. Usa ?-> para cadenas de accesos opcionales sobre objetos y ?? para cualquier valor que pueda ser null: variables, arrays y resultados de funciones.

Conceptos clave

  • ?-> corta la cadena y devuelve null si el operando anterior es null.
  • ?? devuelve el valor por defecto si la expresión izquierda es null.
  • ??= asigna solo cuando la variable no existe o es null.
  • El nullsafe no reemplaza la validación: es una defensa, no una excusa.
  • Se combina: $a?->b->c ?? 'por defecto' para proteger y dar salida.

Ejemplo básico

Un array que puede carecer de un campo anidado deja de ser un problema con el operador de fusión.

Ejemplo intermedio

Con objetos, el nullsafe encadena propiedades opcionales sin if intermedios.

Ejemplo real

Un cliente que llega de una consulta puede no existir. El nullsafe deja escribir la regla en una sola línea legible.

  • Aísla la cadena opcional en una variable con nombre claro.
  • Aporta siempre un valor por defecto con ?? para que el dato tenga contenido.
  • Registra cuándo faltó el dato: el null no debe ser un accidente silencioso.

El nullsafe detiene la cadena pero no evalúa el resto; por eso conviene combinar con ?? para tener siempre un valor con sentido.

Explicación

  • ?-> corta la evaluación en cuanto encuentra null: no accede a lo siguiente.
  • Es válido para métodos: $objeto?->metodo() solo se llama si el objeto existe.
  • ?? también protege contra variables no definidas sin emitir avisos.
  • El null coalescing es una mejora directa de isset() con dos operandos.
  • Encadenar varios ?-> en una línea sigue siendo legible si el dato es claro.

Errores comunes

  • Acceder a ?-> sobre un valor que no es objeto ni null: reventará igual.
  • Usar ?-> allí donde hace falta una decisión real (if/else).
  • Olvidar el valor por defecto y propagar null a la siguiente capa.

Buenas prácticas

  • Da nombre a la cadena opcional: $plan, $email, $direccion…
  • Combina ?-> y ?? para cubrir acceso y valor por defecto en una línea.
  • No uses nullsafe para esconder errores de diseño sin avisar del fallo.

Ejercicio

  1. Reescribe una cadena de accesos con ifs anidados usando ?-> y ??.
  2. Protege el acceso a $respuesta['datos']['usuario']['email'] con ??.
  3. Crea un objeto con una propiedad ?Direccion null y accede con ?->.

Resumen

  • ?-> corta la cadena de accesos si encuentra null.
  • ?? aporta el valor por defecto para los buenos y los malos momentos.
  • La combinación de ambos deja los accesos opcionales en una línea legible.
