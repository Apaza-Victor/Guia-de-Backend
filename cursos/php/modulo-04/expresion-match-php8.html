La expresión match

⚙️ Intermedio 10 min PHP desde cero hasta avanzado Módulo 4 · PHP moderno

Introducción

Decidir entre muchas opciones era cosa de cadenas de elseif con su riesgo de repetir asignaciones y olvidar un caso. PHP 8 trae match: una expresión que compara con igualdad estricta y devuelve un valor.

En un backend, match brilla para clasificar códigos HTTP, estados de pedidos o roles de usuario, y encaja perfecto con el resto del código moderno.

Definición

match es una expresión que evalúa el valor de una variable y devuelve el resultado del primer brazo cuya condición coincida (con comparación estricta ===), sin case por defecto y lanzando UnhandledMatchError si nada casa.

Por qué importa. Evita la verbosidad y los errores de fall-through de switch, garantiza que siempre devuelvas algo y hace el mapa de casos legible de un vistazo.

Cuándo usarlo. Úsalo cuando compares un mismo valor contra varios casos (estados, códigos, roles). Para rangos o condiciones complejas usa match(true) o if tradicional.

Conceptos clave

  • match compara con === y devuelve el valor del primer brazo que coincida.
  • Puede agrupar varios valores en un solo brazo: 200, 201 => 'ok'.
  • Es una expresión: su resultado se asigna o se retorna directamente.
  • Sin coincidencia lanza UnhandledMatchError; añade siempre un default.
  • match(true) evalúa condiciones booleanas como si fueran casos.

Ejemplo real

Traducir códigos de estado HTTP a etiquetas legibles es el pan de cada día en clientes HTTP y proxies que procesan respuestas.

  • Agrupa códigos equivalentes en el mismo brazo para no duplicar lógica.
  • Siempre existe un default: las APIs devuelven códigos inesperados.
  • Devuelve el resultado con return para mantener la función corta.

Como match es una expresión, puedes devolverla directamente con return y tu función queda sin variables intermedias.

Explicación

  • El primer brazo que coincide gana; el orden importa cuando los casos se solapan.
  • La comparación estricta evita sorpresas como 0 == 'abc'.
  • Psirve de reemplazo idiomático de switch para mapas valor-a-valor.
  • match(true) reutiliza la misma sintaxis para condiciones completas.
  • Cualquier brazo puede lanzar una excepción o llamar a una función: sigue devolviendo algo.

Errores comunes

  • Olvidar default y recibir UnhandledMatchError con un valor inesperado.
  • Usar match para rangos numéricos en vez de match(true) o if.
  • Confundir match con switch y esperar que se 'caiga' a la siguiente rama.

Buenas prácticas

  • Prefiere match a switch en PHP 8: es más seguro y legible.
  • Mantén cada brazo corto; si la lógica crece, llévala a un método.
  • Usa match(true) cuando tus casos sean condiciones y no valores.
  • Escribe siempre un default explícito aunque creas que cubres todo.

Ejercicio

  1. Reescribe una sentencia switch que clasifique notas (A, B, C, F) con match.
  2. Etiqueta códigos HTTP con match y devuelve también un mensaje de error.
  3. Usa match(true) para validar si un usuario puede editar, ver o eliminar según rol y estado.

Resumen

  • match compara con === y devuelve el valor del primer brazo coincidente.
  • match(true) transforma condiciones booleanas en casos legibles.
  • Un default explícito evita UnhandledMatchError con datos inesperados.
