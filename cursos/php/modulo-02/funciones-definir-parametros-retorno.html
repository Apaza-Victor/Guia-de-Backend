Funciones: definir, parámetros y retorno

⚙️ Intermedio 12 min PHP desde cero hasta avanzado Módulo 2 · Control de flujo y funciones

Definir y llamar funciones

Una función es un bloque de código con nombre que puedes ejecutar tantas veces como quieras. Se define con la palabra function seguida de un nombre descriptivo, paréntesis con sus parámetros y el cuerpo entre llaves.

En PHP, una función definida en el nivel superior del archivo está disponible en todo el script, incluso si la llamas en una línea anterior a donde se definió.

Parámetros tipados y valores por defecto

PHP 8 permite declarar el tipo de cada parámetro (int, float, string, bool, array, clases…). También puedes dar valores por defecto: si la llamada no aporta ese argumento, se usa el valor predeterminado.

El tipo que aparece junto a : antes de la llave es el tipo de retorno. Si la función devuelve algo que no cuadra, PHP lanza un TypeError.

Retorno anticipado

return devuelve un valor y detiene la función de inmediato. Un patrón muy usado en el backend es el early return: validar y salir pronto en lugar de anidar if.

Argumentos variádicos

El operador ... recoge un número indefinido de argumentos en un array. Es la base de funciones como array_sum o los ayudantes de logs que aceptan varios datos.

Ejercicio

  1. Define esPar(int $n): bool que devuelva true si el número es par.
  2. Crea descuento(float $precio, float $porcentaje = 10): float y pruébala con y sin el segundo argumento.
  3. Escribe una función bienvenida(...$usuarios) que imprima un saludo para cada usuario recibido.
  4. Añade el tipo de retorno : int a una función que devuelva un float y ejecuta para ver el TypeError.

Resumen

  • Las funciones se declaran con function nombre(...) y se llaman por su nombre.
  • Los parámetros pueden tener tipo y valores por defecto.
  • return devuelve un valor y detiene la función; el tipo de retorno se declara tras :.
  • El early return reduce anidamiento en validaciones.
  • ... permite un número variable de argumentos.
