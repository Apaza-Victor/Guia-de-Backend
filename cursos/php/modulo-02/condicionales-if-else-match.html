Condicionales: if, else y match

⚙️ Intermedio 10 min PHP desde cero hasta avanzado Módulo 2 · Control de flujo y funciones

if, else y elseif

La estructura if ejecuta un bloque solo si la condición es verdadera. Con else cubres el caso contrario y con elseif encadenas varias condiciones.

En la práctica del backend, el caso else suele representar la respuesta de error o el plan alternativo. Una buena lectura: si la validación pasa, sigue; si no, responde con el problema.

El operador ternario y el operador ??

Para decisiones simples en una sola línea, PHP ofrece el operador ternario condicion ? valorSiTrue : valorSiFalse y el null coalescing ??, que devuelve el valor de la derecha si el de la izquierda no existe o es null.

El operador ?? es uno de los secretos del backend moderno en PHP: permite leer datos de formularios, cabeceras o configuraciones sin que falle el script cuando la clave no existe.

match: la alternativa moderna

Cuando necesitas comparar un valor contra varias opciones, match (PHP 8) es más expresiva y segura que una cadena de if. A diferencia de switch, match es una expresión: devuelve un valor y usa comparación estricta ===.

Si ningún brazo coincide y no existe default, match lanza un UnhandledMatchError. Eso fuerza a cubrir todos los casos, que es justo lo que quieres en lógica de negocio.

La sintaxis alternativa

PHP permite una sintaxis alternativa de if, for, foreach y while usando dos puntos y endif. Es especialmente cómoda cuando intercalas mucho HTML en plantillas.

Ejercicio

  1. Escribe un script que reciba un precio en $precio y aplique: 10% de descuento si supera 100, 5% si supera 50, y nada en caso contrario.
  2. Usa match para traducir los códigos A, B, C a las etiquetas «Alta», «Media» y «Baja» prioridad.
  3. Reescribe esa decisión con switch y compara la sintaxis y el comportamiento.

Resumen

  • if / elseif / else construyen decisiones por bloques.
  • El ternario ?: comprime una decisión simple a una línea.
  • ?? devuelve el primer valor no nulo y evita avisos con claves ausentes.
  • match (PHP 8) compara en estricto y siempre devuelve un valor.
  • La sintaxis alternativa con endif brilla en plantillas con HTML.
