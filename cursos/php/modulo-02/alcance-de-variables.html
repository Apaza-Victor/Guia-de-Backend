Alcance de variables (scope)

⚙️ Intermedio 8 min PHP desde cero hasta avanzado Módulo 2 · Control de flujo y funciones

¿Qué es el alcance?

El alcance (scope) decide desde qué puntos del código puedes «ver» una variable. Si declaras una variable fuera de las funciones, esa variable es global. Si la declaras dentro de una función, es local a esa función.

Regla fundamental de PHP: una variable global no es visible dentro de una función y viceversa. Esta design es intencionada: mantiene cada función aislada y predecible.

El scope local de las funciones

Cada llamada a una función crea su propio mundo de variables. Los parámetros y las variables creadas dentro se destruyen al terminar la llamada... a menos que uses static.

La palabra global

Si necesitas usar una variable global dentro de una función, debes declararla con global $nombre;. A pesar de existir, en el backend moderno se evita: crea dependencias ocultas entre funciones.

Las superglobals

PHP pone a tu disposición superglobals: variables predefinidas disponibles en todo el código, incluso dentro de las funciones. Son el puente entre el mundo HTTP y tu programa.

  • $_GET: parámetros enviados por la URL.
  • $_POST: datos enviados por un formulario en POST.
  • $_SERVER: cabeceras y datos del servidor y de la petición.
  • $_SESSION y $_COOKIE: estado del usuario.
  • $_FILES: archivos subidos.

Ejercicio

  1. Crea una variable global $IVA = 0.21 e intenta usarla dentro de una función; anota el aviso que recibes.
  2. Resuelve el problema de dos formas: con global y pasándola como parámetro.
  3. Escribe una función con static $llamadas que cuente cuántas veces fue invocada.
  4. Dentro de una función, imprime el método HTTP actual usando $_SERVER.

Resumen

  • Las variables tienen ámbito local y global; los bloques if/for no crean scope propio.
  • Dentro de una función no se ven las variables globales automáticamente.
  • static conserva el valor local entre llamadas.
  • global importa una variable global, pero conviene evitarla.
  • Las superglobals como $_GET, $_POST o $_SERVER están siempre disponibles.
