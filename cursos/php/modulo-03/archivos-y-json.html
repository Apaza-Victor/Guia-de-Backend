Manipulación de archivos y JSON

⚙️ Intermedio 12 min PHP desde cero hasta avanzado Módulo 3 · Arrays y estructuras de datos

Leer archivos

PHP puede leer cualquier archivo del servidor. Las funciones habituales van desde file_get_contents (todo el contenido de una vez) hasta fopen + fgets para archivos grandes línea a línea.

Antes de leer, comprueba que el archivo existe con file_exists para evitar avisos desagradables.

Escribir archivos

Para guardar datos, tienes file_put_contents (escribe de una vez) o fopen con el modo "w" (sobrescribe) / "a" (añade al final).

En producción raramente escribirás archivos de datos: usarás una base de datos. Pero los logs y los archivos de configuración sí se leen y se escriben a diario.

De PHP a JSON: json_encode

JSON es el formato en el que el backend habla con el mundo. json_encode convierte arrays y objetos de PHP en una cadena JSON lista para enviar en una API.

Las opciones JSON_UNESCAPED_UNICODE (no escapar acentos) y JSON_PRETTY_PRINT (con saltos de línea) son las más usadas. En las APIs reales, la respuesta se envía con el header Content-Type: application/json.

De JSON a PHP: json_decode

json_decode hace el camino inverso: convierte una cadena JSON en un objeto o, si pasas true como segundo argumento, en un array asociativo.

La comprobación de errores es obligatoria: cuando json_decode devuelve null no sabes si es un JSON inválido o la palabra null válida. Detectar el error al decodificar siempre hay que hacerlo con json_last_error() y json_last_error_msg().

Ejercicio

  1. Crea un archivo datos.json con la estructura de un pedido (id, cliente, total, items).
  2. Léelo con file_get_contents y decodifícalo a array asociativo.
  3. Modifica el total y vuelve a guardarlo con file_put_contents y json_encode.
  4. Prueba a decodificar JSON inválido y muestra el mensaje de json_last_error_msg.

Resumen

  • Lee archivos con file_get_contents, file o fopen/fgets.
  • Escribe con file_put_contents y los modos w y a.
  • json_encode serializa arrays/objetos a JSON para APIs.
  • json_decode($json, true) devuelve un array asociativo.
  • Comprueba siempre el resultado de json_decode con json_last_error.
