Módulo 3 · Arrays y estructuras de datos

Trabaja con colecciones: arrays indexados, asociativos, funciones de orden superior y manejo de strings.

5 lecciones ≈ 54 min Módulo 2 recomendado

Objetivos del módulo

✔Crear y manipular arrays indexados y asociativos, con todas las llaves.
✔Recorrer colecciones con foreach y técnicas como desempaquetado y referencias.
✔Aplicar funciones de orden superior: array_map, array_filter y array_reduce.
✔Manipular strings con las funciones de texto y la interpolación.
✔Leer y escribir archivos y convertir datos entre PHP y JSON con json_encode y json_decode.
