Recorriendo arrays con foreach

⚙️ Intermedio 8 min PHP desde cero hasta avanzado Módulo 3 · Arrays y estructuras de datos

La forma básica

foreach es el bucle diseñado para recorrer arrays. Cada iteración te entrega el valor actual en una variable; no necesitas contadores ni índices.

Es la forma más segura de iterar: PHP gestiona el movimiento interno sin que te equivoques con índices, y funciona igual con arrays que tengan huecos o claves no numéricas.

Acceder a la clave y al valor

Con la forma foreach ($array as $clave => $valor) obtienes también la clave de cada elemento. Es imprescindible con arrays asociativos, como las configuraciones o las respuestas de una API.

Otro uso frecuente: cuando necesitas la posición para numerar resultados, aunque el array no esté indexado desde 0.

Modificar elementos dentro del bucle

En foreach la variable $valor es una copia: modificarla no cambia el array original. Para actualizar los elementos con el bucle, recorre por referencia con &$valor o altera el array usando la clave.

El unset($p) del final es una buena práctica documentada en la documentación oficial: sin él, la variable $p conserva la referencia al último elemento y podría sobreescribirlo sin querer después del bucle.

Recorridos sobre listas de objetos

Cuando una base de datos devuelve filas, casi siempre recibirás un array (de arrays u objetos). foreach es donde se construye el cuerpo de muchísimas respuestas HTTP.

Ejercicio

  1. Recorre un array de calificaciones y calcula la media con foreach.
  2. Conviértelas de escala 0-10 a 0-100: multiplica por 10 usando el modo por clave.
  3. Con un array asociativo de «ciudad => habitantes», imprime una frase por ciudad y calcula la suma total de habitantes.
  4. Comprueba qué ocurre si sumas $total dentro del bucle sin inicializarlo antes.

Resumen

  • foreach ($arr as $valor) recorre valores; as $clave => $valor añade la clave.
  • La variable de valor es una copia; para cambiar el array usa la clave o una referencia.
  • Cuando recorres por referencia, libera la última con unset($valor).
  • Es la herramienta principal para construir listados y totales en el backend.
