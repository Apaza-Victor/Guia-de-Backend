Funciones útiles: array_map, filter y reduce

⚙️ Intermedio 12 min PHP desde cero hasta avanzado Módulo 3 · Arrays y estructuras de datos

El estilo funcional con arrays

Cuando tratas colecciones, la mayor parte del trabajo se reduce a tres operaciones: transformar cada elemento (map), quedarse con los que cumplen una condición (filter) y acumular un resultado (reduce). PHP las tiene como funciones que reciben un callback.

Muchas veces se combinan con funciones flecha (PHP 7.4+) que permiten escribir la lógica en una línea sin crear funciones auxiliares.

array_map: transformar

array_map aplica una función a cada elemento y devuelve un array nuevo del mismo tamaño. El array original no se toca.

array_filter: filtrar

array_filter recorre el array y conserva únicamente los elementos para los que el callback devuelve true. Sin callback, elimina todos los valores falsy.

array_reduce: acumular

array_reduce reduce una colección a un único valor. El callback recibe el acumulador y el elemento actual, y devuelve el nuevo acumulador.

El tercer argumento es el valor inicial del acumulador. En el ejemplo del conteo, inicia en [] porque queremos ir «engordando» un array.

Combinar las tres

El proceso real de una API suele ser: filtro, transformo y resumo. Encadenar estas funciones produce código declarativo y fácil de leer.

Se lee de dentro hacia fuera: filtra lo no devuelto, calcula cada subtotal y suma todo.

Ejercicio

  1. Con array_map, convierte un array de nombres a mayúsculas con strtoupper.
  2. Con array_filter y una función flecha, quédate con los números mayores que 20.
  3. Con array_reduce, calcula el producto de todos los números de un array (inicia el acumulador en 1).
  4. Combina las tres para: recibir precios, descartar los negativos, aplicarles el IVA y sumar el resultado.

Resumen

  • array_map transforma cada elemento y devuelve un array nuevo.
  • array_filter conserva los elementos que cumplen la condición; sin callback quita los falsy.
  • array_reduce acumula un valor a lo largo de la colección.
  • Las funciones flecha fn($x) => ... hacen el estilo funcional mucho más legible.
  • Combinadas resuelven «filtra, transforma y resume», el patrón estrella del backend.
