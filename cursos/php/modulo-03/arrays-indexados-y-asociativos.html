Arrays indexados y asociativos

⚙️ Intermedio 12 min PHP desde cero hasta avanzado Módulo 3 · Arrays y estructuras de datos

¿Qué es un array?

Un array en PHP es una colección ordenada de pares clave => valor. Es la estructura de datos más importante del lenguaje porque puede representar listas, tablas, estructuras de configuraciones y respuestas de JSON.

Si solo indicas valores, PHP genera claves numéricas automáticas: es un array indexado. Si defines las claves tú mismo, tienes un array asociativo.

Añadir, modificar y eliminar

Los arrays de PHP son dinámicos: crecen solos y admiten cualquier mezcla de tipos. Para añadir un elemento sin especificar clave, usa la sintaxis de corchetes vacíos [], que agrega al final.

Arrays multidimensionales

Como los valores pueden ser cualquier cosa, es normal tener arrays de arrays (y arrays de objetos en el siguiente módulo). Los resultados de base de datos y las respuestas de APIs suelen ser exactamente eso.

Buscar y ordenar

PHP viene con decenas de funciones de arrays. Las más comunes en el día a día: in_array, array_key_exists, array_search, sort y ksort.

Ejercicio

  1. Crea un array asociativo con los datos de un producto: nombre, precio y stock.
  2. Añade un descuento con la clave descuento, actualiza el stock y elimina la clave con unset.
  3. Construye un array de 3 pedidos (arrays asociativos anidados) y muestra el total de cada uno.
  4. Usa array_merge para unir dos arrays de etiquetas y array_unique para quitar duplicados.

Resumen

  • Los arrays guardan pares clave => valor; sin claves se numeran solos desde 0.
  • $array[] = $x añade al final y unset() elimina.
  • count(), array_merge(), in_array() y array_search() son operaciones esenciales.
  • Los arrays multidimensionales modelan listas de registros, como las de una base de datos.
