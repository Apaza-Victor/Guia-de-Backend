⚡ Etapa Intermedio

Tu código funciona; ahora hazlo seguro, robusto y desplegable. Aprenderás a proteger accesos y datos, escribir código mantenible con patrones, probarlo con testing y empaquetarlo con Docker.

Habilidades que dominarás

JWT OAuth 2.0 Top 10 OWASP Testing Contenedores Git avanzado

Recorrido de la etapa

⚡

De funcional a profesional

Los siguientes temas distinguen a un desarrollador junior de uno que ya puede trabajar en producción.

1. Autenticación y Autorización

Sesiones, JWT, OAuth 2.0, roles y permisos: decide quién eres y qué puede hacer cada usuario en tu aplicación.

Curso: Autenticación y Autorización
Duración: 4 semanas

2. Seguridad en Backend

El Top 10 de OWASP en detalle: inyección SQL, XSS, cifrado, HTTPS y endurecimiento de servidores.

Curso: Seguridad en Backend
Duración: 4 semanas

3. Patrones de Diseño

Soluciones probadas para problemas recurrentes: patrones creacionales, estructurales y de comportamiento aplicados al Backend.

Curso: Patrones de Diseño
Duración: 4 semanas

4. Testing

Pruebas unitarias, de integración y end-to-end: la red de seguridad que te permite refactorizar sin miedo.

Curso: Testing
Duración: 4 semanas

5. Docker y Git avanzado

Empaqueta tu aplicación en contenedores reproducibles y domina flujos avanzados de Git: rebase, cherry-pick, tags y branching estratégico.

Curso: Docker Curso: Git y GitHub (avanzado)
Duración: 4 semanas
