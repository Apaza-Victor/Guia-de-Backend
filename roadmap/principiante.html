🌱 Principiante

🌱 Etapa Principiante

Aquí se construyen los cimientos: qué es el Backend, cómo funciona Internet y cómo programar tu primer servidor. No necesitas experiencia previa, solo curiosidad y constancia.

4 bloques · ~17 semanas 4 cursos Meta: tu primera API local

Habilidades que dominarás

Backend Internet y HTTP Lógica de programación Terminal Git básico

Recorrido de la etapa

🌱

Punto de partida

Sigue los bloques en orden. Cuando termines el último, estarás listo para la etapa Básico.

1. Fundamentos de Backend

Qué es el Backend, cómo funciona Internet, el protocolo HTTP y la arquitectura cliente-servidor. Todo lo que ocurre detrás de un clic.

Curso: Fundamentos de Backend
Duración: 6 semanas · 5 módulos

2. Programación para Backend

Lógica, variables, estructuras de datos, control de flujo y algoritmos básicos. El lenguaje de programación concreto lo elegirás en la siguiente etapa.

Curso: Programación para Backend
Duración: 5 semanas

3. Git y GitHub básico

Versiona tu código desde el día uno: commits, ramas, fusiones y el flujo de trabajo con repositorios remotos en GitHub.

Curso: Git y GitHub
Duración: 3 semanas

4. Linux básico

La terminal, los procesos, los permisos y SSH: el entorno real donde se ejecuta casi todo el Backend del mundo.

Curso: Linux para Backend
Duración: 3 semanas

Siguiente paso

¿Completaste los cuatro bloques? Es hora de elegir tu primer lenguaje de servidor y aprender bases de datos.
