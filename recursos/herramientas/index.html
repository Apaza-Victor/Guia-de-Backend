🛠️ Herramientas esenciales del backend

Un desarrollador de backend trabaja con pocas categorías de herramientas bien elegidas: un editor, una terminal, un cliente de bases de datos, un cliente de APIs y, según el proyecto, contenedores y servicios de nube. Aquí tienes las que recomendamos, agrupadas por categoría y con su sitio oficial.

9 categorías 25 herramientas Enlaces oficiales
💡

No instales todo de golpe. Empieza con un editor, la terminal de tu sistema y el cliente de la base de datos que estés estudiando. Añade el resto cuando lo necesites: cada herramienta se domina con el uso, no descargándolas todas.

Editores de código

El lugar donde pasas la mayor parte del tiempo. Coincidimos con la industria: que te guste usar uno es más importante que el editor en sí.

Visual Studio Code

Editor

El editor más popular del ecosistema: extensiones, depurador integrado, terminal y soporte para prácticamente todos los lenguajes de backend. Gratuito y multiplataforma.

Sitio oficial

Vim / Neovim

Editor

Editores modales que viven en la terminal. Neovim conserva la ligereza de Vim y suma un ecosistema moderno de plugins con LSP y autocompletado. Curva de aprendizaje alta, recompensa enorme.

Sitio oficial

Terminal

El backend se gobierna desde la terminal: comandos, scripts y conexiones remotas. Empieza por dominar tu shell y un buen emulador.

PowerShell

Shell

Shell y lenguaje de scripting de Microsoft, disponible hoy en Windows, Linux y macOS. Ideal para automatizar tareas y administrar sistemas en el ecosistema Microsoft.

Documentación

Windows Terminal

Emulador

Terminal moderna de Windows con pestañas, paneles y perfiles personalizables. Junta PowerShell, CMD y WSL en una sola ventana con tema oscuro.

Sitio oficial

iTerm2

Emulador

La terminal por excelencia de macOS: split panes, búsqueda instantánea, colores personalizados y perfiles. Esencial si desarrollas en un Mac.

Sitio oficial

Clientes de bases de datos

Las bases de datos se administran mejor con un cliente visual: ver eras con una interfaz no es hacer trampa, es ser productivo.

DBeaver

BD

Cliente universal de bases de datos gratuito y de código abierto: conecta MySQL, PostgreSQL, SQLite, Redis y decenas de motores desde una misma interfaz.

Sitio oficial

TablePlus

BD

Cliente nativo, rápido y elegante para macOS, Windows y Linux. Soporta las bases relacionales y NoSQL más usadas y es muy cómodo para el trabajo diario.

Sitio oficial

Clientes de API

Pruebas, colecciones y documentación de tus endpoints. Aprende curl primero y elige un cliente gráfico para trabajar más rápido.

Postman

APIs

El estándar para probar APIs: colecciones, entornos, variables, tests automatizados y documentación generada desde tus propios endpoints.

Sitio oficial

Insomnia

APIs

Cliente de APIs centrado en la productividad: soporta GraphQL, variables de entorno, generación de código en varios lenguajes y diseño de interfaces.

Sitio oficial

Bruno

APIs

Cliente de API de código abierto y sin nube: las colecciones se guardan como archivos de texto y viven en tu repositorio Git con el resto del código.

Sitio oficial

curl

CLI

La herramienta por línea de comandos para transferir datos con una URL. Imprescindible para probar endpoints, descargar archivos y automatizar peticiones.

Sitio oficial

Contenedores

Los contenedores empaquetan tu aplicación con todo lo que necesita para ejecutarse en cualquier máquina. Es el estándar del backend moderno.

Docker Desktop

Contenedores

Motor de contenedores con interfaz gráfica para levantar, inspeccionar y orquestar contenedores en local. La forma más rápida de tener una base de datos o un servicio corriendo en tu máquina.

Sitio oficial

Podman

Contenedores

Alternativa a Docker sin demonio central: funciona sin privilegios de root y es compatible con las imágenes del ecosistema Docker. Muy usada en servidores.

Sitio oficial

Sysadmin

Cuando tu proyecto sale de tu máquina, necesitas conocer las piezas que mantienen los servidores vivos.

Nginx

Servidor web

Servidor web y proxy inverso de altísimo rendimiento: sirve estáticos, hace balanceo de carga y termina TLS en producción. El compañero habitual de tus aplicaciones backend.

Sitio oficial

systemd

Servicios

Sistema de inicio y gestor de servicios en la mayoría de distribuciones Linux. Con unidades de systemd mantienes tus procesos siempre activos y recuperables.

Sitio oficial

htop

Monitoreo

Monitor de procesos interactivo para la terminal: uso de CPU, memoria y procesos en tiempo real para diagnosticar por qué un servidor va lento.

Sitio oficial

tmux

Terminal

Multiplexor de terminal: mantén sesiones corriendo en el servidor y reconéctate cuando quieras sin cortar tus procesos en ejecución.

Sitio oficial

Git

El control de versiones es la base de todo equipo. Aprende Git por terminal y usa un cliente gráfico como comodidad, no como sustituto.

Git

Control de versiones

Control de versiones distribuido: ramas, commits, historial y colaboración en equipo. Es la infraestructura sobre la que se apoya todo el desarrollo moderno.

Sitio oficial

GitHub Desktop

Git

Cliente gráfico oficial de GitHub para administrar repositorios, ramas y pull requests visualmente. Muy útil al empezar o en equipos que prefieren la interfaz.

Sitio oficial

Cloud

Cuando un proyecto crece, el backend se apoya en servicios en la nube para computar, almacenar y escalar sin administrar hardware.

AWS Console

Cloud

Panel de control de Amazon Web Services: EC2, S3, RDS y Lambda. El proveedor de infraestructura más usado del mundo y la referencia para estudiar cloud.

Sitio oficial

Vercel

Cloud

Plataforma para desplegar aplicaciones y funciones serverless con integración continua de Git y vistas previas por cada push. Perfecta para proyectos que combinan frontend y API.

Sitio oficial

Render

Cloud

Plataforma cloud sencilla: despliega servicios web, trabajos programados, bases de datos administradas y contenedores con una configuración mínima y permanente gratuita.

Sitio oficial

Railway

Cloud

Despliegue por plantillas y por Git: aprovisiona bases de datos, servicios y microservicios sin configurar servidores. Ideal para proyectos personales y prototipos.

Sitio oficial

Monitoreo y observabilidad

En producción, lo que no se mide no se puede mejorar. Estas herramientas convierten el caos en métricas y alertas accionables.

Grafana

Dashboards

Panel de visualización de métricas: conecta Prometheus, bases de datos y APIs para construir cuadros de mando de tus servicios en producción.

Sitio oficial

Prometheus

Métricas

Sistema de métricas y alertas de código abierto con un potente modelo de series de tiempo. El estándar de facto del monitoreo en Kubernetes.

Sitio oficial

Sentry

Errores

Monitorización de errores en producción: captura excepciones, trazas completas y la versión del código donde ocurrieron, en tiempo real.

Sitio oficial
