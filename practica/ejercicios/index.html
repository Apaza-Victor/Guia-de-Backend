✍️ Ejercicios prácticos

Doce ejercicios pensados para abrir el editor apenas terminas una lección. Lee el enunciado, intenta resolverlo sin ayuda y solo abre la pista si te atascas. Cada ejercicio enlaza a la lección que lo explica.

12 ejercicios 4 básicos 5 intermedios 3 avanzados

Nivel básico

Para las primeras semanas del roadmap: lo esencial de servidores, HTTP y lógica.

1. Tu primer servidor

🚀 Básico

Instrucción: escribe un servidor HTTP que responda {"mensaje": "Hola desde el backend"} en cada petición GET y ejecútalo en localhost:8000.

💡 Pista

Puedes usar el servidor integrado de Python http.server y sobrescribir el método do_GET.

Lección relacionada
¿Qué es Backend?

2. El servidor responde tu URL

🚀 Básico

Instrucción: modifica tu servidor para que responda un JSON con la ruta y el método de cada petición, por ejemplo {"ruta": "/hola", "metodo": "GET"}.

💡 Pista

El objeto de la petición expone self.path y self.command en el handler de Python.

Lección relacionada
Request

3. Cazador de códigos de estado

🚀 Básico

Instrucción: con curl -i visita cinco sitios conocidos y anota: código de estado, Content-Type y Server. Clasifícalos por familia (2xx, 3xx, 4xx, 5xx).

💡 Pista

Usa curl -i https://ejemplo.com. Los códigos 2xx son éxito, 3xx redirecciones y 4xx/5xx errores.

Lección relacionada
Códigos de estado HTTP

4. Tipos de datos en tu lenguaje

🚀 Básico

Instrucción: declara una variable de cada tipo básico (entero, decimal, texto, booleano y lista/arreglo) y muestra en consola su valor y su tipo.

💡 Pista

En Python usa type(), en PHP gettype() y en JavaScript typeof.

Lección relacionada
Tipos de datos

Nivel intermedio

Control de flujo, funciones y estructuras de datos aplicadas a problemas típicos del Backend.

5. Calculadora de descuentos

⚡ Intermedio

Instrucción: escribe una función que reciba el total de una compra y aplique 10% si supera 100, 20% si supera 500, y 0% en otro caso. Devuelve el total final.

💡 Pista

Evalúa primero el descuento mayor: usa condicionales en cascada con if / else if.

Lección relacionada
Condicionales

6. Suma los pares del 1 al 100

⚡ Intermedio

Instrucción: calcula la suma de todos los números pares entre 1 y 100 usando un bucle y muestra el resultado (debe ser 2550).

💡 Pista

Un bucle for con += y la condición n % 2 === 0 (o equivalente) es suficiente.

Lección relacionada
Bucles for

7. Validador de contraseña

⚡ Intermedio

Instrucción: escribe una función que valide una contraseña: mínimum 8 caracteres, al menos una mayúscula, un número y un símbolo. Devuelve true o false.

💡 Pista

Comprueba cada regla por separado y combínalas. No guardes contraseñas en texto plano cuando llegues a autenticación.

Lección relacionada
Funciones

8. Usuarios a partir de un array

⚡ Intermedio

Instrucción: dada una lista de nombres, genera otra con los nombres de más de 5 letras en mayúsculas. Hazlo con un bucle y después con funciones de alto nivel del lenguaje.

💡 Pista

Busca map y filter (o las funciones equivalentes de tu lenguaje).

Lección relacionada
Arrays

9. Inverso con recursividad

⚡ Intermedio

Instrucción: implementa una función recursiva que devuelva un texto al revés, sin usar el método invertido del lenguaje. Ejemplo: "hola" → "aloh".

💡 Pista

El último carácter de la cadena + la función aplicada al resto es la definición clásica.

Lección relacionada
Recursividad

Nivel avanzado

Calidad de código y manejo de errores: lo que separa un script de un Backend mantenible.

10. Caza el error

🔥 Avanzado

Instrucción: escribe deliberadamente tres errores (sintaxis, lógica y de tiempo de ejecución) y depúralos con las herramientas de tu lenguaje: usa la pila de errores, puntos de ruptura y la impresión de variables.

💡 Pista

Un error de lógica no da excepción: compara el resultado esperado con el obtenido paso a paso.

Lección relacionada
Debugging

11. Refactor a código limpio

🔥 Avanzado

Instrucción: toma una función larga con nombres vagos y variables sueltas. Refactórala en funciones pequeñas, con nombres claros, sin repetir lógica y comenta solo lo necesario.

💡 Pista

Un buen indicador: si la función tiene más de 20 líneas o varios if anidados, probablemente se puede dividir.

Lección relacionada
Clean Code

12. Consumo de API con errores

🔥 Avanzado

Instrucción: escribe un cliente que consulte una API pública, maneje tiempo de espera y errores de red con captura de excepciones, y devuelva un mensaje claro si falla.

💡 Pista

Envuelve la petición en try/catch, distingue error de conexión y error de respuesta HTTP, y define un timeout.

Lección relacionada
Manejo de errores
