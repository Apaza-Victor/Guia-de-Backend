🏁 Desafíos semanales

Retos semanales

Desafíos completos con requisitos, criterios de aceptación y entregables concretos. Cada reto pone en práctica varios temas a la vez: de un CRUD REST con autenticación JWT hasta cachear con Redis, dockerizar tu API o montar un pipeline de CI/CD.

1 reto nuevo por semana Intermedio y avanzado Al final, un portafolio

Cómo funcionan los retos

Un reto se considera superado cuando cumple todos sus criterios de aceptación y tu solución está publicada en GitHub. Los retos se publican de forma progresiva a medida que se completa cada área del roadmap.

📋 Enunciado

Requisitos

Descripción del sistema, stack permitido y criterios de aceptación verificables. Sin ambigüedad: o lo cumples o no.

FormatoEntregable definido

🧪 Evaluación

Criterios

Comprueba tú mismo cada criterio de aceptación antes de entregar. Si algo no se puede comprobar, no cuenta como criterio.

FormatoChecklist explícito

🚀 Entregable

GitHub

Repositorio con README, variables de entorno documentadas y pasos de ejecución. Tu perfil de GitHub es tu portafolio.

FormatoRepo + README

¿Para cuándo cada reto?

Caché con RedisCuando termines el módulo de caché y Redis del roadmap.
Dockerizar tu APIAl completar Docker: imagen, compose y despliegue local.

Servicio distribuidoAl final del roadmap: colas, consistencia y observabilidad en producción.
