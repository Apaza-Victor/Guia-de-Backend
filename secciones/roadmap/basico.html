🚀 Básico

🚀 Etapa Básico

Elige tu primer lenguaje de servidor y aprende a construir aplicaciones que guardan y recuperan datos. Eliges un camino: PHP, Node.js o Python, y lo complementas con bases de datos y APIs REST.

5 bloques · ~27 semanas 5 cursos Meta: APIs REST con persistencia

Habilidades que dominarás

PHP Node.js Python SQL Modelado de datos REST

Recorrido de la etapa

🚀

Tu primer lenguaje de servidor

Elige uno de los tres caminos según tus intereses: web clásica (PHP), ecosistema JavaScript (Node.js) o versatilidad y datos (Python).

1a. PHP

El lenguaje que impulsa la mayoría de la web. Sintaxis, entornos, buenas prácticas y frameworks modernos como Laravel.

Curso: PHP
Duración: 6 semanas

1b. Node.js

JavaScript del lado del servidor con Node y Express: eventos, operaciones asíncronas y APIs con el mismo lenguaje del frontend.

Curso: Node.js
Duración: 6 semanas

1c. Python para Backend

Python aplicado al servidor con FastAPI y Django: tipado, validación de datos y APIs modernas en muy pocas líneas.

Curso: Python para Backend
Duración: 6 semanas

2. Bases de Datos y SQL

Modelado de datos, normalización, índices y consultas: el par de cursos que te enseña a diseñar y consultar bases relacionales.

Curso: Bases de Datos Curso: SQL
Duración: 4 + 4 semanas

3. APIs REST básicas

Aplica todo lo anterior: diseña, versiona y documenta APIs REST con verbos HTTP, códigos de estado y buenas prácticas.

Curso: APIs REST
Duración: 5 semanas

4. HTTP avanzado

Caché, headers, cookies, autenticación básica por encabezados y control de la comunicación entre cliente y servidor.

Repasar módulos de HTTP REST avanzado
Integrado en los cursos anteriores
