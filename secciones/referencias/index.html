📚 Documentación oficial

📚 Referencias y enlaces oficiales

Toda la documentación y los enlaces oficiales que sustentan los cursos de Backend Academy, agrupados por categoría. Cuando una lección menciona una referencia, aquí la encontrarás lista para profundizar.

7 categorías Fuentes oficiales Enlaces verificados Se abren en pestaña nueva

Fundamentos y la Web

Los conceptos base de los cursos de fundamentos: Internet, HTTP y estándares.

  • MDN Web Docs — La referencia técnica de la Web en español: HTML, CSS, JavaScript y el protocolo HTTP explicados con autoridad.
  • MDN · HTTP — Métodos, cabeceras, códigos de estado y caché: el protocolo completo que mueve la Web.
  • W3C — El consorcio que publica los estándares abiertos de la Web.

Lenguajes de programación

Documentación oficial de los lenguajes que usas en la etapa Básico del roadmap.

  • Manual de PHP en español — Funciones, sintaxis y buenas prácticas del lenguaje del curso PHP.
  • Documentación de Node.js — La guía oficial de Node y su API para construir servidores con JavaScript.
  • Documentación de Python en español — El tutorial y la referencia del lenguaje usados en el curso de Python para Backend.
  • MDN · JavaScript — La referencia completa de JavaScript también aplicable a entornos de servidor.

Bases de datos

Motores y lenguajes de consulta trabajados en los cursos de bases de datos y SQL.

  • Documentación de MySQL — Manual oficial del motor más usado en los proyectos del curso SQL.
  • Documentación de PostgreSQL — Referencia de PostgreSQL: SQL, transacciones, índices y administración.
  • Documentación de SQLite — El motor autocontenido perfecto para empezar y para pruebas locales.
  • Documentación de Redis — Guía oficial de Redis: caché, estructuras de datos, colas y persistencia.

Control de versiones e infraestructura

Las herramientas que versionan y despliegan tu código: Git, contenedores y terminal.

  • Documentación de Git — Manuales y tutoriales oficiales del sistema de control de versiones.
  • Documentación de Docker — Imágenes, contenedores, Compose y los conceptos de los cursos de infraestructura.
  • Manual de Bash de GNU — La referencia de la shell más usada para operar servidores Linux.
  • Documentación del kernel de Linux — Material profundo del sistema operativo que ejecuta casi todo el Backend del mundo.

Seguridad

Las fuentes de referencia de los cursos de seguridad y autenticación.

  • OWASP Top 10 — Los diez riesgos de seguridad más críticos en aplicaciones web, con explicación y mitigaciones.
  • OWASP Cheat Sheet Series — Guías concretas de autenticación, control de acceso, cifrado y prevención de inyecciones.

Arquitectura y escalabilidad

Criterios y guías para diseñar sistemas que crecen: de un monolito a microservicios.

  • roadmap.sh — Mapas de ruta comunitarios de Backend y de otras especialidades, inspiración del roadmap de esta plataforma.
  • The Twelve-Factor App — Las doce prácticas para construir aplicaciones desplegables, escalables y mantenibles.
  • microservices.io — Patrones de diseño y despliegue de arquitecturas de microservicios.

Práctica y entrevistas

Recursos complementarios para ejercitar y preparar entrevistas técnicas.

  • SQLZoo — Tutoriales y ejercicios interactivos de SQL con corrección inmediata.
  • LeetCode — Problemas de lógica y algoritmos para preparar entrevistas de ingeniería de software.
  • System Design Primer — Material de referencia abierto para aprender a diseñar sistemas a gran escala.

¿Falta alguna referencia?

Las fuentes se verifican y actualizan de forma continua. Si detectas un enlace roto o conoces una referencia oficial valiosa para los cursos, contáctanos y lo revisamos.
