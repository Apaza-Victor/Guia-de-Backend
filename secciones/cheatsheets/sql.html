🗄️ SQL

El lenguaje universal de las bases relacionales: leer, filtrar, combinar y resumir datos. Esta hoja cubre SELECT hasta EXPLAIN, pasando por JOINs, CTEs y transacciones.

⚡ Cheatsheet Bases de datos Cheatsheets

SELECT

El orden lógico de evaluación SQL no coincide con el orden de escritura: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.

Subconsultas

CTEs (WITH)

La forma más legible de componer consultas: define bloques nombrados que se reutilizan en la consulta principal.

Transacciones

Agrupan operaciones que deben ocurrir todas o ninguna. Garantizan atomicidad, consistencia, aislamiento y durabilidad (ACID).

Índices

Los índices aceleran la lectura a cambio de espacio y escritura más lenta. Se crean sobre columnas que se usan en WHERE, JOIN y ORDER BY.

EXPLAIN

Diagnostica cómo ejecutaría el motor tu consulta. Busca Seq Scan (escaneo completo) y conviértelo en Index Scan creando el índice correcto.

Buenas prácticas

  • Escribe SQL en mayúsculas y usa alias cortos y consistentes (u, p).
  • Nunca construyas consultas concatenando texto del usuario: usa prepared statements.
  • Filtra lo máximo posible con WHERE antes de agregar con GROUP BY.
  • Evita SELECT * en la lógica de la aplicación; pide solo lo que usas.
  • Crea índices medidos con EXPLAIN, no a ciegas.
  • Usa transacciones para operaciones que deben ser atómicas.
