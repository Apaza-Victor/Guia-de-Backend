🟢 Node.js

JavaScript fuera del navegador: un runtime orientado a eventos que mueve gran parte de los backends modernos. Módulos core, npm, Express y procesos asíncronos.

⚡ Cheatsheet Backend Cheatsheets

Módulos core

Node agrupa su funcionalidad en módulos que se importan con require() (CommonJS) o import (ESM). Los más usados en backend:

MóduloPara quéComún de estos días
fsSistema de archivos: leer, escribir, borrar.fs/promises
pathUnir y normalizar rutas.path.join()
httpCrear servidores HTTP puros.suele delegarse a Express
osInformación del sistema (CPU, memoria, red).os.cpus()
urlParsear y construir URLs.new URL(...)
cryptoHashes, cifrado, aleatoriedad segura.crypto.randomUUID()
eventsEmisores de eventos.base de muchos módulos
child_processEjecutar comandos del sistema.spawn, exec

Debugging

Buenas prácticas

  • Sintaxis ESM (import/export) o CommonJS consistente en todo el proyecto.
  • Maneja siempre el rechazo de promesas: un error no capturado puede tumbar el proceso.
  • Usa fs/promises; evita operaciones síncronas dentro del flujo de una petición.
  • Separa capas: rutas, controladores, servicios y acceso a datos.
  • Añade .gitignore con node_modules/ y .env antes que nada.
  • Pin versiones con package-lock y revisa npm audit.
  • Para escala real emplea TypeScript, pero domina el JS primero.
