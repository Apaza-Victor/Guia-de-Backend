Errores y depuración

Buenas prácticas

  • Activa declare(strict_types=1); al inicio de todos los archivos.
  • Usa prepared statements (PDO) para toda consulta con datos de usuario.
  • Nunca muestres errores en producción: loguealos con error_log().
  • Escapa la salida con htmlspecialchars() para prevenir XSS.
  • Valida y sanea toda entrada: filter_var(), ctype_* y casting.
  • Separa responsabilidades: un archivo no debería hacer SQL y pintar HTML a la vez.
  • Usa Composer para dependencias y PSR-4 para autoloading.
